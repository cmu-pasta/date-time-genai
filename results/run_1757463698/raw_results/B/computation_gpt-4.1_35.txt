Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We will use the `datetime` and `zoneinfo` modules from the standard library. The `zoneinfo` module is available in Python 3.9+ and provides support for IANA time zones.
2. **Define a function**: We'll define a function that accepts a `datetime` input (`dt`) and a `zoneinfo.ZoneInfo` timezone (`tz`).
3. **Attach the timezone if needed**: If the `datetime` object is naive (lacking timezone information), we'll assign the input timezone.
4. **Determine if DST is observed**: We'll inspect the `dst()` method of the `datetime` object with timezone to determine if it is non-zero (which means DST is active).
5. **Return the result**: The function will return a `bool` indicating if the given datetime is in daylight saving time for the specified timezone.

```python
from datetime import datetime
from zoneinfo import ZoneInfo

def is_dst(dt: datetime, tz: ZoneInfo) -> bool:
    # Step 1: Ensure the datetime is timezone-aware; attach timezone if naive
    if dt.tzinfo is None:
        dt = dt.replace(tzinfo=tz)
    else:
        # Convert to requested timezone if already tz-aware
        dt = dt.astimezone(tz)
    # Step 2: Determine if DST is in effect by checking if dt.dst() is not zero
    return bool(dt.dst() and dt.dst() != datetime.timedelta(0))

# Entry point: is_dst(dt: datetime, tz: ZoneInfo) -> bool
```
