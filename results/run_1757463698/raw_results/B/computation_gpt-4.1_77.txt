Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We'll use the `datetime` module to work with dates. We also need `calendar` to determine the total days in the month.
2. **Define the function**: We'll write a function that takes three integer inputs: `year`, `month`, and `weekday` (where Monday is 0 and Sunday is 6).
3. **Find total days in the month**: Use the `calendar.monthrange(year, month)` function, which returns a tuple where the second value is the total number of days in the month.
4. **Loop through each day of the month**: For each day, create a `date` object and check if its `weekday()` matches the given weekday.
5. **Return the result**: The function will return the number of times this weekday falls in the given month as an integer.

```python
from datetime import date
import calendar

def count_weekday_in_month(year: int, month: int, weekday: int) -> int:
    # Step 1: Get the total number of days in the given month
    _, num_days = calendar.monthrange(year, month)
    
    # Step 2: Initialize a counter for matching weekdays
    count = 0
    
    # Step 3: Loop through each day of the month
    for day in range(1, num_days + 1):
        current_date = date(year, month, day)
        if current_date.weekday() == weekday:
            count += 1
    
    # Step 4: Return the total count
    return count

# Entry point: count_weekday_in_month(year: int, month: int, weekday: int) -> int
```
