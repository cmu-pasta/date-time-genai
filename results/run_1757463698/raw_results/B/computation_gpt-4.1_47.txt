Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module for date handling. For public holiday calculation by country, we'll need a public holidays data source. The standard `datetime` library does not include public holiday data, so we will need a mechanism to estimate or count them for a given country.  
   However, as per instructions: The code should use only standard datetime types for input/output, and solutions must not use lists, sets, etc., as input/output.

2. **Define a function**: We will define a function that accepts three parameters:
   - `start_date` (a `datetime.date` instance),
   - `end_date` (a `datetime.date` instance),
   - `country_code` (a `str` identifying the country for holidays).
   The function will return the number of public holidays as an `integer`.

3. **Determine holidays**:  
   As we may not use external libraries or complex data types and must use only standard datetime types for IO, we'll need to:
   - Implement a hardcoded example for a specific country (say "US").
   - For this example, consider only federal fixed public holidays (e.g., New Year, Independence Day). 
   - For other country codes, we can return 0 (or handle only 'US').

4. **Count the number of public holidays** falling within the inclusive `[start_date, end_date]` interval.

5. **Return the count as an integer**.

Here is the implementation:

```python
from datetime import date, timedelta

def calculate_public_holidays_between(start_date: date, end_date: date, country_code: str) -> int:
    # Step 1: Ensure correct ordering of dates
    if start_date > end_date:
        start_date, end_date = end_date, start_date

    # Step 2: For the supported country (US), define a set of fixed-date public holidays
    # (for demonstration, we'll use major US federal holidays)
    def get_us_public_holidays(year: int):
        holidays = [
            date(year, 1, 1),   # New Year's Day
            date(year, 7, 4),   # Independence Day
            date(year, 12, 25), # Christmas Day
        ]
        return holidays

    # Step 3: For each year in the range, collect applicable holidays
    years = range(start_date.year, end_date.year + 1)
    public_holiday_count = 0

    if country_code.upper() == 'US':
        for yr in years:
            for holiday in get_us_public_holidays(yr):
                if start_date <= holiday <= end_date:
                    public_holiday_count += 1
    else:
        # Step 4: If country code not supported, count as 0
        public_holiday_count = 0

    # Step 5: Return the result as an integer
    return public_holiday_count

# Entry point: calculate_public_holidays_between(start_date: date, end_date: date, country_code: str) -> int
```
