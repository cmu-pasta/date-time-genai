Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with `datetime` objects.
2. **Define the function**: We will create a function that accepts a `datetime` object as input.
3. **Find the ISO week start**: The ISO week starts on Monday. We can use the `isoweekday()` method (where Monday is 1) to calculate how many days to subtract from the given datetime to reach the Monday of that week.
4. **Normalize to start of day**: To get the timestamp for the very start of the week, set the time fields to 00:00:00.
5. **Return the result**: Return the `datetime` object representing the start of the ISO week.

```python
from datetime import datetime, timedelta

def get_iso_week_start(dt: datetime) -> datetime:
    # Step 1: Calculate days to subtract to get to Monday (ISO week start)
    days_to_subtract = dt.isoweekday() - 1  # isoweekday() is 1 (Monday) to 7 (Sunday)
    
    # Step 2: Subtract these days and set time to 00:00:00
    iso_week_start = (dt - timedelta(days=days_to_subtract)).replace(hour=0, minute=0, second=0, microsecond=0)
    
    # Step 3: Return the datetime of ISO week start (Monday at 00:00:00)
    return iso_week_start

# Entry point: get_iso_week_start(dt: datetime) -> datetime
```
