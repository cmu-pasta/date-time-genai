Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts a date or datetime object as input.
3. **Extract the day of the year**: The `date` and `datetime` classes in Python have a method called `.timetuple()`. Its `tm_yday` attribute gives us the day of the year as an integer (from 1 to 366).
4. **Return the result**: Return the integer value representing the nth day of the year for the given date.

```python
from datetime import date, datetime

def get_nth_day_of_year(dt: date) -> int:
    # Step 1: Use the timetuple method to access tm_yday
    nth_day = dt.timetuple().tm_yday
    
    # Step 2: Return the day of the year as an integer
    return nth_day

# Entry point: get_nth_day_of_year(dt: date) -> int
```
