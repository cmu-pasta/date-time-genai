Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We will use the `datetime` module from Python's standard library.
2. **Define a function**: The function will accept two `datetime` objects, representing the timestamps to be subtracted.
3. **Calculate the duration**: Subtract the two `datetime` objects to get a `timedelta` object representing the duration.
4. **Extract hours and minutes**: Convert the total duration in seconds to hours and minutes as integers.
5. **Return the result**: Return the hours and minutes as two separate integers.

```python
from datetime import datetime

def duration_in_hours_and_minutes(ts1: datetime, ts2: datetime) -> int:
    """
    Subtract two timestamps (datetime objects) and return the duration in hours and minutes.
    Returns the total duration as the number of hours * 100 + minutes (e.g. 3 hours 45 minutes -> 345).
    """
    # Step 1: Calculate absolute difference
    delta = abs(ts2 - ts1)
    # Step 2: Extract total seconds
    total_seconds = int(delta.total_seconds())
    # Step 3: Compute hours and minutes
    hours = total_seconds // 3600
    minutes = (total_seconds % 3600) // 60
    # Step 4: Combine hours and minutes in a simple integer format
    result = hours * 100 + minutes
    return result

# Entry point: duration_in_hours_and_minutes(ts1: datetime, ts2: datetime) -> int
```
