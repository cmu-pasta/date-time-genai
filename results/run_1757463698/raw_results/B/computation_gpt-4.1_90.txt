3. **Accept the user input**: Our function will accept a `datetime.date` object as input.

5. **Return the result**: Map each range to an integer (e.g. Aries=1, Taurus=2, ..., Pisces=12), and return the corresponding integer value.

```python
from datetime import date

def find_zodiac_sign(birth_date: date) -> int:
    # Step 1: Extract month and day from the date
    month = birth_date.month
    day = birth_date.day

    # Step 2: Check which zodiac sign matches
    # Zodiac sign dates (Western astrology):
    # Aries:       March 21 - April 19
    # Taurus:      April 20 - May 20
    # Gemini:      May 21 - June 20
    # Cancer:      June 21 - July 22
    # Leo:         July 23 - August 22
    # Virgo:       August 23 - September 22
    # Libra:       September 23 - October 22
    # Scorpio:     October 23 - November 21
    # Sagittarius: November 22 - December 21
    # Capricorn:   December 22 - January 19
    # Aquarius:    January 20 - February 18
    # Pisces:      February 19 - March 20

    if   (month == 3 and day >= 21) or (month == 4 and day <= 19):
        return 1  # Aries
    elif (month == 4 and day >= 20) or (month == 5 and day <= 20):
        return 2  # Taurus
    elif (month == 5 and day >= 21) or (month == 6 and day <= 20):
        return 3  # Gemini
    elif (month == 6 and day >= 21) or (month == 7 and day <= 22):
        return 4  # Cancer
    elif (month == 7 and day >= 23) or (month == 8 and day <= 22):
        return 5  # Leo
    elif (month == 8 and day >= 23) or (month == 9 and day <= 22):
        return 6  # Virgo
    elif (month == 9 and day >= 23) or (month == 10 and day <= 22):
        return 7  # Libra
    elif (month == 10 and day >= 23) or (month == 11 and day <= 21):
        return 8  # Scorpio
    elif (month == 11 and day >= 22) or (month == 12 and day <= 21):
        return 9  # Sagittarius
    elif (month == 12 and day >= 22) or (month == 1 and day <= 19):
        return 10 # Capricorn
    elif (month == 1 and day >= 20) or (month == 2 and day <= 18):
        return 11 # Aquarius
    elif (month == 2 and day >= 19) or (month == 3 and day <= 20):
        return 12 # Pisces
    else:
        # Should not happen if input is valid date
        raise ValueError("Invalid birth date for zodiac computation.")
```
