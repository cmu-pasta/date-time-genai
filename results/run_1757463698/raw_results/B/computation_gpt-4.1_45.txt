Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module (specifically, `date`, `timedelta`) to work with dates.
2. **Define a function**: We'll create a function that accepts a single input: a `date` object representing any date in the target month.
3. **Calculate the last day of the month**: 
    - Find the first day of the next month.
    - Subtract one day from it to get the last day of the current month.
4. **Determine if the last day is a business day**:
    - If it's a weekday (Monday-Friday), that's our answer.
    - If it's a weekend (Saturday or Sunday), subtract one day at a time until we reach a weekday.
5. **Return the result**: Output the result as a `date` object.

```python
from datetime import date, timedelta

def last_business_day_of_month(given_date: date) -> date:
    # Step 1: Find the first day of the next month
    if given_date.month == 12:
        first_of_next_month = date(given_date.year + 1, 1, 1)
    else:
        first_of_next_month = date(given_date.year, given_date.month + 1, 1)
    
    # Step 2: Get the last day of the current month
    last_day = first_of_next_month - timedelta(days=1)
    
    # Step 3: If last day is a weekday (Mon-Fri), return it, otherwise step backward
    while last_day.weekday() >= 5:  # 5 = Saturday, 6 = Sunday
        last_day -= timedelta(days=1)
    
    # Step 4: Return the last business day as a date object
    return last_day

# Entry point: last_business_day_of_month(given_date: date) -> date
```
