Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need to use `datetime` from Python's standard library to work with dates and time.
2. **Define the function**: We'll create a function that takes two `datetime` objects: the current time and the future event time.
3. **Calculate the time difference**: Subtract the current datetime from the future event datetime to obtain a `timedelta` object.
4. **Extract the total number of days**: Use the `.days` attribute of the `timedelta` object to get the difference in days (ignoring any negative values if the event is in the past).
5. **Convert days to weeks and days**: Compute the integer number of full weeks and remaining days.
6. **Return the output**: Return the number of weeks and days as two separate integers.

```python
from datetime import datetime

def time_until_event_in_weeks_and_days(current_time: datetime, future_event_time: datetime) -> int:
    """
    Calculates the time remaining until a future event in weeks and days.
    Returns the number of weeks and days as two integers, separated by a comma.
    If the event is in the past, both values will be zero.
    """
    # Step 1: Calculate the timedelta between now and the event
    delta = future_event_time - current_time

    # Step 2: If the event is in the past, return 0 weeks and 0 days
    if delta.days <= 0:
        print(0)
        print(0)
        return

    # Step 3: Convert days to weeks and remaining days
    weeks = delta.days // 7
    days = delta.days % 7

    # Step 4: Return the result: weeks and days as integers, each on its own line
    print(weeks)
    print(days)

# Entry point: time_until_event_in_weeks_and_days(current_time: datetime, future_event_time: datetime) -> int
```
