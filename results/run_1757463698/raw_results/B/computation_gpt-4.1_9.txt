Let's think step by step to solve this problem.

1. **Import the necessary library**: We need to use the `datetime` library's `date` object to represent dates.
2. **Define a function**: We will create a function that accepts a single argument of type `date`.
3. **Advance to the next month**: To find the last day of the month, move to the first day of the next month. If the input date is in December, we move to January of the following year.
4. **Step back by one day**: Subtract one day from the first day of the next month to get the last day of the current month.
5. **Return the result**: Output the date corresponding to the last day of the month.

```python
from datetime import date, timedelta

def last_day_of_month(input_date: date) -> date:
    # Step 1: Find the first day of the next month
    if input_date.month == 12:
        next_month = date(input_date.year + 1, 1, 1)
    else:
        next_month = date(input_date.year, input_date.month + 1, 1)
    
    # Step 2: Subtract one day from the first day of next month to get last day of input month
    last_day = next_month - timedelta(days=1)
    
    # Step 3: Return the last day
    return last_day

# Entry point: last_day_of_month(input_date: date) -> date
```
