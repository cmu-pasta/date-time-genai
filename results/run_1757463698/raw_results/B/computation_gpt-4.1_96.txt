Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We will use `datetime` and `zoneinfo` from Python's standard library to work with time zones and offsets.
2. **Define a function**: We'll create a function that accepts a `zoneinfo.ZoneInfo` object as input.
3. **Determine a date that is always outside of daylight saving time (DST)**: In most regions, January 1st is outside DST. We'll pick January 1st, 2020 to avoid ambiguity.
4. **Create a datetime object in the given timezone for that date**.
5. **Get the UTC offset for that datetime and timezone**: This will provide the standard time offset (not accounting for DST).
6. **Return the standard offset as a `timedelta` object**.

```python
from datetime import datetime, timedelta
from zoneinfo import ZoneInfo

def get_standard_utc_offset(tz: ZoneInfo) -> timedelta:
    # Step 1: Pick a date that is very likely outside DST - January 1st, 2020
    reference_date = datetime(2020, 1, 1, 0, 0, 0, tzinfo=tz)
    # Step 2: Get the UTC offset for the given datetime and timezone
    standard_offset = reference_date.utcoffset()
    # Step 3: Return the offset as a timedelta
    return standard_offset

# Entry point: get_standard_utc_offset(tz: ZoneInfo) -> timedelta
```
