Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.  
2. **Define a function**: We'll write a function that accepts a `date` object as input.  
3. **Compute the ISO week number**: The `date` object in Python has an `.isocalendar()` method that returns a tuple `(ISO year, ISO week number, ISO weekday)`. We can retrieve the week number from this tuple.  
4. **Return the result**: We'll return the ISO week number as an integer.  

```python
from datetime import date

def get_iso_week_number(input_date: date) -> int:
    # Step 1: Use the .isocalendar() method to get the ISO week
    iso_calendar = input_date.isocalendar()  # Returns (ISO year, ISO week number, ISO weekday)
    iso_week_number = iso_calendar[1]        # The second element is the ISO week number
    
    # Step 2: Return the ISO week number
    return iso_week_number

# Entry point: get_iso_week_number(input_date: date) -> int
```
