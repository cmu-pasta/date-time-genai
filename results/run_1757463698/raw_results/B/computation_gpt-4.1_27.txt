1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with datetime objects and time deltas.
2. **Define a function**: We'll define a function that accepts two `datetime` objects as input.
3. **Calculate the difference**: Compute the absolute difference between the two datetime inputs using subtraction, resulting in a `timedelta` object.
4. **Find the midpoint**: Add half of this time delta to the earlier of the two datetimes to get the exact midpoint.
5. **Return the result**: Return the midpoint as a `datetime` object.

```python
from datetime import datetime, timedelta

def midpoint_between_datetimes(dt1: datetime, dt2: datetime) -> datetime:
    # Step 1: Calculate the difference
    difference = dt2 - dt1

    # Step 2: Compute half of the difference (midpoint duration)
    half_difference = difference / 2

    # Step 3: Find the earlier datetime as the base
    if dt1 < dt2:
        midpoint = dt1 + half_difference
    else:
        midpoint = dt2 + (-half_difference)

    # Step 4: Return the midpoint datetime
    return midpoint
```
