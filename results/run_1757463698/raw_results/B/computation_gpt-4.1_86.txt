Let's think step by step to solve this problem.

1. **Import the necessary library**: We'll use the `datetime` module, specifically the `time` class, to compare times.
2. **Define the function and its parameters**: We'll create a function that accepts three `datetime.time` objects as input:
    - `check_time`: the time we want to check,
    - `interval_start`: the start of the recurring interval,
    - `interval_end`: the end of the recurring interval.
3. **Handle normal and overnight intervals**:
    - If `interval_start <= interval_end`, the interval is on the same day (e.g., 12:00–13:00).
    - If `interval_start > interval_end`, the interval spans midnight (e.g., 22:00–02:00).
4. **Determine if `check_time` falls within the interval**:
    - For normal intervals: check if `interval_start <= check_time < interval_end`.
    - For overnight intervals: check if `check_time >= interval_start` _or_ `check_time < interval_end`.
5. **Return the result**: The function returns a boolean value: `True` if `check_time` falls within the interval, `False` otherwise.

```python
from datetime import time

def is_time_in_recurring_interval(check_time: time, interval_start: time, interval_end: time) -> bool:
    """
    Checks if 'check_time' falls within a recurring interval defined by 'interval_start' and 'interval_end'.
    Handles intervals that may span midnight.
    """
    # If interval does not span midnight
    if interval_start <= interval_end:
        return interval_start <= check_time < interval_end
    else:
        # Interval spans midnight
        return check_time >= interval_start or check_time < interval_end
```
