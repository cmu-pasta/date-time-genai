Let's think step by step to solve this problem.

1. **Import the necessary library**: We need the `datetime` module from Python's standard library to handle dates.
2. **Define a function**: We will create a function that accepts two dates as input. These should be of type `datetime.date`.
3. **Arrange the dates in order**: Ensure the first date is not after the second date to simplify iteration, or swap if needed.
4. **Count weekdays**: Iterate from the start date to the end date (inclusive), and for each date, check if it is a weekday (Monday=0 to Friday=4; use `.weekday()` method).
5. **Return the count**: The function will return an integer representing the number of weekdays between the two dates.

```python
from datetime import date, timedelta

def count_weekdays_between(d1: date, d2: date) -> int:
    # Ensure d1 is not after d2
    if d1 > d2:
        d1, d2 = d2, d1
    count = 0
    current = d1
    one_day = timedelta(days=1)
    while current <= d2:
        if current.weekday() < 5:  # 0=Monday, ..., 4=Friday
            count += 1
        current += one_day
    return count

# Entry point: count_weekdays_between(d1: date, d2: date) -> int
```
