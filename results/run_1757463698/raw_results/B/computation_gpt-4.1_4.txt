Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with date objects.
2. **Define a function**: The function will take a birthdate as input. The birthdate should be a `datetime.date` object for precise calculations.
3. **Get today's date**: We use `datetime.date.today()` to get the current date.
4. **Compute the preliminary difference in years, months, and days**:
    - Subtract the birth year from the current year to get years.
    - Subtract the birth month from the current month to get months.
    - Subtract the birth day from the current day to get days.
5. **Adjust the years and months based on the month/day differences**:
    - If the day difference is negative, borrow days from previous month and decrement month.
    - If the month difference is negative, borrow months from previous year and decrement year.
6. **Return the result**: The function should return the age as three integers—years, months, and days.

```python
from datetime import date

def compute_age_in_years_months_days(birthdate: date) -> int:
    # Step 3: Get today's date
    today = date.today()
    
    # Step 4: Compute the preliminary difference
    years = today.year - birthdate.year
    months = today.month - birthdate.month
    days = today.day - birthdate.day
    
    # Step 5: Adjust for negative days
    if days < 0:
        # Borrow days from previous month
        # Calculate the number of days in the previous month
        if today.month == 1:
            prev_month = 12
            prev_year = today.year - 1
        else:
            prev_month = today.month - 1
            prev_year = today.year
        from calendar import monthrange
        days_in_prev_month = monthrange(prev_year, prev_month)[1]
        days += days_in_prev_month
        months -= 1

    # Step 5: Adjust for negative months
    if months < 0:
        months += 12
        years -= 1

    # Since the output type cannot be a tuple (per constraints), we'll encode the three values as a single integer.
    # For clarity, we'll return years*10000 + months*100 + days  (e.g. 21 years, 5 months, 12 days = 210512).
    return years * 10000 + months * 100 + days
```
