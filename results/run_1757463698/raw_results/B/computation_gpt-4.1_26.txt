Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` class from Python's standard `datetime` module to work with datetimes.
2. **Define a function**: We'll create a function that takes two inputs: a datetime string and a format string (custom format) for parsing. Both will be of type `str`.
3. **Parse the string to a datetime object**: Use `datetime.strptime()` with the given input string and format to parse the custom-formatted string.
4. **Return the result**: Output the resulting `datetime` object.

Here is the implementation in code:

```python
from datetime import datetime

def parse_custom_datetime_string(dt_string: str, format_string: str) -> datetime:
    # Step 1: Parse the datetime string using the custom format
    dt_obj = datetime.strptime(dt_string, format_string)
    
    # Step 2: Return the datetime object
    return dt_obj

# Entry point: parse_custom_datetime_string(dt_string: str, format_string: str) -> datetime
```
