Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to determine the dates and their week numbers.
2. **Define a function**: We'll create a function that accepts a year (as an integer), constructs the last day of that year as a `date` object, and returns its week number.
3. **Construct the last day of the year**: Given a year, the last day will always be December 31st. We'll use `datetime.date(year, 12, 31)` to generate this date.
4. **Get the ISO week number**: The ISO calendar week can be obtained with the `isocalendar()` method, which returns a tuple `(ISO year, ISO week number, ISO weekday)`. We'll extract the week number.
5. **Return the result**: The function will return the week number as an integer.

```python
from datetime import date

def get_weeknumber_of_last_day_of_year(year: int) -> int:
    # Step 3: Construct the last day of the given year
    last_day = date(year, 12, 31)
    
    # Step 4: Get the ISO week number using isocalendar()
    week_number = last_day.isocalendar()[1]
    
    # Step 5: Return the result as an integer
    return week_number

# Entry point: get_weeknumber_of_last_day_of_year(year: int) -> int
```
