Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We'll use the `datetime` module from Python's standard library. For convenience, we'll also use the `calendar` module, as it helps us get the number of days in a month.
2. **Define a function**: We will create a function that accepts a `datetime` object as input.
3. **Find the last day of the month**: Using the year and month of the given date, we can use `calendar.monthrange()` to get the last day of that month.
4. **Construct the end-of-month timestamp**: We'll create a new `datetime` object with the same year and month, and set the day to the last day. We'll set the time to the last possible second of the day (23:59:59) (and use the same tzinfo as the input, if any).
5. **Return the result**: The function returns the constructed `datetime` object.

```python
from datetime import datetime, time
import calendar

def end_of_month_timestamp(dt: datetime) -> datetime:
    # Step 1: Find the last day in the month
    last_day = calendar.monthrange(dt.year, dt.month)[1]
    # Step 2: Construct a datetime for the last second of the last day
    end_of_month = datetime(
        year=dt.year,
        month=dt.month,
        day=last_day,
        hour=23,
        minute=59,
        second=59,
        tzinfo=dt.tzinfo  # Preserve timezone info, if present
    )
    return end_of_month
```
