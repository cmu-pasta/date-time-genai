Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` and `zoneinfo` modules from Python's standard library. The `zoneinfo` module (introduced in Python 3.9) provides support for IANA time zones.
2. **Define a function**: We will create a function that accepts the year (as an integer) and the timezone (as a `zoneinfo.ZoneInfo` object) as inputs.
3. **Determine the daylight saving start**: Most time zones that observe DST change their offset at local 2:00 am. We'll iterate over each day (starting from January 1st) checking for an increase in UTC offset, which indicates the start of daylight saving time.
4. **Return the result**: The function will return the exact `datetime` (with timezone) corresponding to the daylight saving time start, or `None` if the timezone does not observe DST in that year.

```python
from datetime import datetime, timedelta
from zoneinfo import ZoneInfo

def get_daylight_saving_start(year: int, tz: ZoneInfo) -> datetime:
    """
    Returns the start datetime of daylight saving time for a given year and timezone,
    or None if DST is not observed.
    """
    # Step 1: Define the starting point of the search (January 1st of the year)
    dt = datetime(year, 1, 1, 0, 0, 0, tzinfo=tz)
    # Step 2: Store the initial UTC offset
    prev_offset = dt.utcoffset()
    # Step 3: Loop day by day through the year to find the DST start
    one_day = timedelta(days=1)
    while dt.year == year:
        next_dt = dt + one_day
        next_offset = next_dt.utcoffset()
        if next_offset > prev_offset:
            # Step 4: Narrow down to exact time by iterating hour and minute
            # We'll perform a binary search between dt and next_dt to be precise
            low = dt
            high = next_dt
            while (high - low) > timedelta(minutes=1):
                mid = low + (high - low) // 2
                if mid.utcoffset() > prev_offset:
                    high = mid
                else:
                    low = mid
            # Step 5: Return the first datetime at which DST is in effect
            return high
        dt = next_dt
        prev_offset = next_offset
    # Step 6: Return None if no DST transition is found
    return None
```
