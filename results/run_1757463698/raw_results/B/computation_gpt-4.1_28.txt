Let's think step by step to solve this problem.

1. **Import the necessary library**: We will use the `datetime` module from Python's standard library.
2. **Define the function**: The function will take a single input which is a `date` object from `datetime`.
3. **Compute the first day of the current month**: Using the input date, we first figure out if it's already the first of the month.
4. **If the date is already the first day, move to next month's first day**: If yes, then we need to move to the first day of the next month.
5. **Otherwise, return the first day of the next month**: If it's not the first, we also return the first day of the next month.
6. **Handle year increment**: If the current month is December, rolling forward involves incrementing the year.
7. **Return the result**: The function will return a `date` object representing the next first-day-of-the-month.

```python
from datetime import date

def roll_forward_to_next_month_start(dt: date) -> date:
    # Step 1: Check if current month is December
    if dt.month == 12:
        # Next month is January of the next year
        next_month = 1
        next_year = dt.year + 1
    else:
        # Normal case: increment the month
        next_month = dt.month + 1
        next_year = dt.year
    # Step 2: Construct and return the first day of the next month
    return date(next_year, next_month, 1)

# Entry point: roll_forward_to_next_month_start(dt: date) -> date
```
