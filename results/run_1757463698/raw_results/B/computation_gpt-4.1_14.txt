Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `date` class from Python's `datetime` module to work with dates.
2. **Define a function**: We'll create a function that receives the current date (as a `date` object) and the month and day (as integers) of the holiday.
3. **Construct the holiday for the current or next year**: We'll construct a `date` object representing the next occurrence of the holiday. 
    - If the holiday has not occurred yet this year, use the current year.
    - If the holiday has already passed this year, use the next year.
4. **Calculate the number of days until the next occurrence**: Subtract the current date from the holiday date to get a `timedelta` object and use its `days` attribute.
5. **Return the result**: Return the number of days as an integer.

```python
from datetime import date

def days_until_next_holiday(current_date: date, holiday_month: int, holiday_day: int) -> int:
    # Step 1: Construct the holiday date for the current year
    holiday_this_year = date(current_date.year, holiday_month, holiday_day)
    
    # Step 2: If the holiday has already occurred this year, use next year
    if holiday_this_year < current_date:
        holiday_next = date(current_date.year + 1, holiday_month, holiday_day)
    else:
        holiday_next = holiday_this_year
    
    # Step 3: Calculate the difference in days
    delta = (holiday_next - current_date).days
    
    # Step 4: Return the result as an integer
    return delta

# Entry point: days_until_next_holiday(current_date: date, holiday_month: int, holiday_day: int) -> int
```
