Let's think step by step to solve this problem.

1. **Identify What Is Required**:  
   We are to determine the date and time of a solstice (either June or December) for a given location and year, using only the standard `datetime` (and optionally `zoneinfo`) library datatypes for input and output.

2. **Solstice Approximation**:  
   Accurate solstice calculations require astronomical algorithms, which are not present in the standard library. However, we can use well-known average UTC datetimes for the solstices, and adjust the output to the given location's time zone using the `zoneinfo` module (Python 3.9+).

   - *June solstice*: typically occurs around June 21st at 15:00 UTC.
   - *December solstice*: typically occurs around December 21st at 10:00 UTC.

   These are average values; actual times vary year to year by several hours, but this is the best approximation available without third-party libraries.

3. **Handling the Location**:  
   We'll accept the location as an IANA time zone string (e.g., `"America/New_York"`), and use `zoneinfo.ZoneInfo` to convert the UTC time to local time.

4. **Function Inputs and Outputs**:  
   Inputs:  
   - `year: int`  
   - `solstice: str` ("june" or "december")  
   - `location: str` (IANA time zone string)

   Output:  
   - `datetime` (with correct time zone)

5. **Compute the (Approximate) UTC Solstice Time**:  
   Create the relevant UTC datetime for the requested solstice.

6. **Convert to Local Time**:  
   Use `astimezone()` with the specified location's time zone.

7. **Entry Point**:  
   The function signature will be:  
   `def get_solstice_datetime(year: int, solstice: str, location: str) -> datetime:`

---

```python
from datetime import datetime, timezone
from zoneinfo import ZoneInfo

def get_solstice_datetime(year: int, solstice: str, location: str) -> datetime:
    """
    Return the date and time of the solstice for a given location and year.
    The value is an *approximate*, based on average UTC solstice times.
    Inputs:
        year: The year as an integer.
        solstice: "june" or "december" (case-insensitive).
        location: IANA time zone string, e.g., "America/New_York".
    Output:
        datetime: The datetime of the solstice in the requested location and year.
    """
    # Step 1: Select solstice UTC datetime (approximate)
    if solstice.lower() == 'june':
        # June solstice typically around June 21 15:00 UTC
        dt_utc = datetime(year, 6, 21, 15, 0, tzinfo=timezone.utc)
    elif solstice.lower() == 'december':
        # December solstice typically around December 21 10:00 UTC
        dt_utc = datetime(year, 12, 21, 10, 0, tzinfo=timezone.utc)
    else:
        raise ValueError("solstice must be 'june' or 'december'")
    
    # Step 2: Convert UTC datetime to local time zone
    try:
        tz = ZoneInfo(location)
    except Exception:
        raise ValueError(f"Invalid location/timezone: '{location}'")
    
    dt_local = dt_utc.astimezone(tz)

    # Step 3: Return the result
    return dt_local

# Entry point: get_solstice_datetime(year: int, solstice: str, location: str) -> datetime
```
