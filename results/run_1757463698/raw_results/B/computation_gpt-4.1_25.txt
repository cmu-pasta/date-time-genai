Let's think step by step to solve this problem.

1. **Import the necessary library**: We must use the `datetime` module, which provides the `datetime` and `timedelta` classes.
2. **Define the function**: The function should accept two `datetime` objects as inputs.
3. **Calculate the absolute difference**: Find the absolute difference between the two `datetime` objects, which gives a `timedelta` object.
4. **Extract total nanoseconds**: The `timedelta` type has attributes `days`, `seconds`, and `microseconds`. To get nanoseconds, convert all these components to nanoseconds:
   - `days` → `days * 24 * 3600 * 1_000_000_000`
   - `seconds` → `seconds * 1_000_000_000`
   - `microseconds` → `microseconds * 1_000`
   - If using Python 3.7+, you can also leverage the `datetime` attribute `.nanosecond` (if present), otherwise, just multiply microseconds as shown.
5. **Return the result**: Return the total difference in nanoseconds as an integer.

```python
from datetime import datetime

def calculate_nanoseconds_difference(dt1: datetime, dt2: datetime) -> int:
    """
    Calculate the absolute difference in nanoseconds between two datetime objects.
    """
    # Step 1: Calculate the absolute difference as a timedelta object
    delta = abs(dt2 - dt1)
    
    # Step 2: Compute the total nanoseconds from timedelta attributes
    total_nanoseconds = (
        delta.days * 24 * 60 * 60 * 1_000_000_000 +
        delta.seconds * 1_000_000_000 +
        delta.microseconds * 1_000
    )
    # Step 3: Return the result as an integer
    return total_nanoseconds

# Entry point: calculate_nanoseconds_difference(dt1: datetime, dt2: datetime) -> int
```
