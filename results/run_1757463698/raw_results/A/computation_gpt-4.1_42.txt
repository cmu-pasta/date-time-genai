Let's think step by step to solve this problem.

1. **Understand the problem**: We need to find the next date (after a given date) that matches a specific recurrence rule. In our example, this means finding the next occurrence of (e.g.) the third Thursday of a month.

2. **Choose the inputs**: We'll need a starting date (`from_date`: `date`), and the recurrence rule:
    - Which weekday? (`weekday`: `integer` where Monday is 0 and Sunday is 6, per `datetime.date.weekday()`)
    - Which occurrence in the month? (`nth`: `integer` for "3rd" means 3)
   
3. **Define the recurrence rule**: We'll look for the nth occurrence of the given weekday in the month, starting from the month and year of the start date, but **the next occurrence, possibly in this or the next month**.

4. **Algorithm outline**:
    - For the month of `from_date`, calculate the nth weekday date.
    - If that date is *after* `from_date`, return it.
    - Otherwise, repeat for the following month (and so on, until we find a match).
   
5. **Implementation details**:
    - For a given year and month: 
        - Find the first date of the month.
        - Calculate the day offset to the desired weekday.
        - Find the nth such weekday in the month.
        - If the date is valid (not exceeding the current month), return that; else, try next month.

Now, the code:

```python
from datetime import date, timedelta

def get_next_nth_weekday(from_date: date, weekday: int, nth: int) -> date:
    """
    Finds the next date after `from_date` that is the nth occurrence
    of the given weekday (where Monday is 0 and Sunday is 6) in a month.

    Parameters:
        from_date (date): The starting date to search from (exclusive).
        weekday (int): The target weekday (Monday=0 ... Sunday=6).
        nth (int): The nth occurrence in a month (e.g., 3 for "third Thursday").

    Returns:
        date: The next date on or after from_date matching the nth occurrence of weekday.
    """
    if nth < 1 or weekday < 0 or weekday > 6:
        raise ValueError("nth must be >=1, weekday must be in 0...6")

    year = from_date.year
    month = from_date.month

    while True:
        # First day of the month
        first_day = date(year, month, 1)
        # What day of week is the first day?
        first_day_weekday = first_day.weekday()
        # Calculate the day difference to the target weekday
        days_until_target = (weekday - first_day_weekday + 7) % 7
        # The date of the first matching weekday in the month
        first_matching = first_day + timedelta(days=days_until_target)
        # The nth matching date:
        nth_matching = first_matching + timedelta(weeks=nth - 1)

        # Check that nth matching is in the same month
        if nth_matching.month == month and nth_matching > from_date:
            return nth_matching

        # Go to the next month
        if month == 12:
            year += 1
            month = 1
        else:
            month += 1

# Entry point: get_next_nth_weekday(from_date: date, weekday: int, nth: int) -> date
```
