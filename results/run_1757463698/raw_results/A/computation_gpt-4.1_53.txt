Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with `datetime` objects and `timedelta`.
2. **Define a function**: We'll create a function that accepts a `datetime` object and an integer interval value (in minutes).
3. **Calculate the rounded value**: We'll round the input `datetime` object **down** to the nearest multiple of the given interval. This means we need to find the number of minutes since midnight, floor it to the nearest interval, and reconstruct the datetime.
4. **Return the result**: The function should return a new `datetime` object, rounded down as specified.

```python
from datetime import datetime, timedelta

def round_down_datetime(dt: datetime, interval_minutes: int) -> datetime:
    # Step 1: Calculate the number of minutes since midnight
    minutes_since_midnight = dt.hour * 60 + dt.minute
    # Step 2: Round down to nearest multiple of interval
    rounded_minutes = (minutes_since_midnight // interval_minutes) * interval_minutes
    # Step 3: Rebuild new datetime with rounded down time
    rounded_dt = dt.replace(hour=rounded_minutes // 60, minute=rounded_minutes % 60, second=0, microsecond=0)
    return rounded_dt

# Entry point: round_down_datetime(dt: datetime, interval_minutes: int) -> datetime
```
