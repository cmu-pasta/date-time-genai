Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We'll use the `datetime` module.
2. **Define the function**: The function should accept a year and a month as integer inputs.
3. **Find the number of days in the month**: To get this, we can:
    - Create a date object for the first day of the next month and for the first day of the current month.
    - Subtract the two dates to get the number of days in the current month.
4. **Iterate through all days in the month**: For each date, check if it's a weekend (Saturday or Sunday).
5. **Count the number of weekends**: Increment a counter for each day that is a Saturday or Sunday.
6. **Return the result**: Return the count as an integer.

```python
from datetime import date, timedelta

def count_weekend_days_in_month(year: int, month: int) -> int:
    # Step 1: Create a date object for the first day of the month
    first_day = date(year, month, 1)
    
    # Step 2: Calculate the first day of the next month
    if month == 12:
        next_month = date(year + 1, 1, 1)
    else:
        next_month = date(year, month + 1, 1)
    
    # Step 3: Find the number of days in the month
    days_in_month = (next_month - first_day).days
    
    # Step 4: Initialize the weekend counter
    weekend_count = 0
    
    # Step 5: Iterate through all the days in the month
    for day_delta in range(days_in_month):
        current_day = first_day + timedelta(days=day_delta)
        # Step 6: Check if the day is Saturday (5) or Sunday (6)
        if current_day.weekday() == 5 or current_day.weekday() == 6:
            weekend_count += 1
    
    # Step 7: Return the result
    return weekend_count

# Entry point: count_weekend_days_in_month(year: int, month: int) -> int
```
