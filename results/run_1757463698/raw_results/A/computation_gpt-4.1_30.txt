Let's think step by step to solve this problem.

1. **Understand the Problem**: We need to return the first day of the fiscal year for a specified organization. 
    - The "first day of the fiscal year" varies between organizations (e.g., some start on January 1, some on April 1, July 1, or October 1). 
    - We will accept a current date and the fiscal year starting month and day as inputs.

2. **Import the Necessary Libraries**: We need to work with the `date` object from Python's `datetime` module.

3. **Define the Function**:
    - Inputs:
        - `current_date`: a `datetime.date` object representing the date for which we want to find the fiscal year's first day.
        - `fiscal_year_start_month`: an `int` (1-12) representing the month when the fiscal year starts (e.g., 4 for April).
        - `fiscal_year_start_day`: an `int` (1-31) representing the day of the starting month (e.g., 1 for the first).
    - Output: 
        - A `datetime.date` object representing the first day of the fiscal year that contains the current_date.

4. **Compute the Fiscal Year Start for the Given Date**:
    - If `current_date` is on or after the fiscal year start in the current calendar year, then the fiscal year start was earlier this year.
    - If `current_date` is before the fiscal year start in the current calendar year, the fiscal year started in the previous year.

5. **Return the Result**: Output the computed `date` object.

```python
from datetime import date

def get_fiscal_year_start(
    current_date: date, 
    fiscal_year_start_month: int, 
    fiscal_year_start_day: int
) -> date:
    """
    Returns the first day of the fiscal year for a given organization.
    
    Args:
        current_date (date): The date for which to find the fiscal year start.
        fiscal_year_start_month (int): The starting month of the fiscal year (1-12).
        fiscal_year_start_day (int): The starting day of the fiscal year (1-31).
        
    Returns:
        date: The first day of the corresponding fiscal year.
    """
    # Step 1: Construct this year's fiscal year start date
    fy_start_this_year = date(
        year=current_date.year,
        month=fiscal_year_start_month,
        day=fiscal_year_start_day
    )
    
    # Step 2: Determine if the fiscal year starts this year or last year
    if current_date >= fy_start_this_year:
        return fy_start_this_year
    else:
        # Fiscal year started last year
        return date(
            year=current_date.year - 1,
            month=fiscal_year_start_month,
            day=fiscal_year_start_day
        )
```
