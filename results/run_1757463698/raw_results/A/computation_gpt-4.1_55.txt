Let's think step by step to solve this problem.

1. **Import the necessary library**: We'll use the `datetime` module from Python's standard library.
2. **Define the function**: The function should accept three inputs: the `year`, the `month`, and the `weekday` (where Monday is 0 and Sunday is 6, as per `datetime.date.weekday()` conventions). All inputs are integers.
3. **Find the last day of the month**: 
    - If the month is December, the last day is December 31.
    - Otherwise, find the first day of the next month and subtract one day to get the last day of the current month.
4. **Iterate backwards from the last day**: Starting at the last day of the month, check the weekday. If it matches the desired weekday, return this date. Otherwise, subtract one day and repeat.
5. **Return the result**: The function will return a `datetime.date` object representing the last occurrence of the specified weekday in that month.

```python
from datetime import date, timedelta

def last_weekday_in_month(year: int, month: int, weekday: int) -> date:
    """
    Returns the date of the last occurrence of a specific weekday in a given month.
    
    Parameters:
    - year: The year as an integer.
    - month: The month as an integer (1-12).
    - weekday: The target weekday as an integer, where Monday is 0 and Sunday is 6.
    
    Returns:
    - A date object representing the last occurrence of the specified weekday in the given month.
    """
    # Step 1: Find the last day of the month
    if month == 12:
        last_day = date(year, 12, 31)
    else:
        last_day = date(year, month + 1, 1) - timedelta(days=1)
    
    # Step 2: Iterate backwards to find the last occurrence of the specified weekday
    days_to_subtract = (last_day.weekday() - weekday) % 7
    target_date = last_day - timedelta(days=days_to_subtract)
    
    # Step 3: Return the target date
    return target_date

# Entry point: last_weekday_in_month(year: int, month: int, weekday: int) -> date
```
