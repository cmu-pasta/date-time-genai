Let's think step by step to solve this problem.

1. **Import the necessary library**: We need the `datetime` module from Python's standard library to work with datetimes.
2. **Define a function**: We'll create a function that accepts two `datetime` objects as input—these represent the start and end times of the meeting.
3. **Calculate the duration**: Subtract the start time from the end time to get a `timedelta` object. 
4. **Convert duration to milliseconds**: Extract the total duration in seconds from the `timedelta`, then multiply by 1000 to get milliseconds. Convert the result to an integer.
5. **Return the result**: Return the computed duration as an integer.

```python
from datetime import datetime

def compute_meeting_duration_milliseconds(start: datetime, end: datetime) -> int:
    # Step 1: Calculate the duration as a timedelta object
    duration = end - start
    
    # Step 2: Convert the duration to milliseconds
    milliseconds = int(duration.total_seconds() * 1000)
    
    # Step 3: Return the duration in milliseconds
    return milliseconds

# Entry point: compute_meeting_duration_milliseconds(start: datetime, end: datetime) -> int
```
