Let's think step by step to solve this problem.

1. **Import the necessary library**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define the function signature**: The function needs to accept the starting date, the number of business days to skip, and must be able to recognize public holidays (which must be passed in for this constraint, but since we cannot accept lists, we will pass a method to get whether a date is a public holiday as a boolean).
3. **Iterate and skip business days/public holidays**: Starting from the given date, increment the date, and for each date, check if it is a business day (Monday-Friday, not Saturday/Sunday), and not a public holiday.
4. **Advance until the requested number of business days/public holidays are skipped**: Continue iterating until the desired count is reached.
5. **Return the resulting date**: Once done, return the new future date as a `date` object.

Note: Due to the restriction, the function cannot take lists for holidays. The cleanest way (given the allowed datatypes) is to pass in either the next holiday date each time or a function that, given a date, returns whether it is a holiday (but we can't accept a function or datastructure as an input). As a workaround, we can support *one* extra public holiday, or the function can only handle weekends, or the function can check only a single holiday date. Here, I'll provide a form taking a single public holiday date as an example.

---

```python
from datetime import date, timedelta

def future_business_date(start_date: date, skip_count: int, public_holiday: date) -> date:
    """
    Returns the future date after skipping a set number of business days and a set public holiday.
    - start_date: The initial date to start counting from (inclusive; if it's a business day/holiday, not counted).
    - skip_count: The number of *business days* to skip.
    - public_holiday: The one public holiday date (if any). If no holiday, pass date.min.
    
    Returns: The computed future date as a 'date' object.
    """
    current_date = start_date
    days_skipped = 0
    while days_skipped < skip_count:
        current_date += timedelta(days=1)
        weekday = current_date.isoweekday()  # Monday=1, Sunday=7
        is_public_holiday = (public_holiday != date.min and public_holiday == current_date)
        if weekday in range(1,6) and not is_public_holiday:
            days_skipped += 1
    return current_date

# Entry point: future_business_date(start_date: date, skip_count: int, public_holiday: date) -> date
```
