Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We will need the `datetime` module from Python's standard library to work with datetime objects.

2. **Define a function**: Create a function, say `average_timestamp`, that will iteratively take in a series of datetime objects as input (note: as per constraint, input and output types must only be from the allowed list, so we take datetimes one by one and call the function repeatedly rather than a list at once).

3. **Accumulate state**: Since we're not allowed to pass lists, the function should accept two parameters: the running sum of seconds (as a float) and the running count (as an integer), along with the next datetime to add. It will update the running sum and count and, once all datetimes have been input, a separate function will compute and return the average as a datetime object.

4. **Compute the average**: Use the accumulated total seconds and count to compute the average timestamp (as a float), then convert it back to a `datetime`.

5. **Return the result**: The final result will be a single `datetime` object representing the average timestamp.

Here is the implementation of the above steps:

```python
from datetime import datetime, timedelta

def add_timestamp_to_accumulator(dt: datetime, epoch: datetime, running_total: float, running_count: int) -> tuple:
    """
    Adds a datetime (dt) to the running total (seconds since epoch) and updates count.
    Returns updated running_total (seconds) and running_count (integer).
    """
    dt_seconds = (dt - epoch).total_seconds()
    return running_total + dt_seconds, running_count + 1

def compute_average_timestamp(epoch: datetime, total_seconds: float, count: int) -> datetime:
    """
    Computes the average timestamp as a datetime object given the epoch, total_seconds, and count.
    """
    if count == 0:
        raise ValueError("Count must be greater than zero to compute an average.")
    average_seconds = total_seconds / count
    return epoch + timedelta(seconds=average_seconds)
```
