Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need `datetime` for working with dates and times, and `zoneinfo` to handle timezones in Python (Python 3.9+).
2. **Define the function signature**: The function should accept a timezone as a `zoneinfo.ZoneInfo` object (standard from Python's datetime).
3. **Obtain the current date in the target timezone**: Get the current date and time in the specified timezone.
4. **Create a datetime for the end of today in that timezone**: That’s “23:59:59.999999” of the current day, in the given timezone.
5. **Convert the end-of-day datetime to an epoch timestamp**: Use `.timestamp()` method on the aware `datetime` object to get the float seconds since epoch.
6. **Return the result as a float**: Return the float value representing the epoch timestamp.

```python
from datetime import datetime, time
from zoneinfo import ZoneInfo

def epoch_end_of_today(tz: ZoneInfo) -> float:
    # Step 1: Get current datetime in the specified timezone
    now = datetime.now(tz)
    
    # Step 2: Construct 'end of today' datetime in the same timezone
    end_of_today = datetime(
        year=now.year,
        month=now.month,
        day=now.day,
        hour=23,
        minute=59,
        second=59,
        microsecond=999999,
        tzinfo=tz
    )
    
    # Step 3: Convert to epoch timestamp (float seconds since epoch)
    epoch_timestamp = end_of_today.timestamp()
    
    # Step 4: Return the epoch timestamp
    return epoch_timestamp

# Entry point: epoch_end_of_today(tz: ZoneInfo) -> float
```
