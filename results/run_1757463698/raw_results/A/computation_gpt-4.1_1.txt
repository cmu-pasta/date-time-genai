Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library, specifically the `date` class to work with dates.
2. **Define a leap year determination helper**: We’ll need a function that determines if a given year is a leap year. According to the Gregorian calendar, a leap year is divisible by 4, but if it is a century year (divisible by 100), it must also be divisible by 400.
3. **Define the main function**: This function will accept a `date` object as input. It will find the next year greater than the date’s year (i.e., strictly greater than the input year) that is a leap year.
4. **Iterate to find the next leap year**: Starting from the year after the input year, check each year using the helper function until a leap year is found.
5. **Return the result**: Return the next leap year as an integer.

Here is the implementation of the above steps in code:

```python
from datetime import date

def is_leap_year(year: int) -> bool:
    # Leap year rule: divisible by 4, but not by 100 unless also divisible by 400
    return (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)

def next_leap_year_after(given_date: date) -> int:
    # Step 1: Start with the year after the input date's year
    next_year = given_date.year + 1

    # Step 2: Iterate forward to find the next leap year
    while not is_leap_year(next_year):
        next_year += 1

    # Step 3: Return the next leap year
    return next_year

# Entry point: next_leap_year_after(given_date: date) -> int
```
