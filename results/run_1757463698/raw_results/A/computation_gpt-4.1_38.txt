Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: Create a function that accepts a `date` object as an argument.
3. **Calculate the weekday**: For a given date, we need to know how many days have passed since the last Sunday. In Python, `date.weekday()` returns 0 for Monday and 6 for Sunday, but we want weeks starting on Sunday, so we need to adjust this.
4. **Find the start of the week (Sunday)**: To do this, calculate how many days to subtract from the current date to get to Sunday. Since `weekday()` returns 6 for Sunday, the number of days to subtract is `(date.weekday() + 1) % 7`.
5. **Return the result**: Subtract the calculated number of days from the given date and return that as the week's start date.

```python
from datetime import date, timedelta

def get_weeks_start_sunday(input_date: date) -> date:
    """
    Returns the start date of the week (Sunday) for a given input_date.
    
    Args:
        input_date (date): The input date.
    
    Returns:
        date: The date corresponding to the week's Sunday.
    """
    # Step 1: Calculate the number of days since the previous Sunday
    days_since_sunday = (input_date.weekday() + 1) % 7  # weekday(): Mon=0,...,Sun=6
    
    # Step 2: Subtract that many days to get the week's start date (Sunday)
    week_start = input_date - timedelta(days=days_since_sunday)
    
    # Step 3: Return the calculated date
    return week_start

# Entry point: get_weeks_start_sunday(input_date: date) -> date
```
