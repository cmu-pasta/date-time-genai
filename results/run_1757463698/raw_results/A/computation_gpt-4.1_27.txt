Let's think step by step to solve this problem.

1. **Import the required module**: We need the `datetime` module from Python's standard library to work with datetime objects.
2. **Define the function**: Create a function that accepts two `datetime` objects as input parameters.
3. **Compute the time difference**: Subtract the earlier datetime from the later one to get a `timedelta` representing their difference.
4. **Calculate half of the difference**: Divide the `timedelta` by 2 to find the midpoint interval.
5. **Find the midpoint datetime**: Add the half-difference to the earlier datetime.
6. **Return the midpoint datetime**: Return the computed `datetime` object representing the midpoint.

```python
from datetime import datetime

def find_midpoint_datetime(dt1: datetime, dt2: datetime) -> datetime:
    # Step 1: Ensure dt1 is the earlier datetime
    if dt1 > dt2:
        dt1, dt2 = dt2, dt1
    
    # Step 2: Calculate the difference between the two datetimes
    delta = dt2 - dt1
    
    # Step 3: Calculate half of the time difference
    half_delta = delta / 2
    
    # Step 4: Add half of the delta to the earlier datetime to get midpoint
    midpoint = dt1 + half_delta
    
    # Step 5: Return the midpoint datetime
    return midpoint

# Entry point: find_midpoint_datetime(dt1: datetime, dt2: datetime) -> datetime
```
