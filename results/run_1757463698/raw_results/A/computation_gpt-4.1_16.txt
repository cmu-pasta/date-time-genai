Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We will use the `datetime` module from Python's standard library.
2. **Define the function**: Create a function that takes two inputs: the reference date (`date` object, not including time) and the target weekday to find (an integer, where Monday is 0 and Sunday is 6).
3. **Compute the previous occurrence**:
    - Determine the weekday of the given date.
    - Calculate the number of days to subtract by comparing the reference weekday to the target weekday and adjusting for cases where the target is after the reference by wrapping around the week.
    - Ensure we do not return the same day if it matches the target; we only consider previous occurrences.
4. **Calculate and return the result**: Subtract the calculated number of days from the input date to get the previous occurrence as a `date` object, and return it.

```python
from datetime import date, timedelta

def previous_weekday(before_date: date, target_weekday: int) -> date:
    """
    Finds the previous occurrence of the specified weekday before the given date.
    :param before_date: The reference date as a date object.
    :param target_weekday: The target weekday as an integer (Monday=0, Sunday=6).
    :return: The previous occurrence of the specified weekday as a date object.
    """
    # Step 1: Determine the current weekday
    current_weekday = before_date.weekday()
    
    # Step 2: Calculate days to subtract; ensure result is not today even if matches
    days_back = (current_weekday - target_weekday) % 7 or 7  # if same day, go 7 days back

    # Step 3: Compute the previous weekday date
    prev_date = before_date - timedelta(days=days_back)
    
    # Step 4: Return the previous weekday date
    return prev_date

# Entry point: previous_weekday(before_date: date, target_weekday: int) -> date
```
