Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We'll use Python's `datetime` module to perform date calculations.
2. **Define a function**: We'll create a function that takes in the current date and the month and day of the holiday.
3. **Determine the next occurrence of the holiday**:
   - Construct a date object for the holiday in the current year.
   - If the holiday for the current year is still upcoming or today, use that date.
   - If the holiday has already passed this year, set the holiday to next year.
4. **Calculate the number of days until the holiday**:
   - Subtract the current date from the next holiday's date.
   - The result is a timedelta; obtain the number of days from it.
5. **Return the result**: Return the difference as an integer.

```python
from datetime import date, timedelta

def days_until_next_holiday(today: date, holiday_month: int, holiday_day: int) -> int:
    # Step 1: Construct the date for the holiday in the current year
    current_year_holiday = date(today.year, holiday_month, holiday_day)
    
    # Step 2: If the holiday for this year has already passed, move to next year
    if today > current_year_holiday:
        next_holiday = date(today.year + 1, holiday_month, holiday_day)
    else:
        next_holiday = current_year_holiday
    
    # Step 3: Calculate the days difference
    days_difference = (next_holiday - today).days
    
    # Step 4: Return the days difference
    return days_difference

# Entry point: days_until_next_holiday(today: date, holiday_month: int, holiday_day: int) -> int
```
