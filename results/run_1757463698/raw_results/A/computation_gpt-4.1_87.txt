Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We'll define a function that takes an integer representing the year as input.
3. **Find the last day of the year**: For any given year, the last day is December 31st.
4. **Get the week number of this date**: Use the `.isocalendar()` method on a `date` object, which returns a `(year, weeknumber, weekday)` tuple. Extract the week number.
5. **Return the result**: Return the week number as an integer.

Here is the implementation of the above steps in code:

```python
from datetime import date

def get_week_number_of_last_day(year: int) -> int:
    # Step 1: Create a date object for December 31st of the given year
    last_day = date(year, 12, 31)
    
    # Step 2: Extract the ISO week number
    week_number = last_day.isocalendar().week
    
    # Step 3: Return the week number as an integer
    return week_number

# Entry point: get_week_number_of_last_day(year: int) -> int
```
