Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with date objects.
2. **Define a function**: We'll create a function that accepts a `date` object as input. This object should be of type `datetime.date`.
3. **Use the `.toordinal()` method**: The `date` object in Python's `datetime` library has a built-in method `.toordinal()` that returns the proleptic Gregorian ordinal of the date, where January 1 of year 1 has ordinal 1.
4. **Return the result**: Return the computed ordinal as an integer.

```python
from datetime import date

def date_to_ordinal(dt: date) -> int:
    # Step 1: Use the .toordinal() method of the date object
    ordinal_number = dt.toordinal()
    
    # Step 2: Return the result as an integer
    return ordinal_number

# Entry point: date_to_ordinal(dt: date) -> int
```
