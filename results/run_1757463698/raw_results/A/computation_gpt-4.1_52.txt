Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We'll use `datetime` from Python's standard library to handle dates.
2. **Define the function interface**: The function should take a year as an `integer`, a month as an `integer`, and a `start_index` as an `integer` (for which Sunday in the month to return). Since we cannot output a list, we will design the function to return the `nth` Sunday as a `date` based on the start_index parameter (e.g., 1 returns the first Sunday of the month, 2 the second, etc.).
3. **Find the first Sunday**: Construct the date for the first day of the month and then calculate the date of the first Sunday.
4. **Find the nth Sunday**: Calculate the nth Sunday in the month by adding 7 * (start_index - 1) days to the first Sunday.
5. **Check if nth Sunday exists in the month**: If the resulting date is still within the requested month, return it; otherwise, return `None`.
6. **Return the result**: The function returns a `date` representing the nth Sunday, or `None` if that Sunday doesn't exist in the month.

```python
from datetime import date, timedelta

def get_nth_sunday(year: int, month: int, n: int) -> date:
    """
    Returns the date of the nth Sunday of the specified month and year.
    If there is no nth Sunday in the month, returns None.
    """
    # Step 1: Find the first day of the month
    first_day = date(year, month, 1)
    
    # Step 2: Calculate the weekday of the first day (Monday=0, Sunday=6)
    first_day_weekday = first_day.weekday()
    
    # Step 3: Calculate days to add to get the first Sunday
    days_until_sunday = (6 - first_day_weekday) % 7
    first_sunday = first_day + timedelta(days=days_until_sunday)
    
    # Step 4: Calculate the nth Sunday
    nth_sunday = first_sunday + timedelta(days=7*(n-1))
    
    # Step 5: Validate if nth_sunday is still within the same month
    if nth_sunday.month == month:
        return nth_sunday
    else:
        return None

# Entry point: get_nth_sunday(year: int, month: int, n: int) -> date
```
