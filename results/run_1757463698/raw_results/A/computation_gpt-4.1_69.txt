Let's think step by step to solve this problem.

1. **Import necessary libraries**: We'll need `datetime` and `zoneinfo` from the Python standard library. `datetime` handles date/time objects, and `zoneinfo` provides time zone information (available in Python 3.9+).
2. **Define a function**: The function will accept a `datetime` object (representing the date/time we want to compute the offset for) and a `zoneinfo.ZoneInfo` object (representing the desired time zone).
3. **Attach timezone to datetime**: Ensure the supplied `datetime` is timezone-aware for accurate UTC offset calculation. 
   - If not already timezone-aware, localize using the provided time zone.
4. **Get UTC offset**: Use the `utcoffset()` method on the timezone-aware datetime object. This returns a `timedelta` representing the offset from UTC.
5. **Extract hours and minutes**: Parse the total seconds of the UTC offset to get hours and minutes (as integers, handling sign for west/east of UTC).
6. **Return the result**: Output the offset as two integers: hours and minutes.

```python
from datetime import datetime, timedelta
from zoneinfo import ZoneInfo

def get_utc_offset_hours_minutes(dt: datetime, tz: ZoneInfo) -> int:
    # Step 1: Ensure the datetime is timezone-aware using the provided time zone
    if dt.tzinfo is None:
        dt = dt.replace(tzinfo=tz)
    else:
        dt = dt.astimezone(tz)
    
    # Step 2: Get the UTC offset as a timedelta
    offset: timedelta = dt.utcoffset()
    if offset is None:
        # This should not happen with valid zones and dates
        return 0  # Or raise an error depending on requirements

    # Step 3: Extract total offset in seconds
    total_seconds = offset.total_seconds()
    
    # Step 4: Calculate hours and minutes, preserving sign
    hours = int(total_seconds // 3600)
    minutes = int((abs(total_seconds) % 3600) // 60)
    
    # Step 5: Combine hours and minutes into a single integer, e.g., +5:30 => 530, -4:00 => -400
    sign = 1 if hours >= 0 else -1
    offset_int = sign * (abs(hours) * 100 + minutes)
    
    # Step 6: Return the offset integer
    return offset_int

# Entry point: get_utc_offset_hours_minutes(dt: datetime, tz: ZoneInfo) -> int
```
