Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We'll use the `datetime` module from Python's standard library to handle datetime objects and perform the computation.
2. **Define the function**: We'll create a function that accepts two `datetime` objects as inputs.
3. **Compute the difference**: Subtract one datetime from the other to obtain a `timedelta` object.
4. **Extract microseconds**: The total difference in microseconds can be found by multiplying the total number of seconds (including fractional seconds) by 1,000,000 and converting the result to an integer.
5. **Return the result**: Output the absolute number of microseconds as an integer as required.

```python
from datetime import datetime

def calculate_microseconds_difference(dt1: datetime, dt2: datetime) -> int:
    # Step 1: Subtract the two datetime objects to get a timedelta
    delta = dt2 - dt1
    # Step 2: Get the total difference in seconds (including fractions)
    total_seconds = abs(delta.total_seconds())
    # Step 3: Compute the total microseconds
    microseconds = int(total_seconds * 1_000_000)
    # Step 4: Return the result
    return microseconds

# Entry point: calculate_microseconds_difference(dt1: datetime, dt2: datetime) -> int
```
