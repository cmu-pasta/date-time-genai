Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library. RFC 2822 formatting can be achieved with `email.utils.format_datetime`, but since we should stick to `datetime` formatting (per instructions), we'll manually format according to RFC 2822. Optionally, use `zoneinfo` if you need timezone support.
2. **Define a function**: We will create a function that accepts a timestamp as input (a float or integer representing seconds since the Unix epoch).
3. **Convert the timestamp to a datetime**: Use `datetime.fromtimestamp` to get a datetime object. For RFC 2822, the time should be in local time (for UTC, explicitly set the `tzinfo`).
4. **Format datetime in RFC 2822 format**: Format as `"Day, DD Mon YYYY HH:MM:SS +/-ZZZZ"` using `strftime` (e.g., "Fri, 21 Nov 1997 09:55:06 -0600").
5. **Return the formatted string**: Output the formatted string.

```python
from datetime import datetime, timezone

def timestamp_to_rfc2822(ts: float) -> str:
    # Step 1: Convert the timestamp to a datetime object in UTC
    dt = datetime.fromtimestamp(ts, tz=timezone.utc)
    
    # Step 2: Format the datetime as per RFC 2822
    # Example: "Fri, 21 Nov 1997 09:55:06 +0000"
    rfc2822_str = dt.strftime('%a, %d %b %Y %H:%M:%S %z')
    
    # Step 3: Return the formatted string
    return rfc2822_str

# Entry point: timestamp_to_rfc2822(ts: float) -> str
```
