Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We'll use the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We'll implement a function that takes two arguments—a starting date (`datetime.date` object) and a target month and day (as integers).
3. **Generate the next matching date**: From the starting date, we'll search for the next date that matches the provided month (`MM`) and day (`DD`).  
    - If the month and day have already passed in the current year (i.e., the date in this year would come before the starting date), we consider the matching date in the next year.
    - If the matching MM-DD in the current year is equal to or after the start date, we return that date.
    - We must handle the edge case where MM-DD might not exist in some years (e.g., Feb 29 in non-leap years), so we'll need to check for valid dates.
4. **Return the result**: The function will return the next date (as a `datetime.date` object) with the matching MM-DD pattern.

Here's the implementation:

```python
from datetime import date, timedelta

def find_next_matching_mmdd(start_date: date, month: int, day: int) -> date:
    # Step 1: Try to create the candidate date in the current year
    year = start_date.year
    while True:
        try:
            candidate = date(year, month, day)
            if candidate >= start_date:
                return candidate
            year += 1
        except ValueError:
            # Invalid date for this year (e.g., Feb 29 in non-leap years)
            year += 1

# Entry point: find_next_matching_mmdd(start_date: date, month: int, day: int) -> date
```
