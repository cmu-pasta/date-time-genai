Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` and `zoneinfo` modules from Python's standard library to work with time zones.
2. **Define a function**: We'll create a function that accepts a timezone-aware `datetime` object, a source time zone, and a target time zone—all as appropriate types from the list.
3. **Localize datetime if necessary**: If the input datetime is naive (i.e., has no time zone information), we first assign it the source time zone.
4. **Convert to the target timezone**: Use the `astimezone` method on the datetime object to convert it to the desired time zone. This will handle any daylight saving time transitions automatically.
5. **Return the converted datetime**: Output the converted datetime object (still timezone-aware).

```python
from datetime import datetime
from zoneinfo import ZoneInfo

def convert_datetime_timezone(dt: datetime, source_tz: ZoneInfo, target_tz: ZoneInfo) -> datetime:
    # Step 1: Ensure the datetime is timezone-aware in source_tz
    if dt.tzinfo is None:
        dt = dt.replace(tzinfo=source_tz)
    else:
        # To ensure correct conversion, bring to the source timezone first
        dt = dt.astimezone(source_tz)
    # Step 2: Convert to the target timezone (handles DST automatically)
    converted_dt = dt.astimezone(target_tz)
    # Step 3: Return the converted datetime
    return converted_dt

# Entry point: convert_datetime_timezone(dt: datetime, source_tz: ZoneInfo, target_tz: ZoneInfo) -> datetime
```
