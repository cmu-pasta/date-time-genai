Let's think step by step to solve this problem.

1. **Import the necessary library**: We need the `datetime` module from Python's standard library to work with date and time objects.
2. **Define a function**: We'll create a function that takes two `datetime` objects: the current time and the future event's time.
3. **Calculate the time difference**: Subtract the current time from the future time to get a `timedelta` object representing the time remaining.
4. **Convert the remaining time to weeks and days**: We can obtain the total number of days from the `timedelta`, divide by 7 to get full weeks and use modulus to get the remaining days.
5. **Return the result**: The function should return the number of weeks and number of days remaining as two integer values.

```python
from datetime import datetime

def time_until_event_in_weeks_days(now: datetime, future_event: datetime) -> int:
    """
    Calculate the time remaining until a future event in weeks and days.
    
    Returns: 
      The number of full weeks and remaining days as two separate integer outputs.
      To adhere to allowed output types, weeks are returned first, then days.
    """
    if future_event < now:
        # If the event is in the past, no time remaining
        weeks = 0
        days = 0
    else:
        delta = future_event - now
        total_days = delta.days
        weeks = total_days // 7
        days = total_days % 7
    # Print the result to adhere to the allowed output types, return weeks first then days
    print(weeks)
    print(days)
    return weeks  # Return value by specification; actual output seen in prints
```
