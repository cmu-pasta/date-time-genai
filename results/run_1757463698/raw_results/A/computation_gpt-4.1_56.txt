Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from the Python standard library.
2. **Define the function signature**: The function will accept as input a single `datetime` representing the current time and a series of scheduled meeting `time` objects (one per call, since lists/tuples/sets/dicts are not allowed as inputs/outputs).
3. **Process inputs over multiple calls**: Since we can't accept a list, we will design a mechanism whereby the user calls the function repeatedly for each scheduled meeting, and the function keeps track of the smallest (next) upcoming meeting across calls. This can be done using a closure or by storing state via a global (typically undesirable, but sometimes necessary for interface constraints like in this case).
4. **Compare times**: For each meeting time provided, compute the `datetime` when the meeting will next occur (either today if it's later than now, or tomorrow otherwise).
5. **Calculate the duration**: Subtract the current datetime from the next scheduled meeting's datetime to get a `timedelta`.
6. **Return the duration until the next meeting**: After all times have been checked (for example, when an explicit finalization call is made), return the minimum duration as a `timedelta`, which represents the time until the next meeting.

Below is the implementation:

```python
from datetime import datetime, time, timedelta

# A helper function to compute the next occurrence of a time from a given datetime
def _next_meeting_datetime(current_dt: datetime, meeting_t: time) -> datetime:
    meeting_today = current_dt.replace(hour=meeting_t.hour, minute=meeting_t.minute, second=meeting_t.second, microsecond=meeting_t.microsecond)
    if meeting_today > current_dt:
        return meeting_today
    else:
        # Meeting time has passed today, so schedule for next day
        return meeting_today + timedelta(days=1)

# State initialization for storing the minimum timedelta found
_min_duration = None

def add_scheduled_meeting_time(current_dt: datetime, meeting_t: time) -> None:
    """
    Processes a single meeting time and updates the minimum duration until a next meeting.

    Input:
        current_dt: datetime  (current date and time)
        meeting_t: time       (scheduled meeting time)
    Output:
        None
    """
    global _min_duration
    meeting_dt = _next_meeting_datetime(current_dt, meeting_t)
    duration = meeting_dt - current_dt
    if (_min_duration is None) or (duration < _min_duration):
        _min_duration = duration

def get_next_meeting_duration() -> timedelta:
    """
    Returns the duration until the next scheduled meeting, as a timedelta.

    Input:
        None
    Output:
        timedelta   (duration until next meeting)
    """
    global _min_duration
    return _min_duration

def reset_next_meeting_calculator() -> None:
    """
    Resets the calculator state, so it can be reused for another set of meetings.

    Input:
        None
    Output:
        None
    """
    global _min_duration
    _min_duration = None

# Entry point: add_scheduled_meeting_time(current_dt: datetime, meeting_t: time) -> None
# Usage:
#     1. Call reset_next_meeting_calculator()
#     2. For each scheduled meeting, call add_scheduled_meeting_time(current_dt, meeting_t)
#     3. After all meetings are entered, call get_next_meeting_duration() -> timedelta
```
