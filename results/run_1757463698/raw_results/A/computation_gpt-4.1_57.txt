Let's think step by step to solve this problem.

1. **Understand the Problem**:  
   We want to compute the duration of daylight (in hours/minutes) for a given date and location (latitude and longitude).

2. **Explore datetime Capabilities**:  
   Python’s standard `datetime` library does not include solar position or sunrise/sunset calculations. However, we can compute a basic astronomical sunrise and sunset time for a given date and location using mathematical formulas (e.g., the sunrise equation). We'll use only standard types and no external libraries.

3. **Outline Inputs and Outputs**:
   - Inputs:  
     - `date`: a `datetime.date` object  
     - `latitude`: a `float` (degrees north, positive for north, negative for south)  
     - `longitude`: a `float` (degrees east, positive for east, negative for west)
   - Output:  
     - `timedelta` representing daylight duration

4. **Sunrise Equation**:  
   We'll follow the standard sunrise equation, making reasonable approximations for civil calculations.

5. **Implement the Algorithm**:
   - Compute the day of year
   - Calculate the declination of the sun
   - Calculate hour angle
   - Compute sunrise and sunset in UTC (assuming local mean solar time, not accounting for time zone or altitude)
   - Compute difference

```python
from datetime import date, timedelta
import math

def calculate_daylight_duration(day: date, latitude: float, longitude: float) -> timedelta:
    # Step 1: Compute day of the year
    n = day.timetuple().tm_yday

    # Step 2: Calculate the declination of the sun
    # δ = 23.44° * sin(360°/365 * (n - 81))
    decl = math.radians(23.44) * math.sin(math.radians(360 / 365 * (n - 81)))

    # Step 3: Calculate hour angle for sunrise/sunset
    # cos(H) = -tan(φ) * tan(δ)
    lat_rad = math.radians(latitude)
    try:
        cosH = -math.tan(lat_rad) * math.tan(decl)
    except:
        # At the poles, tangent can go out of bounds. Clamp.
        cosH = 1.0 if latitude > 0 else -1.0

    # Clamp cosH to the range [-1, 1]
    cosH = max(min(cosH, 1), -1)

    # Step 4: Compute hour angle in radians
    # When cosH > 1: Polar night (no sunrise)
    # When cosH < -1: Midnight sun (no sunset)
    if cosH >= 1:
        # No sunrise, sun does not rise
        daylight_hours = 0.0
    elif cosH <= -1:
        # No sunset, sun does not set
        daylight_hours = 24.0
    else:
        H = math.acos(cosH)
        daylight_hours = (2 * H * 24) / (2 * math.pi)

    # Step 5: Return timedelta for daylight duration
    return timedelta(hours=daylight_hours)

# Entry point: calculate_daylight_duration(day: date, latitude: float, longitude: float) -> timedelta
```
