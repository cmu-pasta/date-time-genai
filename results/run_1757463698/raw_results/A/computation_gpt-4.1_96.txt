Let's think step by step to solve this problem.

1. **Understand the meaning of "standard time offset"**: The standard time offset for a timezone refers to the UTC offset when daylight saving time (DST) is *not in effect*.
2. **Select an approach**: In Python's standard library, the `zoneinfo` module (Python 3.9+) represents time zones. To get the standard offset, we need a datetime that falls outside any DST period, since simply getting the offset for "now" might be incorrect if DST is in effect.
3. **Choose a date in standard time**: January 1st is almost always in standard time for any timezone that observes DST (since DST is generally in northern hemisphere late spring → early fall, and in southern hemisphere, transitions rarely include January 1st).
4. **Implement the function**: The function will accept a `zoneinfo.ZoneInfo` object and return the standard (non-DST) time offset as a `timedelta`.
5. **Perform the computation**: Create a `datetime` (e.g., January 1, 2020) in the given zone, and access its `.utcoffset()`.
6. **Return the result**: Output the UTC offset as a `timedelta`.

```python
from datetime import datetime, timedelta
from zoneinfo import ZoneInfo

def get_standard_utc_offset(tz: ZoneInfo) -> timedelta:
    # Step 1: Choose a date likely to be in standard time (not affected by DST). January 1st is typically a safe choice.
    standard_date = datetime(2020, 1, 1, 12, 0, 0, tzinfo=tz)  # Noon to avoid ambiguous transition times
    
    # Step 2: Get the UTC offset for this date, which should reflect standard time offset
    standard_offset = standard_date.utcoffset()
    
    # Step 3: Return the offset as a timedelta
    return standard_offset

# Entry point: get_standard_utc_offset(tz: ZoneInfo) -> timedelta
```
