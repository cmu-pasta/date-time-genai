Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `datetime` class from Python's standard `datetime` module to work with dates.
2.  **Define a function**: Create a function, `calculate_age_in_total_days`, that accepts two `datetime` objects: `birth_date` and `reference_date`.
3.  **Calculate the difference**: Subtract the `birth_date` from the `reference_date`. This operation results in a `timedelta` object.
4.  **Extract total days**: Access the `days` attribute of the `timedelta` object to get the difference in days as an integer.
5.  **Handle pre-birth scenario**: Age cannot be negative. If the `reference_date` is before the `birth_date`, the calculated difference will be negative. In such a case, the age should be considered 0 days.
6.  **Return the result**: Return the calculated non-negative number of days as an integer.

```python
from datetime import datetime

def calculate_age_in_total_days(birth_date: datetime, reference_date: datetime) -> int:
    # Step 1: Calculate the difference between the reference_date and the birth_date
    time_difference = reference_date - birth_date
    
    # Step 2: Extract the number of days from the timedelta object
    total_days = time_difference.days
    
    # Step 3: Ensure age is not negative. If reference_date is before birth_date, age is 0.
    return max(0, total_days)

# Entry point: calculate_age_in_total_days(birth_date: datetime, reference_date: datetime) -> int
```
