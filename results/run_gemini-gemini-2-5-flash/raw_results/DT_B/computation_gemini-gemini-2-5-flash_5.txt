Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `datetime` and `timedelta` classes from Python's standard `datetime` module to work with dates and time differences.
2.  **Define a function**: Create a function that accepts the `year` and `month` as integer inputs.
3.  **Construct the first day of the month**: Create a `datetime` object representing the first day of the given `year` and `month`.
4.  **Determine the weekday of the first day**: Use the `weekday()` method of the `datetime` object. This method returns an integer where Monday is 0 and Sunday is 6.
5.  **Calculate the number of days to add to reach the first Monday**:
    *   If the first day of the month is already a Monday (weekday 0), we add 0 days.
    *   If it's not a Monday, we calculate how many days forward we need to go to reach the next Monday. The number of days to add can be calculated as `(7 - first_day_of_month.weekday()) % 7`. This formula correctly handles all cases, including when the first day is a Monday (adds 0 days) and when it's a Sunday (adds 1 day).
6.  **Add the calculated days to the first day of the month**: Use a `timedelta` object to add the required number of days to our initial `datetime` object.
7.  **Return the resulting datetime object**: This object will represent the first Monday of the specified month and year.

```python
from datetime import datetime, timedelta

def find_first_monday(year: int, month: int) -> datetime:
    # Step 3: Construct the first day of the month
    first_day_of_month = datetime(year, month, 1)
    
    # Step 4 & 5: Determine the weekday of the first day and calculate days to add
    # weekday() returns 0 for Monday, 1 for Tuesday, ..., 6 for Sunday
    # We want to find the next day where weekday is 0 (Monday).
    # If first_day_of_month.weekday() is 0 (Monday), days_to_add will be (7 - 0) % 7 = 0
    # If first_day_of_month.weekday() is 1 (Tuesday), days_to_add will be (7 - 1) % 7 = 6
    # If first_day_of_month.weekday() is 6 (Sunday), days_to_add will be (7 - 6) % 7 = 1
    days_to_add = (7 - first_day_of_month.weekday()) % 7
    
    # Step 6: Add the calculated days to the first day of the month
    first_monday = first_day_of_month + timedelta(days=days_to_add)
    
    # Step 7: Return the resulting datetime object
    return first_monday

# Entry point: find_first_monday(year: int, month: int) -> datetime
```
