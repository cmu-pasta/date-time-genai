Let's think step by step to solve this problem.

1.  **Import necessary libraries**: We need the `datetime` class from the `datetime` module to handle dates and `timedelta` to perform date arithmetic.
2.  **Define a function**: Create a function that accepts a `datetime` object as input, representing the given date.
3.  **Determine the first day of the next month**: To find the last day of the current month, a robust approach is to first find the first day of the *next* month.
    *   If the input date's month is December (12), the next month will be January (1) of the next year.
    *   Otherwise, the next month is simply the current month plus one, in the same year.
    *   We create a new `datetime` object for the first day (day=1) of this calculated next month.
4.  **Subtract one day**: Subtract one day from the first day of the next month using `timedelta(days=1)`. This will yield the last day of the original month.
5.  **Return the result**: The function should return the calculated last day as a `datetime` object.

```python
from datetime import datetime, timedelta

def find_last_day_of_month(dt: datetime) -> datetime:
    # Step 1 & 2: Determine the year and month for the first day of the next month
    if dt.month == 12:
        # If it's December, the next month is January of the next year
        next_month_year = dt.year + 1
        next_month = 1
    else:
        # Otherwise, the next month is simply the current month + 1 in the same year
        next_month_year = dt.year
        next_month = dt.month + 1
    
    # Step 3: Create a datetime object for the first day of the next month
    # We set the day to 1 and the time components to 0 to ensure consistency.
    first_day_of_next_month = datetime(next_month_year, next_month, 1)
    
    # Step 4: Subtract one day to get the last day of the current month
    last_day = first_day_of_next_month - timedelta(days=1)
    
    # Step 5: Return the result as a datetime object
    return last_day

# Entry point: find_last_day_of_month(dt: datetime) -> datetime
```
