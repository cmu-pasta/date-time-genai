2.  **Choose an Algorithm**: A widely accepted algorithm for calculating Easter Sunday (Gregorian calendar) is the Meeus/Jones/Butcher algorithm, also sometimes referred to as the Gaussian algorithm for Easter. This algorithm involves a series of integer arithmetic operations based on the input year.
3.  **Identify Inputs and Outputs**: The input will be an `integer` representing the year. The output should be a `datetime.date` object, as Easter Sunday is a specific date.

```python
from datetime import date

def find_easter_sunday(year: int) -> date:
    # Meeus/Jones/Butcher algorithm for calculating Easter Sunday (Gregorian calendar)
    # This algorithm is purely integer arithmetic.

    a = year % 19
    b = year // 100
    c = year % 100
    d = b // 4
    e = b % 4
    f = (b + 8) // 25
    g = (b - f + 1) // 3
    h = (19 * a + b - d - g + 15) % 30
    i = c // 4
    k = c % 4
    l = (32 + 2 * e + 2 * i - h - k) % 7
    m = (a + 11 * h + 22 * l) // 451

    # Calculate month (3 for March, 4 for April)
    month = (h + l - 7 * m + 114) // 31
    # Calculate day
    day = ((h + l - 7 * m + 114) % 31) + 1

    # Construct and return the date object
    return date(year, month, day)
```
