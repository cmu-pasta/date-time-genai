Let's think step by step to solve this problem.

1.  **Import necessary libraries**: We will need the `datetime` class for date manipulation and `timedelta` to subtract days, both from the `datetime` module.
2.  **Define a function**: Create a function that accepts a `datetime` object representing any day within the target month.
3.  **Determine the last day of the month**: To find the last day of the month for the given `input_date`, we can first determine the first day of the *next* month. If the current month is December, the next month is January of the next year. Otherwise, it's simply the next month in the same year. Once we have the first day of the next month, subtracting one day will give us the last day of the current month.
4.  **Iterate backward to find the last business day**: Starting from the `last_day_of_month`, check its weekday. Python's `weekday()` method returns 0 for Monday and 6 for Sunday. If the day is a Saturday (5) or Sunday (6), subtract one day and repeat the check until a weekday (Monday-Friday) is found.
5.  **Return the result**: The found `datetime` object will be the last business day of the month.

```python
from datetime import datetime, timedelta

def find_last_business_day_of_month(input_date: datetime) -> datetime:
    # Step 3: Determine the last day of the given month.
    # First, find the year and month from the input_date.
    year = input_date.year
    month = input_date.month

    # Calculate the first day of the next month
    if month == 12:
        # If the current month is December, the next month is January of the next year.
        first_day_of_next_month = datetime(year + 1, 1, 1)
    else:
        # Otherwise, it's the next month in the same year.
        first_day_of_next_month = datetime(year, month + 1, 1)

    # Subtract one day from the first day of the next month to get the last day of the current month.
    last_day_of_month = first_day_of_next_month - timedelta(days=1)

    # Step 4: Iterate backward from the last day until a business day is found.
    current_day = last_day_of_month
    
    # A business day is Monday (0) through Friday (4).
    # We need to skip Saturday (5) and Sunday (6).
    while current_day.weekday() >= 5: # 5 is Saturday, 6 is Sunday
        current_day -= timedelta(days=1)
    
    # Step 5: Return the found business day.
    return current_day

# Entry point: find_last_business_day_of_month(input_date: datetime) -> datetime
```
