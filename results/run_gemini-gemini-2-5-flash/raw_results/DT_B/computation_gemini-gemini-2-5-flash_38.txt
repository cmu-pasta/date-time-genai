Let's think step by step to solve this problem.

1.  **Import necessary libraries**: We will need `datetime` and `timedelta` from the `datetime` module to work with dates and perform date arithmetic.
2.  **Define the function signature**: Create a function that accepts a `datetime` object representing the starting date. It should return a `datetime` object.
3.  **Initialize the search date**: The problem asks for the *next* occurrence *after* the given date. Therefore, we should start checking from the day immediately following the input `start_date`.
4.  **Iterate to find Friday the 13th**: We will use a `while True` loop to continuously check dates until the condition is met.
    a. Inside the loop, check if the `current_date` is the 13th day of the month (`current_date.day == 13`).
    b. Simultaneously, check if the `current_date` is a Friday (`current_date.weekday() == 4`, where Monday is 0 and Friday is 4).
    c. If both conditions are true, we have found the next Friday the 13th. Return this `current_date`.
    d. If the conditions are not met, increment the `current_date` by one day using `timedelta(days=1)` and continue to the next iteration of the loop.

```python
from datetime import datetime, timedelta

def find_next_friday_the_13th(start_date: datetime) -> datetime:
    # Step 1: Initialize the search date to the day after the given start_date.
    # This ensures we find the *next* occurrence after the input date.
    current_date = start_date + timedelta(days=1)

    # Step 2: Loop indefinitely until a Friday the 13th is found.
    while True:
        # Step 3: Check if the current_date is the 13th day of the month AND a Friday.
        # datetime.weekday() returns 0 for Monday, 1 for Tuesday, ..., 4 for Friday, ..., 6 for Sunday.
        if current_date.day == 13 and current_date.weekday() == 4:
            # Step 4: If both conditions are met, this is the next Friday the 13th.
            # Return the datetime object.
            return current_date
        
        # Step 5: If not, increment the current_date by one day and continue the loop.
        current_date += timedelta(days=1)
```
