Let's think step by step to solve this problem.

1.  **Import necessary types**: We need `datetime` and `timedelta` from the `datetime` module to work with dates and iterate day by day.
2.  **Define the function `calculate_weekends_between_dates`**: This function will take two `datetime` objects, `dt1` and `dt2`, as input. The goal is to return an integer representing the total number of Saturdays and Sundays.
3.  **Normalize and order dates**: To simplify iteration, we will first extract only the date component from the input `datetime` objects. Then, we ensure that `start_date` is chronologically before or the same as `end_date` by swapping them if necessary. This makes the iteration logic simpler and covers cases where the input dates are not in chronological order.
4.  **Initialize a counter**: A variable `weekend_count` will be initialized to 0. This variable will store the cumulative count of weekend days.
5.  **Iterate through each day**: We will use a `while` loop starting from `start_date` and continuing as long as the `current_date` is less than or equal to `end_date`.
6.  **Check for weekend**: Inside the loop, for each `current_date`, we use the `weekday()` method. `weekday()` returns an integer where Monday is 0 and Sunday is 6. Therefore, Saturday is 5 and Sunday is 6. If `current_date.weekday()` is either 5 or 6, we increment `weekend_count`.
7.  **Advance to the next day**: After checking the `current_date`, we advance to the next day by adding `timedelta(days=1)` to `current_date`.
8.  **Return the total count**: Once the loop finishes, `weekend_count` will hold the total number of Saturdays and Sundays between and including the two input dates. This value is then returned.

```python
from datetime import datetime, timedelta

def calculate_weekends_between_dates(dt1: datetime, dt2: datetime) -> int:
    # Step 1: Normalize dates to only their date part and ensure start_date <= end_date
    date1 = dt1.date()
    date2 = dt2.date()

    if date1 <= date2:
        start_date = date1
        end_date = date2
    else:
        start_date = date2
        end_date = date1

    # Step 2: Initialize a counter for weekend days
    weekend_count = 0
    
    # Step 3: Iterate through each day from start_date to end_date (inclusive)
    current_date = start_date
    while current_date <= end_date:
        # Step 4: Check if the current day is a Saturday (5) or Sunday (6)
        if current_date.weekday() == 5 or current_date.weekday() == 6:
            weekend_count += 1
        
        # Step 5: Move to the next day
        current_date += timedelta(days=1)
        
    # Step 6: Return the total count of weekend days
    return weekend_count
```
