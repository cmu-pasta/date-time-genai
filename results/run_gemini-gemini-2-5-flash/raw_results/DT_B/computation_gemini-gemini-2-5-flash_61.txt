Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with date objects.
2.  **Define a function**: Create a function that accepts a `datetime` object as input, representing the date for which we want to find the day number.
3.  **Determine the day of the week**: The `datetime` object has a built-in method, `isoweekday()`, which returns the day of the week as an integer, where Monday is 1 and Sunday is 7. This directly matches the desired output format.
4.  **Return the result**: The function will return this integer.

```python
from datetime import datetime

def get_day_of_week_number(dt: datetime) -> int:
    # Step 1: Use the isoweekday() method of the datetime object
    # This method returns the day of the week as an integer, where Monday is 1 and Sunday is 7.
    day_number = dt.isoweekday()
    
    # Step 2: Return the result
    return day_number

# Entry point: get_day_of_week_number(dt: datetime) -> int
```
