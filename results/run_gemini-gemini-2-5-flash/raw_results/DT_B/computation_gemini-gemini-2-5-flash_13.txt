Let's think step by step to solve this problem.

1.  **Import the necessary library**: We need the `datetime` class from Python's standard `datetime` module to work with date objects.
2.  **Define a function**: Create a function that accepts a single `datetime` object as input, representing the date for which we want to determine the quarter.
3.  **Extract the month**: Access the `month` attribute of the input `datetime` object.
4.  **Calculate the quarter**: Use integer division to map the month number (1-12) to the corresponding quarter (1-4). The formula `(month - 1) // 3 + 1` can achieve this effectively.
    *   Months 1-3 map to Quarter 1.
    *   Months 4-6 map to Quarter 2.
    *   Months 7-9 map to Quarter 3.
    *   Months 10-12 map to Quarter 4.
5.  **Return the result**: The calculated quarter will be an integer between 1 and 4.

```python
from datetime import datetime

def get_quarter_of_year(dt: datetime) -> int:
    # Step 1: Extract the month from the datetime object
    month = dt.month
    
    # Step 2: Calculate the quarter based on the month
    # Quarters are typically:
    # Q1: Jan-Mar (1-3)
    # Q2: Apr-Jun (4-6)
    # Q3: Jul-Sep (7-9)
    # Q4: Oct-Dec (10-12)
    # The formula (month - 1) // 3 + 1 correctly maps these ranges.
    quarter = (month - 1) // 3 + 1
    
    # Step 3: Return the quarter as an integer
    return quarter

# Entry point: get_quarter_of_year(dt: datetime) -> int
```
