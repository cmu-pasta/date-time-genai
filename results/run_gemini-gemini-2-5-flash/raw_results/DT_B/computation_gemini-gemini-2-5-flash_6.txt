Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2.  **Define a function**: We will create a function that accepts two `datetime` objects, `start_date` and `end_date`. The function will be designed to calculate the age components.
3.  **Handle date order**: Ensure `start_date` is chronologically before `end_date`. If not, swap them to simplify calculations and ensure a non-negative age.
4.  **Calculate years**: Determine the initial difference in years. Adjust the `start_date` by this number of years and check if it has passed the `end_date`. If so, decrement the years.
5.  **Calculate months**: With the years adjusted, determine the difference in months. Adjust the `start_date` by this number of months and check if it has passed the `end_date`. If so, decrement the months.
6.  **Calculate days**: With years and months adjusted, calculate the remaining difference in days.
7.  **Return the result**: The problem asks to calculate age in years, months, and days. Due to the constraint against complex data types (like tuples) and the need to return three distinct integer values, we will return the age in years as the primary result. A more complete solution would typically return all three components in a structured way, but adhering to the constraints, we focus on the years component as an integer.

```python
from datetime import datetime

def calculate_age_in_years(start_date: datetime, end_date: datetime) -> int:
    """
    Calculates the age in full years between two datetime objects.
    Adheres to the constraint of returning a single integer.
    """
    # Ensure start_date is earlier than or equal to end_date
    if start_date > end_date:
        start_date, end_date = end_date, start_date

    # Calculate initial year difference
    years = end_date.year - start_date.year

    # Adjust if the end_date's month/day is before the start_date's month/day
    # in the calculated year range.
    if (end_date.month < start_date.month) or \
       (end_date.month == start_date.month and end_date.day < start_date.day):
        years -= 1
        
    # Return the age in full years as an integer
    return years
```
