Let's think step by step to solve this problem.
1.  **Import the necessary libraries**: We need the `datetime` and `timedelta` objects from Python's standard `datetime` module to work with dates and time differences.
2.  **Define a function**: Create a function that accepts two `datetime` objects, `dt1` and `dt2`, as input.
3.  **Calculate the total time difference**: Subtract the first `datetime` object (`dt1`) from the second `datetime` object (`dt2`) to get a `timedelta` representing the duration between them.
4.  **Calculate half the time difference**: Divide the total `timedelta` by 2 to find the duration from one end to the midpoint.
5.  **Add half the difference to the start datetime**: Add this calculated half `timedelta` to the first `datetime` object (`dt1`) to determine the exact midpoint `datetime`.
6.  **Return the midpoint datetime**: The function should return this newly calculated `datetime` object.

```python
from datetime import datetime, timedelta

def find_midpoint_datetime(dt1: datetime, dt2: datetime) -> datetime:
    # Step 1: Calculate the total time difference between the two datetimes.
    # The order of subtraction determines the sign of the timedelta,
    # but the subsequent addition will correctly find the midpoint regardless.
    total_difference: timedelta = dt2 - dt1
    
    # Step 2: Calculate half of the total time difference.
    half_difference: timedelta = total_difference / 2
    
    # Step 3: Add this half difference to the first datetime to find the midpoint.
    midpoint_dt: datetime = dt1 + half_difference
    
    # Step 4: Return the calculated midpoint datetime.
    return midpoint_dt
```
