Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with timestamps.
2.  **Define a function**: We will create a function that accepts two `datetime` objects as input, representing the two timestamps.
3.  **Calculate the difference**: Subtract the earlier `datetime` from the later `datetime` to get a `timedelta` object. To ensure a positive duration, we'll use `abs()` on the `timedelta` result.
4.  **Convert to milliseconds**: A `timedelta` object has a `total_seconds()` method, which returns the duration in seconds as a float. To convert this to milliseconds, we multiply by 1000.
5.  **Return the result**: Cast the final float result to an integer, as milliseconds are typically represented as an integer duration.

```python
from datetime import datetime, timedelta

def calculate_milliseconds_duration(dt1: datetime, dt2: datetime) -> int:
    # Step 1: Calculate the absolute difference between the two datetime objects
    difference: timedelta = abs(dt2 - dt1)
    
    # Step 2: Get the total seconds from the timedelta
    total_seconds: float = difference.total_seconds()
    
    # Step 3: Convert total seconds to milliseconds by multiplying by 1000
    # Step 4: Return the result as an integer
    return int(total_seconds * 1000)

# Entry point: calculate_milliseconds_duration(dt1: datetime, dt2: datetime) -> int
```
