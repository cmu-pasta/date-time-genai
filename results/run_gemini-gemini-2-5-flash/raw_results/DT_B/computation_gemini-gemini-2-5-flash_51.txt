Let's think step by step to solve this problem.
1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with `time` and `datetime` objects.
2. **Define a function**: We will create a function that accepts two `datetime.time` objects as input.
3. **Convert to datetime objects for subtraction**: `datetime.time` objects cannot be directly subtracted to yield a `timedelta`. To find the duration between two `time` objects, we need to associate them with an arbitrary common date (e.g., `datetime.date(1, 1, 1)`) to create `datetime.datetime` objects. Then, we can subtract these `datetime` objects to get a `timedelta`.
4. **Calculate the difference in total minutes**: The subtraction of two `datetime.datetime` objects results in a `datetime.timedelta` object. We can use the `total_seconds()` method of the `timedelta` object to get the total number of seconds, and then divide by 60 to convert this to minutes. We will use `abs()` to ensure the duration is always positive, representing the "period."
5. **Return the result**: Return the calculated total minutes as an integer.

```python
from datetime import datetime, time, date

def calculate_total_minutes_between_times(time1: time, time2: time) -> int:
    # Step 1: Create arbitrary datetime objects by combining the input times with a common date.
    # We use date(1, 1, 1) as a base date to allow subtraction.
    dt1 = datetime.combine(date(1, 1, 1), time1)
    dt2 = datetime.combine(date(1, 1, 1), time2)
    
    # Step 2: Calculate the difference between the two datetime objects.
    # The result is a timedelta object.
    time_difference_timedelta = dt2 - dt1
    
    # Step 3: Get the absolute total seconds from the timedelta.
    # We use abs() to ensure a positive duration, as a "period" implies a magnitude.
    total_seconds = abs(time_difference_timedelta.total_seconds())
    
    # Step 4: Convert total seconds to total minutes and return as an integer.
    total_minutes = int(total_seconds / 60)
    
    return total_minutes

# Entry point: calculate_total_minutes_between_times(time1: time, time2: time) -> int
```
