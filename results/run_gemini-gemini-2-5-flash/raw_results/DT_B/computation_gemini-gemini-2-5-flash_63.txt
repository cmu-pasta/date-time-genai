Let's think step by step to solve this problem.
1.  **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2.  **Define a function**: We will create a function that accepts two `datetime` objects as input.
3.  **Calculate the difference in days**: Subtract the two `datetime` objects to get a `timedelta` object, then extract the total number of days from it. We should use `abs()` to ensure a positive difference.
4.  **Calculate the number of fortnights**: A fortnight is defined as 14 days. Divide the total number of days by 14 to find the number of fortnights. Since the problem implies an integer count (and the example output type is integer), we will use integer division (`//`) to get the number of full fortnights.
5.  **Return the result**: Return the calculated number of fortnights as an integer.

```python
from datetime import datetime

def calculate_fortnights_difference(dt1: datetime, dt2: datetime) -> int:
    # Step 1: Calculate the absolute difference in days between the two datetime objects
    difference_in_days = abs((dt2 - dt1).days)
    
    # Step 2: A fortnight is 14 days. Calculate the number of full fortnights.
    number_of_fortnights = difference_in_days // 14
    
    # Step 3: Return the result as an integer
    return number_of_fortnights

# Entry point: calculate_fortnights_difference(dt1: datetime, dt2: datetime) -> int
```
