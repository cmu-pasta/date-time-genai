Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `datetime` class from Python's standard `datetime` module to work with dates.
2.  **Define a function**: Create a function that accepts a `datetime` object as input.
3.  **Extract the month**: Access the `month` attribute of the input `datetime` object.
4.  **Calculate the quarter**: Use integer division and arithmetic to map the month (1-12) to its corresponding quarter (1-4). The formula `(month - 1) // 3 + 1` can achieve this efficiently.
5.  **Return the result**: Return the calculated quarter as an integer.

```python
from datetime import datetime

def determine_quarter(dt: datetime) -> int:
    # Step 1: Extract the month from the datetime object
    month = dt.month
    
    # Step 2: Calculate the quarter based on the month
    # Months 1-3 -> Quarter 1
    # Months 4-6 -> Quarter 2
    # Months 7-9 -> Quarter 3
    # Months 10-12 -> Quarter 4
    quarter = (month - 1) // 3 + 1
    
    # Step 3: Return the quarter as an integer
    return quarter

# Entry point: determine_quarter(dt: datetime) -> int
```
