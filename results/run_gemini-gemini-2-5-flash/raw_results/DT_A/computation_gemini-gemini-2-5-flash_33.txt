Let's think step by step to solve this problem.

1.  **Import necessary classes**: We need `datetime`, `date`, and `time` from the `datetime` module to work with date and time objects.
2.  **Define the function**: Create a function that accepts two `time` objects as input, representing the two times on the same day.
3.  **Combine times with a common date**: Since `time` objects cannot be directly subtracted to yield a `timedelta`, we must combine each `time` object with an arbitrary, common `date` (e.g., `date.min`) to create `datetime` objects. This allows for valid subtraction.
4.  **Calculate the difference**: Subtract the two `datetime` objects. The result will be a `timedelta` object.
5.  **Extract total minutes**: From the resulting `timedelta`, get the total number of seconds using `total_seconds()` and then divide by 60 to convert it to minutes. Use `abs()` to ensure a positive difference.
6.  **Return the result**: Return the calculated number of minutes as an integer.

```python
from datetime import datetime, date, time

def calculate_minutes_difference_times(t1: time, t2: time) -> int:
    # Step 1: Combine each time with an arbitrary common date to create datetime objects.
    # Using date.min ensures we have a valid date part for subtraction,
    # without affecting the time difference.
    dt1 = datetime.combine(date.min, t1)
    dt2 = datetime.combine(date.min, t2)
    
    # Step 2: Calculate the difference between the two datetime objects.
    # This results in a timedelta object.
    time_difference = dt2 - dt1
    
    # Step 3: Get the total number of seconds from the timedelta and convert to minutes.
    # Use abs() to ensure the difference is always positive, regardless of input order.
    total_minutes = abs(int(time_difference.total_seconds() / 60))
    
    # Step 4: Return the result as an integer.
    return total_minutes

# Entry point: calculate_minutes_difference_times(t1: time, t2: time) -> int
```
