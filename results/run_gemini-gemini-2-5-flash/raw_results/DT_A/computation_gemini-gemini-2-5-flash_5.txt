Let's think step by step to solve this problem.

1.  **Import necessary libraries**: We need `datetime` for date objects and `timedelta` to add days.
2.  **Define a function**: Create a function that takes `year` (integer) and `month` (integer) as inputs.
3.  **Construct the first day of the month**: Create a `datetime` object for the first day of the given month and year.
4.  **Calculate days to add to reach the first Monday**:
    *   Determine the weekday of the first day of the month (Monday is 0, Sunday is 6).
    *   Calculate how many days need to be added to reach the next Monday (or the first day itself if it's already Monday). The formula `(0 - first_day.weekday() + 7) % 7` will give us the number of days to add to reach the target weekday (Monday, which is 0).
5.  **Add the calculated days**: Use `timedelta` to add these days to the first day of the month.
6.  **Return the result**: The resulting `datetime` object represents the first Monday of the specified month and year.

```python
from datetime import datetime, timedelta

def find_first_monday(year: int, month: int) -> datetime:
    # Step 3: Construct the first day of the given month and year
    first_day_of_month = datetime(year, month, 1)
    
    # Step 4: Calculate days to add to reach the first Monday
    # Monday is 0, Tuesday is 1, ..., Sunday is 6
    # We want to find the difference to the target weekday (Monday = 0)
    # The formula (target_weekday - current_weekday + 7) % 7 gives days to add
    days_to_add = (0 - first_day_of_month.weekday() + 7) % 7
    
    # Step 5: Add the calculated days to find the first Monday
    first_monday = first_day_of_month + timedelta(days=days_to_add)
    
    # Step 6: Return the resulting datetime object
    return first_monday

# Entry point: find_first_monday(year: int, month: int) -> datetime
```
