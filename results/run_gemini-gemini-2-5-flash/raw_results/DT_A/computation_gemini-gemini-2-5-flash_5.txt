Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We will need `datetime` and `timedelta` from the `datetime` module to create date objects and perform date arithmetic.
2.  **Define a function**: Create a function that accepts `year` and `month` as integer inputs.
3.  **Create the first day of the month**: Construct a `datetime` object representing the first day of the given month and year.
4.  **Calculate the weekday**: Determine the weekday of this first day. Python's `weekday()` method returns an integer where Monday is 0 and Sunday is 6.
5.  **Determine days to add**: Calculate how many days need to be added to the first day of the month to reach the first Monday. This can be done by finding the difference between the desired weekday (Monday, which is 0) and the actual weekday of the first day, adjusted to be within a 0-6 range.
6.  **Add days and return**: Add the calculated number of days to the first day of the month using `timedelta`. The result will be a `datetime` object representing the first Monday of the specified month and year.

```python
from datetime import datetime, timedelta

def find_first_monday(year: int, month: int) -> datetime:
    # Step 1: Create a datetime object for the first day of the given month and year
    first_day_of_month = datetime(year, month, 1)
    
    # Step 2: Get the weekday of the first day of the month
    # Monday is 0, Tuesday is 1, ..., Sunday is 6
    first_day_weekday = first_day_of_month.weekday()
    
    # Step 3: Calculate how many days to add to reach the first Monday
    # (0 - first_day_weekday + 7) % 7 gives the number of days to add to get to the *next* Monday
    # If first_day_weekday is 0 (Monday), days_to_add = (0 - 0 + 7) % 7 = 0
    # If first_day_weekday is 1 (Tuesday), days_to_add = (0 - 1 + 7) % 7 = 6
    # If first_day_weekday is 6 (Sunday), days_to_add = (0 - 6 + 7) % 7 = 1
    days_to_add = (0 - first_day_weekday + 7) % 7
    
    # Step 4: Add the calculated days to the first day of the month
    first_monday = first_day_of_month + timedelta(days=days_to_add)
    
    # Step 5: Return the resulting datetime object
    return first_monday

# Entry point: find_first_monday(year: int, month: int) -> datetime
```
