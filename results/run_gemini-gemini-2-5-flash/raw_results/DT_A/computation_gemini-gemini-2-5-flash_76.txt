Let's think step by step to solve this problem.
1.  **Import the necessary libraries**: We need the `datetime` class from Python's standard `datetime` module.
2.  **Define a function**: Create a function that accepts two `datetime` objects: the `target_datetime` to be converted and a `reference_datetime` from which the days are counted.
3.  **Calculate the time difference**: Subtract the `reference_datetime` from the `target_datetime`. This operation results in a `timedelta` object.
4.  **Extract the days component**: The `timedelta` object has a `days` attribute which represents the number of full days in the difference. This will naturally handle both positive (target after reference) and negative (target before reference) differences.
5.  **Return the result**: Return the extracted `days` component as an integer.

```python
from datetime import datetime, timedelta

def convert_datetime_to_days_since_reference(target_dt: datetime, reference_dt: datetime) -> int:
    # Step 1: Calculate the difference between the target datetime and the reference datetime.
    # This results in a timedelta object.
    time_difference: timedelta = target_dt - reference_dt
    
    # Step 2: Extract the 'days' attribute from the timedelta object.
    # This gives the number of full days as an integer.
    number_of_days: int = time_difference.days
    
    # Step 3: Return the calculated number of days.
    return number_of_days

# Entry point: convert_datetime_to_days_since_reference(target_dt: datetime, reference_dt: datetime) -> int
```
