Let's think step by step to solve this problem.

1.  **Import necessary libraries**: We need the `datetime` module and `timedelta` from Python's standard library to work with dates and compute differences.
2.  **Define the function signature**: Create a function `calculate_business_days_difference` that accepts two `datetime` objects (`dt1` and `dt2`) as input and is expected to return an `integer`.
3.  **Handle date order**: Ensure that the starting date for iteration is always the earlier of the two input dates. If `dt1` is later than `dt2`, swap them.
4.  **Initialize a counter**: A variable `business_days_count` will be used to store the number of business days, initialized to 0.
5.  **Iterate through the dates**: Start from the earlier date and iterate day by day up to and including the later date. We will extract only the date part for iteration to simplify daily checks, as time components are not relevant for counting full days.
6.  **Check for business day**: For each day in the iteration, determine if it is a business day (Monday through Friday). The `weekday()` method of a `date` object returns an integer where Monday is 0 and Sunday is 6. Business days are `weekday()` values from 0 to 4.
7.  **Increment counter**: If the current day is a business day, increment `business_days_count`.
8.  **Return the total**: After iterating through all days, return the final `business_days_count`.

```python
from datetime import datetime, timedelta

def calculate_business_days_difference(dt1: datetime, dt2: datetime) -> int:
    # Step 1: Ensure dt_start is earlier than or equal to dt_end.
    # We only care about the date part for counting days.
    date_start = dt1.date()
    date_end = dt2.date()

    if date_start > date_end:
        date_start, date_end = date_end, date_start

    # Step 2: Initialize a counter for business days.
    business_days_count = 0
    current_date = date_start

    # Step 3: Iterate from the start date up to and including the end date.
    while current_date <= date_end:
        # Step 4: Check if the current day is a weekday (Monday to Friday).
        # weekday() returns 0 for Monday, 1 for Tuesday, ..., 6 for Sunday.
        # Business days are 0, 1, 2, 3, 4.
        if current_date.weekday() < 5:
            business_days_count += 1
        
        # Step 5: Move to the next day.
        current_date += timedelta(days=1)
    
    # Step 6: Return the total number of business days.
    return business_days_count

# Entry point: calculate_business_days_difference(dt1: datetime, dt2: datetime) -> int
```
