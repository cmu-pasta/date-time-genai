Let's think step by step to solve this problem.
1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates and times.
2. **Define a function**: Create a function that accepts a `datetime` object as input.
3. **Convert to ISO 8601 string**: Use the `isoformat()` method available on the `datetime` object, which directly converts the datetime instance into a string formatted according to ISO 8601.
4. **Return the result**: The method will return the ISO 8601 formatted string.

```python
from datetime import datetime

def convert_datetime_to_iso8601(dt_obj: datetime) -> str:
    # Step 1: Use the isoformat() method to convert the datetime object
    # into an ISO 8601 formatted string.
    iso_string = dt_obj.isoformat()
    
    # Step 2: Return the resulting string.
    return iso_string

# Entry point: convert_datetime_to_iso8601(dt_obj: datetime) -> str
```
