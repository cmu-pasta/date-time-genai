Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2.  **Define a function**: We will create a function that accepts a `datetime` object as input.
3.  **Implement fiscal year logic**: We need to check the month of the input date. If the month is April (4) or later, the fiscal year is the same as the calendar year of the date. If the month is before April (January, February, or March), the fiscal year is the previous calendar year.
4.  **Return the result**: The function should return the calculated fiscal year as an integer.

```python
from datetime import datetime

def determine_fiscal_year(date_obj: datetime) -> int:
    """
    Determines the fiscal year for a given date, assuming an April start.

    Args:
        date_obj: The input date as a datetime object.

    Returns:
        The fiscal year as an integer.
    """
    # Fiscal year starts in April (month 4)
    fiscal_start_month = 4

    # If the month is before April, the fiscal year is the previous calendar year
    if date_obj.month < fiscal_start_month:
        fiscal_year = date_obj.year - 1
    # Otherwise (month is April or later), the fiscal year is the current calendar year
    else:
        fiscal_year = date_obj.year
        
    return fiscal_year

# Entry point: determine_fiscal_year(date_obj: datetime) -> int
```
