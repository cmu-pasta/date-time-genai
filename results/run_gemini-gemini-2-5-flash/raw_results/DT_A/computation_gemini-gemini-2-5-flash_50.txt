Let's think step by step to solve this problem.
1.  **Import the necessary libraries**: We need the `datetime` module to work with `datetime` objects and `timedelta` objects.
2.  **Define a function**: We will create a function that accepts a `datetime` object as input, representing the given date.
3.  **Create a timedelta object**: Instantiate a `timedelta` object representing 100 days.
4.  **Perform the subtraction**: Subtract the `timedelta` object from the input `datetime` object.
5.  **Return the result**: The result will be a new `datetime` object representing the date 100 days before the input.

```python
from datetime import datetime, timedelta

def find_date_100_days_before(given_date: datetime) -> datetime:
    # Step 1: Create a timedelta object for 100 days
    hundred_days = timedelta(days=100)
    
    # Step 2: Subtract this timedelta from the given date
    result_date = given_date - hundred_days
    
    # Step 3: Return the resulting datetime object
    return result_date

# Entry point: find_date_100_days_before(given_date: datetime) -> datetime
```
