Let's think step by step to solve this problem.

1.  **Import necessary libraries**: We need `datetime` and `time` objects from the `datetime` module. We will also need `date` to combine with `time` objects for subtraction.
2.  **Define a function**: Create a function that accepts two `datetime.time` objects representing the start and end times of the period.
3.  **Convert times to datetimes**: To calculate a duration, it's easiest to work with `datetime` objects. We can combine our `time` objects with an arbitrary `date` (e.g., `date(1, 1, 1)`) to create `datetime` objects.
4.  **Handle overnight periods**: If the second time is chronologically earlier than the first time (e.g., 10 PM to 2 AM), it implies the period crosses midnight. In this case, we should treat the second `datetime` object as if it occurred on the next day.
5.  **Calculate the time difference**: Subtract the start `datetime` from the end `datetime`. This will result in a `timedelta` object.
6.  **Extract total minutes**: Use the `total_seconds()` method of the `timedelta` object and divide by 60 to get the total minutes, then convert to an integer.
7.  **Return the result**: The total minutes as an integer.

```python
from datetime import datetime, time, date, timedelta

def calculate_total_minutes_between_times(time1: time, time2: time) -> int:
    # Step 3: Convert times to datetimes using an arbitrary date
    # Using a dummy date (e.g., January 1, 1 AD) to combine with the time objects
    dt1 = datetime.combine(date(1, 1, 1), time1)
    dt2 = datetime.combine(date(1, 1, 1), time2)

    # Step 4: Handle overnight periods
    # If time2 is chronologically earlier than time1, it means the period crosses midnight.
    # In such cases, we treat dt2 as if it's on the next day.
    if dt2 < dt1:
        dt2 += timedelta(days=1)

    # Step 5: Calculate the time difference (which will be a timedelta object)
    time_difference = dt2 - dt1

    # Step 6: Extract total minutes from the timedelta
    # total_seconds() returns the total number of seconds in the duration.
    # Dividing by 60 gives the total minutes.
    total_minutes = int(time_difference.total_seconds() / 60)

    # Step 7: Return the result
    return total_minutes

# Entry point: calculate_total_minutes_between_times(time1: time, time2: time) -> int
```
