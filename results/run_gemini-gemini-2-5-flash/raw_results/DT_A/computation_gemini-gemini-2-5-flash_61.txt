Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `datetime` module to work with date objects.
2.  **Define a function**: Create a function that accepts a `datetime.date` object as input, representing the given date.
3.  **Determine the day of the week**: Use the `isoweekday()` method available on `date` objects. This method returns the day of the week as an integer, where Monday is 1 and Sunday is 7, which perfectly matches the desired output format (1-7).
4.  **Return the result**: The function will return this integer value.

```python
from datetime import date

def get_day_number_of_week(dt: date) -> int:
    # Step 1: Use the isoweekday() method to get the day of the week (Monday=1, Sunday=7)
    day_number = dt.isoweekday()
    
    # Step 2: Return the integer representing the day number (1-7)
    return day_number

# Entry point: get_day_number_of_week(dt: date) -> int
```
