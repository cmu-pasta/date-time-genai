Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with timestamps.
2.  **Define a function**: We will create a function that accepts two `datetime` objects as input, representing the two timestamps.
3.  **Calculate the difference**: Subtract one `datetime` object from the other to obtain a `timedelta` object, which represents the duration between the two timestamps.
4.  **Extract total seconds**: Use the `total_seconds()` method of the `timedelta` object to get the total number of seconds as a float.
5.  **Return the result**: Convert the total seconds to an integer and return it. We should use `abs()` to ensure a positive difference, as "number of seconds between" typically implies a magnitude.

```python
from datetime import datetime

def calculate_seconds_difference(dt1: datetime, dt2: datetime) -> int:
    # Step 1: Calculate the difference between the two datetime objects.
    # This results in a timedelta object.
    time_difference = dt2 - dt1
    
    # Step 2: Get the total number of seconds from the timedelta object.
    # total_seconds() returns a float, including microseconds if present.
    total_seconds_float = time_difference.total_seconds()
    
    # Step 3: Convert the float to an integer and ensure it's a positive value.
    # Using abs() to get the magnitude of the difference.
    return int(abs(total_seconds_float))

# Entry point: calculate_seconds_difference(dt1: datetime, dt2: datetime) -> int
```
