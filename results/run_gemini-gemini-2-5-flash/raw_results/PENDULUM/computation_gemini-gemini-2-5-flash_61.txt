Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `pendulum` library to work with dates.
2.  **Define a function**: Create a function that accepts a `pendulum.DateTime` object as input.
3.  **Access the day of the week**: `pendulum.DateTime` objects have a `day_of_week` property which returns the day of the week as an integer, where Monday is 1 and Sunday is 7 (ISO 8601 standard). This directly matches the desired output format (1-7).
4.  **Return the result**: The `day_of_week` property already returns an integer, so we can return it directly.

```python
import pendulum

def get_day_number_of_week(dt: pendulum.DateTime) -> int:
    # Step 1: Access the day_of_week property of the pendulum.DateTime object.
    # Pendulum's day_of_week returns 1 for Monday and 7 for Sunday (ISO 8601).
    day_number = dt.day_of_week
    
    # Step 2: Return the integer representation of the day number.
    return day_number

# Entry point: get_day_number_of_week(dt: pendulum.DateTime) -> int
```
