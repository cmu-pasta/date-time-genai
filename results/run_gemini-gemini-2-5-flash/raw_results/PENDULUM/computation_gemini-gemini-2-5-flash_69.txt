3.  **Calculate the time difference**: `pendulum.DateTime` objects can be directly subtracted from each other. Pendulum automatically handles time zone conversions by internally converting both datetimes to UTC before calculating the difference, ensuring the result is accurate regardless of the original time zones. The result of this subtraction is a `pendulum.Duration` object.
4.  **Return the result**: Return the `pendulum.Duration` object, which encapsulates the total time difference in days, hours, minutes, and seconds.

import pendulum

def calculate_timezone_aware_time_difference(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> pendulum.Duration:
    # Step 1: Subtract the two pendulum.DateTime objects.
    # Pendulum automatically accounts for time zones when performing subtraction,
    # yielding a correct duration between the two specific points in time.
    time_difference = dt2 - dt1
    
    # Step 2: Return the resulting pendulum.Duration object.
    return time_difference
