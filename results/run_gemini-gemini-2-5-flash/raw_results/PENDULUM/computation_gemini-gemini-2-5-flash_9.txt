Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `pendulum` library to work with dates and times.
2.  **Define a function**: We will create a function that accepts two `pendulum.DateTime` objects as input, representing the two timestamps.
3.  **Calculate the difference**: Use the `diff()` method between the two `pendulum.DateTime` objects, and then extract the total number of seconds from the resulting `pendulum.Duration` object using `in_seconds()`.
4.  **Handle absolute difference**: Since the order of timestamps might vary, use `abs()` to return a non-negative number of seconds.
5.  **Return the result**: The `in_seconds()` method returns an integer, which is the desired output type.

```python
import pendulum

def calculate_seconds_difference(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> int:
    # Step 1: Calculate the duration between the two DateTime objects
    duration = dt2.diff(dt1)
    
    # Step 2: Get the total number of seconds from the duration
    # We use abs() to ensure the result is a non-negative integer, regardless of input order
    total_seconds = abs(duration.in_seconds())
    
    # Step 3: Return the total seconds as an integer
    return total_seconds

# Entry point: calculate_seconds_difference(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> int
```
