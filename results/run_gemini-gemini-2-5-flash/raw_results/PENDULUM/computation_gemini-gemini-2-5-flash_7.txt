Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `pendulum` library to work with dates.
2.  **Define a function**: Create a function that accepts an integer representing the year.
3.  **Create a `pendulum.Date` object**: Construct a `pendulum.Date` object for the given year (e.g., January 1st of that year). This object will carry the necessary information about the year.
4.  **Access the `is_leap_year` property**: The `pendulum.Date` object has a convenient `is_leap_year` property that directly returns a boolean indicating whether the year is a leap year.
5.  **Return the result**: Return the boolean value obtained from the `is_leap_year` property.

```python
import pendulum

def is_leap_year(year: int) -> bool:
    # Step 1: Create a pendulum.Date object for the given year.
    # We can use any date within that year, for simplicity, we pick January 1st.
    date_in_year = pendulum.date(year, 1, 1)
    
    # Step 2: Access the is_leap_year property of the pendulum.Date object.
    # This property directly returns a boolean indicating if the year is a leap year.
    is_leap = date_in_year.is_leap_year
    
    # Step 3: Return the boolean result.
    return is_leap

# Entry point: is_leap_year(year: int) -> bool
```
