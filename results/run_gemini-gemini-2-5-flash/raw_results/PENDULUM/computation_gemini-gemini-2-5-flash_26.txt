Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `pendulum` library to work with datetime objects.
2.  **Define a function**: Create a function that accepts two `pendulum.DateTime` objects as input, representing the start and end datetimes.
3.  **Calculate the total duration**: Subtract one datetime from the other to get a `pendulum.Duration` object representing the time span between them.
4.  **Calculate half the duration**: Divide the total duration by 2. This will result in another `pendulum.Duration` object.
5.  **Add half duration to the first datetime**: Add this half-duration to the first `pendulum.DateTime` object. This operation will yield the midpoint `pendulum.DateTime`.
6.  **Return the midpoint datetime**: The function should return the calculated `pendulum.DateTime` object.

```python
import pendulum

def find_midpoint_datetime(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> pendulum.DateTime:
    # Step 1: Calculate the difference (duration) between the two datetimes
    total_duration = dt2 - dt1
    
    # Step 2: Calculate half of the total duration
    half_duration = total_duration / 2
    
    # Step 3: Add half_duration to the first datetime to find the midpoint
    midpoint_dt = dt1 + half_duration
    
    # Step 4: Return the midpoint datetime
    return midpoint_dt

# Entry point: find_midpoint_datetime(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> pendulum.DateTime
```
