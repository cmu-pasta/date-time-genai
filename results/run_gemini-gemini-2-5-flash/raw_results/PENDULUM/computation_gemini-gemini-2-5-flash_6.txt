Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `pendulum` library to work with dates.
2.  **Define a function**: Create a function that accepts two `pendulum.DateTime` objects as input.
3.  **Determine the order**: To get positive age components, we should ensure we subtract the earlier date from the later date. We can use `min()` and `max()` to establish this order.
4.  **Calculate the difference**: Use the `diff()` method on the later `pendulum.DateTime` object, passing the earlier `pendulum.DateTime` object as an argument. This will return a `pendulum.Duration` object.
5.  **Extract components**: From the resulting `pendulum.Duration` object, extract the `years`, `months`, and `days` attributes. Pendulum's `diff` method correctly handles the calculation of these components without needing manual date arithmetic for month/day rollovers.
6.  **Return the result**: Return the extracted years, months, and days as three separate integers.

```python
import pendulum

def calculate_age_components(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> (int, int, int):
    # Step 3: Determine the order to ensure positive age components
    # Age is conventionally positive, so we calculate the difference from earlier to later.
    earlier_date = min(dt1, dt2)
    later_date = max(dt1, dt2)

    # Step 4: Calculate the difference using pendulum's diff() method
    # This returns a pendulum.Duration object
    duration = later_date.diff(earlier_date)
    
    # Step 5: Extract years, months, and days from the duration
    years = duration.years
    months = duration.months
    days = duration.days
    
    # Step 6: Return the components as integers
    return years, months, days

# Entry point: calculate_age_components(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> (int, int, int)
```
