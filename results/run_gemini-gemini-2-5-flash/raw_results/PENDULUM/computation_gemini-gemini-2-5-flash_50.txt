Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `pendulum` library to work with dates and durations.
2.  **Define a function**: Create a function that accepts a `pendulum.DateTime` object as the input, representing the original date.
3.  **Calculate the date 100 days prior**: Use the `subtract` method available on `pendulum.DateTime` objects to subtract 100 days. Pendulum allows direct subtraction of days.
4.  **Return the new date**: The function should return the resulting `pendulum.DateTime` object.

```python
import pendulum

def find_date_100_days_before(original_date: pendulum.DateTime) -> pendulum.DateTime:
    # Step 1: Subtract 100 days from the given date
    # Pendulum's subtract method can take keyword arguments like 'days'
    new_date = original_date.subtract(days=100)
    
    # Step 2: Return the resulting pendulum.DateTime object
    return new_date

# Entry point: find_date_100_days_before(original_date: pendulum.DateTime) -> pendulum.DateTime
```
