Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `pendulum` library to work with dates.
2.  **Define a function**: We will create a function that accepts a `pendulum.DateTime` object as input.
3.  **Determine the day of the week as an integer**: The `pendulum.DateTime` object has a property `isoweekday()` which returns the day of the week as an integer, where 1 represents Monday and 7 represents Sunday. This aligns with the ISO 8601 standard and allows us to return an integer, which is one of the allowed output types.
4.  **Return the result**: The function will return this integer representation of the day of the week.

```python
import pendulum

def get_day_of_week_number(dt: pendulum.DateTime) -> int:
    # Step 1: Use the isoweekday() property to get the day of the week as an integer.
    # ISO 8601 standard: 1 for Monday, 7 for Sunday.
    day_number = dt.isoweekday()
    
    # Step 2: Return the integer representing the day of the week.
    return day_number

# Entry point: get_day_of_week_number(dt: pendulum.DateTime) -> int
```
