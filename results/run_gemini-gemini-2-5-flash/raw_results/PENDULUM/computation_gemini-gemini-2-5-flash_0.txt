Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `pendulum` library to handle date and time objects.
2.  **Define a function**: Create a function that accepts two `pendulum.DateTime` objects as input.
3.  **Determine the date range**: Identify the earlier and later date from the two inputs to establish a proper iteration range.
4.  **Initialize a counter**: Set up a variable to keep track of the number of business days.
5.  **Iterate through each day**: Loop day by day from the start date up to and including the end date.
6.  **Check for business day**: Inside the loop, for each day, check if it falls on a weekday (Monday to Friday). Pendulum's `day_of_week` property returns 1 for Monday and 7 for Sunday, so we are interested in values from 1 to 5.
7.  **Increment counter**: If the current day is a business day, increment the counter.
8.  **Return the result**: After iterating through all days, return the total count of business days as an integer.

```python
import pendulum

def calculate_business_days(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> int:
    # Step 1 & 2: Determine the start and end dates to ensure iteration goes forward
    start_date = dt1.start_of('day') if dt1 <= dt2 else dt2.start_of('day')
    end_date = dt2.start_of('day') if dt1 <= dt2 else dt1.start_of('day')

    # Step 3: Initialize a counter for business days
    business_days_count = 0

    # Step 4 & 5: Iterate through each day from start_date to end_date (inclusive)
    current_date = start_date
    while current_date <= end_date:
        # Step 6: Check if the current day is a weekday (Monday to Friday)
        # Pendulum's day_of_week: 1 (Monday) ... 7 (Sunday)
        if 1 <= current_date.day_of_week <= 5:
            business_days_count += 1 # Step 7: Increment if it's a business day
        
        # Move to the next day
        current_date = current_date.add(days=1)
        
    # Step 8: Return the total count of business days
    return business_days_count

# Entry point: calculate_business_days(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> int
```
