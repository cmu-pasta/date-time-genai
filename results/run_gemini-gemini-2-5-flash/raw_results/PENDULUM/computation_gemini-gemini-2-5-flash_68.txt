Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `pendulum` library to work with dates.
2.  **Define the function signature**: Create a function `find_labor_day` that accepts an integer `year` as input and is expected to return a `pendulum.Date` object.
3.  **Find the first day of September**: Create a `pendulum.Date` object for September 1st of the given year.
4.  **Calculate days to add**: Determine how many days need to be added to the September 1st date to reach the first Monday.
    *   The `day_of_week` attribute returns 1 for Monday, 2 for Tuesday, ..., 7 for Sunday. `pendulum.MONDAY` is 1.
    *   The formula `(pendulum.MONDAY - first_september.day_of_week + 7) % 7` will give the number of days to add to reach the next Monday (or stay on the current date if it's already Monday).
5.  **Add days to find Labor Day**: Use the `add(days=...)` method on the September 1st date to get the final Labor Day date.
6.  **Return the result**: Return the calculated `pendulum.Date` object.

```python
import pendulum

def find_labor_day(year: int) -> pendulum.Date:
    # Step 1: Create a pendulum.Date object for September 1st of the given year.
    first_september = pendulum.date(year, 9, 1)

    # Step 2: Determine the day of the week for September 1st.
    # pendulum.MONDAY is 1, Tuesday is 2, ..., Sunday is 7.
    current_day_of_week = first_september.day_of_week

    # Step 3: Calculate how many days to add to reach the first Monday.
    # If September 1st is already a Monday, days_to_add will be 0.
    # Otherwise, it calculates the difference to the next Monday.
    # The '+ 7) % 7' ensures the result is always positive and correct for week wrapping.
    days_to_add = (pendulum.MONDAY - current_day_of_week + 7) % 7

    # Step 4: Add the calculated days to September 1st to find Labor Day.
    labor_day_date = first_september.add(days=days_to_add)

    # Step 5: Return the resulting pendulum.Date object.
    return labor_day_date

# Entry point: find_labor_day(year: int) -> pendulum.Date
```
