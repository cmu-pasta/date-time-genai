Let's think step by step to solve this problem.

1.  **Import the necessary libraries**: We need the `pendulum` library to work with dates.
2.  **Define a function**: Create a function that accepts a single `pendulum.DateTime` object as input.
3.  **Access the week of the year**: Pendulum's `DateTime` objects have a built-in property, `week_of_year`, which directly provides the ISO week number (1-53).
4.  **Return the result**: The property already returns an integer, which is the desired output.

```python
import pendulum

def get_week_of_year(dt: pendulum.DateTime) -> int:
    # Step 1: Access the 'week_of_year' property of the pendulum.DateTime object.
    # This property directly returns the ISO week number (1-53) for the given date.
    week_number = dt.week_of_year
    
    # Step 2: Return the integer representing the week of the year.
    return week_number

# Entry point: get_week_of_year(dt: pendulum.DateTime) -> int
```
