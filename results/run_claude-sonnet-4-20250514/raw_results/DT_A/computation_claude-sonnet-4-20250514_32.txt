Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts two datetime objects as input parameters.
3. **Calculate the time difference**: Find the difference between the two datetime objects, which will give us a timedelta object.
4. **Find the midpoint**: Divide the time difference by 2 to get half the duration between the dates.
5. **Calculate the middle date**: Add half the difference to the first date to get the date that falls exactly in the middle.
6. **Return the result**: Return the middle date as a datetime object.

```python
from datetime import datetime

def find_middle_date(dt1: datetime, dt2: datetime) -> datetime:
    # Calculate the difference between the two dates
    diff = dt2 - dt1
    
    # Find half the difference
    half_diff = diff / 2
    
    # Add half the difference to the first date to get the middle date
    middle_date = dt1 + half_diff
    
    return middle_date

# Entry point: find_middle_date(dt1: datetime, dt2: datetime) -> datetime
```
