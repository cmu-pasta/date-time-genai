2. **Understand the Easter calculation**: Easter Sunday is calculated using a complex algorithm based on the lunar calendar and the spring equinox. We need to implement the Gregorian calendar Easter calculation algorithm.
3. **Implement the Easter algorithm**: The algorithm involves calculating the "golden number," century values, epact, and finally determining the correct Sunday.
4. **Create the datetime object**: Once we have the month and day, we can create a datetime object for Easter Sunday in the given year.

from datetime import datetime

def find_easter_sunday(year: int) -> datetime:
    # Algorithm for calculating Easter Sunday date (Gregorian calendar)
    
    # Step 1: Calculate the golden number (position in the 19-year Metonic cycle)
    golden_number = (year % 19) + 1
    
    # Step 2: Calculate the century
    century = (year // 100) + 1
    
    # Step 3: Calculate leap year corrections
    leap_correction = (3 * century) // 4 - 12
    moon_correction = (8 * century + 5) // 25 - 5
    
    # Step 4: Calculate Sunday letter
    sunday_letter = (5 * year) // 4 - leap_correction - 10
    
    # Step 5: Calculate the epact (age of moon on January 1st)
    epact = (11 * golden_number + 20 + moon_correction - leap_correction) % 30
    if (epact == 25 and golden_number > 11) or epact == 24:
        epact += 1
    
    # Step 6: Find the full moon date
    full_moon_day = 44 - epact
    if full_moon_day < 21:
        full_moon_day += 30
    
    # Step 7: Find the Sunday after the full moon
    sunday_after = full_moon_day + 7 - ((sunday_letter + full_moon_day) % 7)
    
    # Step 8: Determine the month and day
    if sunday_after > 31:
        easter_month = 4
        easter_day = sunday_after - 31
    else:
        easter_month = 3
        easter_day = sunday_after
    
    # Step 9: Create and return the datetime object
    easter_date = datetime(year, easter_month, easter_day)
    
    return easter_date
