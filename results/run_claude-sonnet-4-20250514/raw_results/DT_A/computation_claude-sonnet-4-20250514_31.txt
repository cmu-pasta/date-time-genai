Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts a datetime object as input.
3. **Determine fiscal year logic**: Since the fiscal year starts in April, if the given date's month is April (4) or later, the fiscal year is the next calendar year. If the month is before April (January-March), the fiscal year is the current calendar year.
4. **Extract the year and month**: Get the year and month from the input datetime object.
5. **Apply fiscal year calculation**: If month >= 4 (April or later), fiscal year = year + 1. Otherwise, fiscal year = year.
6. **Return the result**: Return the fiscal year as an integer.

```python
from datetime import datetime

def determine_fiscal_year(dt: datetime) -> int:
    # Step 1: Extract year and month from the datetime
    year = dt.year
    month = dt.month
    
    # Step 2: Determine fiscal year based on April start
    if month >= 4:  # April (4) or later months
        fiscal_year = year + 1
    else:  # January (1), February (2), or March (3)
        fiscal_year = year
    
    # Step 3: Return the fiscal year as an integer
    return fiscal_year

# Entry point: determine_fiscal_year(dt: datetime) -> int
```
