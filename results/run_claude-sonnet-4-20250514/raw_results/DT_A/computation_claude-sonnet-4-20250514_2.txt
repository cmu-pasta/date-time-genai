Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts a datetime object as input.
3. **Extract the day name**: Use the `strftime()` method with the appropriate format code to get the full day name from the datetime object.
4. **Return the result**: Return the day name as a string.

```python
from datetime import datetime

def get_day_name(dt: datetime) -> str:
    # Step 1: Use strftime to get the full day name
    day_name = dt.strftime('%A')
    
    # Step 2: Return the day name
    return day_name

# Entry point: get_day_name(dt: datetime) -> str
```
