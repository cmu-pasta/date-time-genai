Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with date objects.
2. **Define a function**: We will create a function that accepts a date as input. This date should be provided as a datetime object.
3. **Extract the day of year**: Use the `timetuple()` method to get a time structure, then access the `tm_yday` attribute which represents the day of the year (1-366).
4. **Return the result**: Return the day of year as an integer.

```python
from datetime import datetime

def date_to_day_of_year(dt: datetime) -> int:
    # Step 1: Get the day of year using timetuple
    day_of_year = dt.timetuple().tm_yday
    
    # Step 2: Return the result as an integer
    return day_of_year

# Entry point: date_to_day_of_year(dt: datetime) -> int
```
