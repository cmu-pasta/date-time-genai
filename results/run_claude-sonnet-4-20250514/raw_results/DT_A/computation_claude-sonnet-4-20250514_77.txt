Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` and `timedelta` from Python's datetime module to work with dates and date arithmetic.

2. **Define a function**: Create a function that accepts a year as an integer input and returns a date object representing Columbus Day.

3. **Find October 1st**: Create a datetime object for October 1st of the given year.

4. **Calculate the first Monday**: Determine what day of the week October 1st falls on, then calculate how many days to add to reach the first Monday of October.

5. **Calculate the second Monday**: Add 7 days to the first Monday to get the second Monday, which is Columbus Day.

6. **Return the result**: Return the date as a datetime.date object.

```python
from datetime import datetime, timedelta

def find_columbus_day(year: int) -> datetime:
    # Step 1: Create October 1st of the given year
    october_first = datetime(year, 10, 1)
    
    # Step 2: Calculate days until the first Monday
    # weekday() returns 0 for Monday, 1 for Tuesday, etc.
    days_until_first_monday = (7 - october_first.weekday()) % 7
    
    # Step 3: Calculate the first Monday
    first_monday = october_first + timedelta(days=days_until_first_monday)
    
    # Step 4: Calculate the second Monday (Columbus Day)
    columbus_day = first_monday + timedelta(days=7)
    
    return columbus_day

# Entry point: find_columbus_day(year: int) -> datetime
```
