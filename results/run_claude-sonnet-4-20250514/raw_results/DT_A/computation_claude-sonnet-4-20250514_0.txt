Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates and times.
2. **Define a function**: Create a function that accepts two datetime objects as input parameters.
3. **Determine the date range**: Find the start and end dates, ensuring we handle the case where the dates might be in reverse order.
4. **Iterate through dates**: Loop through each date in the range and check if it's a business day (Monday through Friday).
5. **Count business days**: Use the `weekday()` method to check if each date falls on a weekday (0-4 represent Monday-Friday).
6. **Return the result**: Return the count of business days as an integer.

```python
from datetime import datetime, timedelta

def calculate_business_days(dt1: datetime, dt2: datetime) -> int:
    # Step 1: Determine start and end dates (handle reverse order)
    start_date = min(dt1, dt2)
    end_date = max(dt1, dt2)
    
    # Step 2: Initialize business day counter
    business_days = 0
    
    # Step 3: Iterate through each date in the range
    current_date = start_date
    while current_date <= end_date:
        # Step 4: Check if current date is a business day (Monday=0 to Friday=4)
        if current_date.weekday() < 5:
            business_days += 1
        
        # Move to the next day
        current_date += timedelta(days=1)
    
    # Step 5: Return the count of business days
    return business_days

# Entry point: calculate_business_days(dt1: datetime, dt2: datetime) -> int
```
