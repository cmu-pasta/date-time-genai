Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with datetime objects.
2. **Define a function**: We will create a function that accepts two datetime objects representing times on the same day.
3. **Calculate the time difference**: Use subtraction to find the difference between the two `datetime` objects, which will give us a `timedelta` object.
4. **Convert to minutes**: Extract the total seconds from the timedelta and convert to minutes by dividing by 60.
5. **Return the result**: Return the result as an integer representing the number of minutes between the two times.

```python
from datetime import datetime

def calculate_minutes_between_times(dt1: datetime, dt2: datetime) -> int:
    # Step 1: Calculate the difference between the two datetime objects
    difference = abs(dt2 - dt1)  # Using abs to ensure a positive difference
    
    # Step 2: Convert the timedelta to total seconds, then to minutes
    total_seconds = difference.total_seconds()
    minutes = int(total_seconds / 60)
    
    # Step 3: Return the result as an integer
    return minutes

# Entry point: calculate_minutes_between_times(dt1: datetime, dt2: datetime) -> int
```
