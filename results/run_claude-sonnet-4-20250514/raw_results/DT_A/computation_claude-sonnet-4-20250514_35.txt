Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts a datetime object representing any day in the target month.
3. **Find the last day of the month**: Calculate the last day of the given month by finding the first day of the next month and subtracting one day.
4. **Check if it's a business day**: Use the `weekday()` method to check if the day is a weekday (Monday=0 to Friday=4).
5. **Find the last business day**: If the last day is not a business day, go backwards day by day until we find a business day.
6. **Return the result**: Return the last business day as a datetime object.

```python
from datetime import datetime, timedelta

def find_last_business_day_of_month(dt: datetime) -> datetime:
    # Step 1: Find the last day of the month
    # Get the first day of the next month
    if dt.month == 12:
        next_month_first = datetime(dt.year + 1, 1, 1)
    else:
        next_month_first = datetime(dt.year, dt.month + 1, 1)
    
    # Get the last day of the current month
    last_day_of_month = next_month_first - timedelta(days=1)
    
    # Step 2: Find the last business day
    # Start from the last day and go backwards until we find a weekday
    current_day = last_day_of_month
    
    # weekday() returns 0 for Monday, 6 for Sunday
    # Business days are Monday (0) through Friday (4)
    while current_day.weekday() > 4:  # Saturday is 5, Sunday is 6
        current_day = current_day - timedelta(days=1)
    
    return current_day

# Entry point: find_last_business_day_of_month(dt: datetime) -> datetime
```
