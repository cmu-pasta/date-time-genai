Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `date` and `timedelta` classes from the `datetime` module to work with dates and time differences.

2. **Define the function parameters**: The function needs to accept the year, month, target weekday (0=Monday, 1=Tuesday, etc.), and the occurrence number (n) as integers.

3. **Create the first day of the month**: Use the `date` constructor to create a date object for the first day of the given month and year.

4. **Calculate days to the first occurrence**: Find what weekday the first day of the month is, then calculate how many days to add to reach the first occurrence of the target weekday using modular arithmetic.

5. **Calculate the nth occurrence**: Add the appropriate number of days to get from the first occurrence to the nth occurrence (adding (n-1) * 7 days).

6. **Return the result**: Return the calculated date as a `date` object.

```python
from datetime import date, timedelta

def find_nth_weekday_in_month(year: int, month: int, weekday: int, n: int) -> date:
    # Step 1: Create the first day of the given month and year
    first_day = date(year, month, 1)
    
    # Step 2: Find what weekday the first day is (0=Monday, 1=Tuesday, etc.)
    first_weekday = first_day.weekday()
    
    # Step 3: Calculate days to add to get to the first occurrence of target weekday
    days_to_first_occurrence = (weekday - first_weekday) % 7
    
    # Step 4: Calculate the date of the first occurrence of the target weekday
    first_occurrence = first_day + timedelta(days=days_to_first_occurrence)
    
    # Step 5: Calculate the nth occurrence by adding (n-1) weeks
    nth_occurrence = first_occurrence + timedelta(days=(n-1) * 7)
    
    # Step 6: Return the result as a date object
    return nth_occurrence

# Entry point: find_nth_weekday_in_month(year: int, month: int, weekday: int, n: int) -> date
```
