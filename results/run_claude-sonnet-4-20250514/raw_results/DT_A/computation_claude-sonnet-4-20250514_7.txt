Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts a year as an integer input.
3. **Use datetime to check leap year**: We can determine if a year is a leap year by trying to create February 29th of that year. If it succeeds, it's a leap year; if it raises a ValueError, it's not.
4. **Return the result**: Return a boolean value indicating whether the year is a leap year or not.

```python
from datetime import datetime

def is_leap_year(year: int) -> bool:
    try:
        # Try to create February 29th of the given year
        # If this succeeds, the year is a leap year
        datetime(year, 2, 29)
        return True
    except ValueError:
        # If ValueError is raised, February 29th doesn't exist in this year
        # Therefore, it's not a leap year
        return False

# Entry point: is_leap_year(year: int) -> bool
```
