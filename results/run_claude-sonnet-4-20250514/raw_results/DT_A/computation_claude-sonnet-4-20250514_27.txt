Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates and check for leap years.

2. **Define a function**: We will create a function that accepts two years as integers representing the start and end years of the range.

3. **Determine the range**: We need to ensure we're checking all years between (and including) the two input years, regardless of which one is larger.

4. **Check each year for leap year**: For each year in the range, we'll use datetime to determine if it's a leap year by attempting to create a February 29th date for that year.

5. **Count and return**: Count the number of leap years found and return the result as an integer.

```python
from datetime import datetime, date

def calculate_leap_years_between(year1: int, year2: int) -> int:
    # Ensure we have the correct start and end years
    start_year = min(year1, year2)
    end_year = max(year1, year2)
    
    leap_year_count = 0
    
    # Check each year in the range (inclusive)
    for year in range(start_year, end_year + 1):
        # Try to create February 29th for this year
        # If successful, it's a leap year
        try:
            date(year, 2, 29)
            leap_year_count += 1
        except ValueError:
            # February 29th doesn't exist for this year, so it's not a leap year
            continue
    
    return leap_year_count

# Entry point: calculate_leap_years_between(year1: int, year2: int) -> int
```
