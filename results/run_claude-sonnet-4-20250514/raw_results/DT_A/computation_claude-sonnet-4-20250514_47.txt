Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module and specifically `date` and `timedelta` to work with dates.
2. **Define a function**: Create a function that accepts a year as an integer input.
3. **Find the last day of May**: Create a date object for May 31st of the given year.
4. **Determine the weekday**: Use the `weekday()` method to find what day of the week May 31st falls on (where Monday = 0).
5. **Calculate days to subtract**: If May 31st is already a Monday, Memorial Day is May 31st. Otherwise, we need to go back to the previous Monday.
6. **Return the Memorial Day date**: Subtract the appropriate number of days using `timedelta` and return the result as a date object.

```python
from datetime import date, timedelta

def find_memorial_day(year: int) -> date:
    # Step 1: Get May 31st of the given year
    may_31 = date(year, 5, 31)
    
    # Step 2: Find what day of the week May 31st is (Monday = 0, Sunday = 6)
    weekday = may_31.weekday()
    
    # Step 3: Calculate how many days to go back to get to the last Monday
    # If May 31st is Monday (0), we don't need to go back
    # If May 31st is Tuesday (1), we go back 1 day
    # If May 31st is Wednesday (2), we go back 2 days, etc.
    days_to_subtract = weekday
    
    # Step 4: Calculate Memorial Day by subtracting the appropriate days
    memorial_day = may_31 - timedelta(days=days_to_subtract)
    
    return memorial_day

# Entry point: find_memorial_day(year: int) -> date
```
