Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts a year as an integer input.
3. **Find September 1st**: Create a date object for September 1st of the given year.
4. **Determine the day of the week**: Use the `weekday()` method to find what day of the week September 1st falls on (Monday=0, Sunday=6).
5. **Calculate days to add**: If September 1st is already a Monday, Labor Day is September 1st. Otherwise, we need to find the next Monday by adding the appropriate number of days.
6. **Return the Labor Day date**: Add the calculated days to September 1st and return the result.

```python
from datetime import datetime, timedelta

def find_labor_day(year: int) -> datetime:
    # Step 1: Create September 1st of the given year
    sep_first = datetime(year, 9, 1)
    
    # Step 2: Find what day of the week September 1st falls on
    # weekday() returns 0 for Monday, 1 for Tuesday, ..., 6 for Sunday
    weekday = sep_first.weekday()
    
    # Step 3: Calculate how many days to add to get to the first Monday
    # If it's already Monday (0), add 0 days
    # Otherwise, add enough days to reach the next Monday
    days_to_add = (7 - weekday) % 7
    
    # Step 4: Calculate Labor Day by adding the required days
    labor_day = sep_first + timedelta(days=days_to_add)
    
    return labor_day

# Entry point: find_labor_day(year: int) -> datetime
```
