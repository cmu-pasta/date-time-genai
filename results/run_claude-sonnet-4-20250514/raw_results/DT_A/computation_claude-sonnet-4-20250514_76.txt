Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts two datetime objects as input - the target datetime and the reference datetime.
3. **Calculate the difference**: Use subtraction to find the difference between the target datetime and the reference datetime.
4. **Extract days**: Get the days component from the timedelta result.
5. **Return the result**: Return the number of days as an integer.

```python
from datetime import datetime

def convert_to_days_since_reference(dt: datetime, reference_dt: datetime) -> int:
    # Step 1: Calculate the difference between the datetime and reference date
    difference = dt - reference_dt
    
    # Step 2: Extract the days component and return as integer
    return difference.days

# Entry point: convert_to_days_since_reference(dt: datetime, reference_dt: datetime) -> int
```
