Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module and `timedelta` from Python's standard library to work with dates and time differences.

2. **Define a function**: We will create a function that accepts a date as input. This date should be provided as a datetime object.

3. **Calculate 100 days before**: Use `timedelta(days=100)` to represent 100 days, then subtract it from the given datetime object to get the date that is exactly 100 days before.

4. **Return the result**: Return the resulting datetime object which represents the date 100 days before the input date.

```python
from datetime import datetime, timedelta

def find_date_100_days_before(dt: datetime) -> datetime:
    # Step 1: Create a timedelta object representing 100 days
    hundred_days = timedelta(days=100)
    
    # Step 2: Subtract 100 days from the given date
    result_date = dt - hundred_days
    
    # Step 3: Return the resulting datetime
    return result_date

# Entry point: find_date_100_days_before(dt: datetime) -> datetime
```
