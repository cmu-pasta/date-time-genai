Let's think step by step to solve this problem.

1. **Understand the Persian New Year (Nowruz)**: Nowruz is the Persian New Year that occurs on the vernal equinox, typically falling on March 20 or March 21 in the Gregorian calendar.

2. **Import the necessary libraries**: We need the `datetime` module to work with dates.

3. **Define a function**: Create a function that accepts a Gregorian year as an integer and returns the date of Nowruz for that year.

4. **Implement the logic**: Since Nowruz is based on the astronomical vernal equinox, and we're limited to the datetime library only, we'll use a simplified approach. Historically, Nowruz most commonly falls on March 20, with March 21 occurring in certain years (particularly those divisible by 4, but not always).

5. **Return the result**: Return the calculated date as a datetime.date object.

```python
from datetime import datetime, date

def find_persian_new_year(year: int) -> date:
    # Persian New Year (Nowruz) typically falls on March 20 or 21
    # Based on the vernal equinox, which varies slightly year to year
    # For a simplified calculation using only datetime library:
    # Most years: March 20
    # Some years (especially around leap years): March 21
    
    # This is a simplified approximation since exact calculation requires
    # astronomical data not available in datetime library
    # Generally, March 21 occurs more frequently in leap years and surrounding years
    if year % 4 == 0 and year % 100 != 0 or year % 400 == 0:
        # Leap year - more likely to be March 21
        nowruz_date = date(year, 3, 21)
    elif (year + 1) % 4 == 0 or (year - 1) % 4 == 0:
        # Year before or after leap year - also more likely March 21
        nowruz_date = date(year, 3, 21)
    else:
        # Most common case - March 20
        nowruz_date = date(year, 3, 20)
    
    return nowruz_date

# Entry point: find_persian_new_year(year: int) -> date
```
