Let's think step by step to solve this problem.

1. **Understand the requirement**: Martin Luther King Jr. Day is observed on the third Monday of January each year.
2. **Import the necessary library**: We need the pendulum library to work with dates.
3. **Create a function**: The function should accept a year (integer) and return the date as a pendulum.Date object.
4. **Find January 1st**: Create a date object for January 1st of the given year.
5. **Find the first Monday**: Determine what day of the week January 1st falls on, then calculate how many days to add to reach the first Monday of January.
6. **Calculate the third Monday**: Add 14 days (2 weeks) to the first Monday to get the third Monday.
7. **Return the result**: Return the date as a pendulum.Date object.

```python
import pendulum

def find_mlk_day(year: int) -> pendulum.Date:
    # Step 1: Create January 1st of the given year
    jan_first = pendulum.date(year, 1, 1)
    
    # Step 2: Find the first Monday of January
    # Pendulum weekdays: Monday=1, Tuesday=2, ..., Sunday=7
    weekday = jan_first.weekday()
    
    # Calculate days to add to reach the first Monday
    days_to_first_monday = (8 - weekday) % 7
    
    # Step 3: Get the first Monday
    first_monday = jan_first.add(days=days_to_first_monday)
    
    # Step 4: Add 14 days (2 weeks) to get the third Monday
    third_monday = first_monday.add(days=14)
    
    return third_monday

# Entry point: find_mlk_day(year: int) -> pendulum.Date
```
