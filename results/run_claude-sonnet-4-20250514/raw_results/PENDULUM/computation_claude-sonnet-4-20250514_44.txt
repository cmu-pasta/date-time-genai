Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the pendulum library to work with dates.
2. **Define a function**: We will create a function that accepts a year as an integer input.
3. **Determine the first day of spring**: The first day of spring is typically the vernal equinox, which occurs around March 20-21. For simplicity and consistency, we'll use March 20 as the first day of spring.
4. **Create the date**: Use pendulum to create a Date object for March 20 of the given year.
5. **Return the result**: Return the pendulum.Date object representing the first day of spring.

```python
import pendulum

def find_first_day_of_spring(year: int) -> pendulum.Date:
    # The first day of spring (vernal equinox) typically occurs on March 20
    # Using March 20 as the standard first day of spring
    first_day_of_spring = pendulum.date(year, 3, 20)
    
    return first_day_of_spring

# Entry point: find_first_day_of_spring(year: int) -> pendulum.Date
```
