3. **Convert to ISO 8601 format**: Use pendulum's built-in method to convert the datetime to ISO 8601 format string.
4. **Return the result**: Return the formatted string.

```python
import pendulum

def convert_to_iso8601(dt: pendulum.DateTime) -> str:
    # Convert the pendulum DateTime object to ISO 8601 format string
    iso_string = dt.to_iso8601_string()
    
    return iso_string
```
