Let's think step by step to solve this problem.

1. **Understand Nowruz**: Persian New Year (Nowruz) is celebrated on the spring equinox, which typically occurs on March 20th or 21st each year in the Gregorian calendar.

2. **Import the necessary library**: We need the pendulum library to work with dates.

3. **Define the function**: Create a function that accepts a Gregorian year as an integer input.

4. **Determine Nowruz date**: For most years, Nowruz falls on March 20th. We'll use this as our standard date since it's the most common in recent decades.

5. **Create and return the date**: Use pendulum to create a Date object for March 20th of the given year and return it.

```python
import pendulum

def find_persian_new_year(year: int) -> pendulum.Date:
    # Nowruz (Persian New Year) typically falls on March 20th
    # This is the spring equinox date for most years
    nowruz_date = pendulum.date(year, 3, 20)
    
    return nowruz_date

# Entry point: find_persian_new_year(year: int) -> pendulum.Date
```
