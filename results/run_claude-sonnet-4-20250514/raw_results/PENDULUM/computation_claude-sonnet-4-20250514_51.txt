Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the pendulum library to work with dates and times.
2. **Define a function**: We will create a function that accepts two times as pendulum.DateTime objects as input.
3. **Calculate the time difference**: Use the diff() method to find the difference between the two pendulum.DateTime objects, which returns a pendulum.Duration.
4. **Convert to minutes**: Extract the total minutes from the duration using the total_seconds() method and convert to minutes.
5. **Return the result**: Return the total minutes as an integer.

```python
import pendulum

def calculate_total_minutes(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> int:
    # Step 1: Calculate the difference between the two times
    time_difference = dt2.diff(dt1)
    
    # Step 2: Convert the difference to total minutes
    total_minutes = int(time_difference.total_seconds() / 60)
    
    # Step 3: Return the absolute value to ensure positive result
    return abs(total_minutes)

# Entry point: calculate_total_minutes(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> int
```
