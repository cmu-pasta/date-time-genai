Let's think step by step to solve this problem.

1. **Understand the different epochs**: Unix epoch starts at January 1, 1970, 00:00:00 UTC, while Windows FILETIME epoch starts at January 1, 1601, 00:00:00 UTC.

2. **Import the necessary library**: We need the pendulum library for date and time operations.

3. **Define the conversion function**: Create a function that takes a Unix timestamp (as a float) and converts it to Windows FILETIME format.

4. **Convert Unix timestamp to DateTime**: Use pendulum's `from_timestamp()` method to convert the Unix timestamp to a DateTime object.

5. **Calculate Windows epoch difference**: Find the difference between the DateTime object and the Windows epoch start date (January 1, 1601).

6. **Convert to Windows format**: Windows FILETIME represents time as 100-nanosecond intervals since January 1, 1601, so we multiply the total seconds by 10,000,000.

7. **Return the result**: Return the Windows timestamp as an integer.

```python
import pendulum

def convert_unix_to_windows_epoch(unix_timestamp: float) -> int:
    # Step 1: Convert Unix timestamp to pendulum DateTime
    dt = pendulum.from_timestamp(unix_timestamp)
    
    # Step 2: Define Windows epoch start (January 1, 1601, 00:00:00 UTC)
    windows_epoch_start = pendulum.parse("1601-01-01T00:00:00Z")
    
    # Step 3: Calculate the difference between the datetime and Windows epoch start
    diff = dt - windows_epoch_start
    
    # Step 4: Convert to Windows FILETIME format (100-nanosecond intervals)
    windows_timestamp = int(diff.total_seconds() * 10_000_000)
    
    return windows_timestamp

# Entry point: convert_unix_to_windows_epoch(unix_timestamp: float) -> int
```
