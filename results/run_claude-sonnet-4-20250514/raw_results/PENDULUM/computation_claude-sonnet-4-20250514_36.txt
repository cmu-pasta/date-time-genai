Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the pendulum library to work with timestamps and calculate durations.
2. **Define a function**: We will create a function that accepts two timestamps as pendulum.DateTime objects.
3. **Calculate the duration**: Use the diff() method to find the difference between the two timestamps, which returns a pendulum.Duration object.
4. **Convert to milliseconds**: Use the in_milliseconds() method on the duration object to get the total milliseconds.
5. **Return as integer**: Convert the result to an integer and use absolute value to ensure a positive duration.

```python
import pendulum

def calculate_duration_milliseconds(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> int:
    # Calculate the difference between the two timestamps
    duration = dt2.diff(dt1)  # This returns a pendulum.Duration object
    
    # Convert to milliseconds and return as integer (using abs for positive duration)
    return int(abs(duration.in_milliseconds()))

# Entry point: calculate_duration_milliseconds(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> int
```
