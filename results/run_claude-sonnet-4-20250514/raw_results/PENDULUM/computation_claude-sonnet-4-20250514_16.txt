Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the pendulum library to work with datetime objects.
2. **Define a function**: We will create a function that accepts a Unix timestamp as input (integer representing seconds since epoch).
3. **Convert timestamp to datetime**: Use pendulum's built-in method to convert the Unix timestamp to a pendulum.DateTime object.
4. **Return the result**: Return the human-readable datetime as a pendulum.DateTime object.

```python
import pendulum

def convert_unix_to_datetime(timestamp: int) -> pendulum.DateTime:
    # Step 1: Convert Unix timestamp to pendulum DateTime object
    dt = pendulum.from_timestamp(timestamp)
    
    # Step 2: Return the human-readable datetime
    return dt

# Entry point: convert_unix_to_datetime(timestamp: int) -> pendulum.DateTime
```
