Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the pendulum library to work with dates.
2. **Define a function**: We will create a function that accepts two dates as input. These dates should be pendulum.DateTime objects.
3. **Calculate the difference**: Find the time difference between the two dates using the diff() method.
4. **Find the middle point**: Divide the difference by 2 to get the halfway duration.
5. **Calculate the middle date**: Add half of the duration to the earlier date to get the exact middle date.
6. **Return the result**: Return the middle date as a pendulum.DateTime object.

```python
import pendulum

def find_middle_date(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> pendulum.DateTime:
    # Step 1: Determine which date is earlier
    earlier_date = min(dt1, dt2)
    later_date = max(dt1, dt2)
    
    # Step 2: Calculate the duration between the two dates
    duration_diff = later_date.diff(earlier_date)
    
    # Step 3: Find half of the duration
    half_duration = duration_diff / 2
    
    # Step 4: Add half duration to the earlier date to get the middle date
    middle_date = earlier_date + half_duration
    
    # Step 5: Return the middle date
    return middle_date

# Entry point: find_middle_date(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> pendulum.DateTime
```
