Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the pendulum library to work with dates.
2. **Define a function**: We will create a function that accepts a year as input (integer).
3. **Create October 1st**: Start with October 1st of the given year using pendulum.Date.
4. **Find the first Monday**: Calculate how many days to add to October 1st to reach the first Monday.
5. **Get the second Monday**: Add 7 more days to the first Monday to get the second Monday (Columbus Day).
6. **Return the result**: Return the date as a pendulum.Date object.

```python
import pendulum

def find_columbus_day(year: int) -> pendulum.Date:
    # Step 1: Create October 1st of the given year
    october_first = pendulum.Date(year, 10, 1)
    
    # Step 2: Find the first Monday of October
    # weekday() returns 0 for Monday, 1 for Tuesday, ..., 6 for Sunday
    days_to_first_monday = (7 - october_first.weekday()) % 7
    first_monday = october_first.add(days=days_to_first_monday)
    
    # Step 3: Add 7 days to get the second Monday (Columbus Day)
    columbus_day = first_monday.add(days=7)
    
    return columbus_day

# Entry point: find_columbus_day(year: int) -> pendulum.Date
```
