Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the pendulum library to work with dates and times.
2. **Define a function**: Create a function that accepts two pendulum.DateTime objects as input parameters.
3. **Determine date range**: Identify the start and end dates, ensuring proper ordering regardless of which date is earlier.
4. **Iterate through dates**: Loop through each day in the range from start to end date (inclusive).
5. **Check for business days**: For each date, check if it falls on a weekday (Monday through Friday). In Pendulum, weekday() returns 1-7 where Monday=1 and Sunday=7.
6. **Count business days**: Increment a counter for each business day found.
7. **Return the result**: Return the total count as an integer.

```python
import pendulum

def calculate_business_days(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> int:
    # Step 1: Determine the start and end dates, ensuring proper ordering
    start_date = min(dt1, dt2).date()
    end_date = max(dt1, dt2).date()
    
    # Step 2: Initialize business days counter
    business_days_count = 0
    current_date = start_date
    
    # Step 3: Iterate through each day from start to end (inclusive)
    while current_date <= end_date:
        # Step 4: Check if current day is a business day (Monday=1 to Friday=5)
        if current_date.weekday() <= 5:
            business_days_count += 1
        
        # Step 5: Move to the next day
        current_date = current_date.add(days=1)
    
    # Step 6: Return the total count of business days
    return business_days_count

# Entry point: calculate_business_days(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> int
```
