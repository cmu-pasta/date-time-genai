Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the pendulum library to work with dates.
2. **Define a function**: We will create a function that accepts a year as an integer input.
3. **Find October 1st of the given year**: Create a pendulum.Date object for October 1st of the specified year.
4. **Calculate the first Monday**: Determine how many days to add to October 1st to reach the first Monday of October.
5. **Calculate the second Monday**: Add 7 days to the first Monday to get the second Monday.
6. **Return the result**: Return the second Monday as a pendulum.Date object.

```python
import pendulum

def find_indigenous_peoples_day(year: int) -> pendulum.Date:
    # Step 1: Get October 1st of the given year
    october_first = pendulum.date(year, 10, 1)
    
    # Step 2: Calculate days to the first Monday of October
    # weekday() returns 0 for Monday, 1 for Tuesday, etc.
    days_to_first_monday = (7 - october_first.weekday()) % 7
    
    # Step 3: Find the first Monday
    first_monday = october_first.add(days=days_to_first_monday)
    
    # Step 4: Find the second Monday (Indigenous Peoples' Day)
    second_monday = first_monday.add(days=7)
    
    return second_monday

# Entry point: find_indigenous_peoples_day(year: int) -> pendulum.Date
```
