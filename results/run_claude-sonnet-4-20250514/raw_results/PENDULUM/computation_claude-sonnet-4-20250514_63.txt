Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the pendulum library to work with dates and times.
2. **Define a function**: Create a function that accepts two dates as pendulum.DateTime objects as input parameters.
3. **Calculate the difference in days**: Use the diff() method to find the difference between the two dates and convert to days.
4. **Convert days to fortnights**: Since a fortnight is 14 days, divide the number of days by 14.
5. **Return the result**: Return the result as an integer representing the number of fortnights.

```python
import pendulum

def calculate_fortnights_between_dates(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> int:
    # Step 1: Calculate the difference in days
    days_difference = abs(dt2.diff(dt1).in_days())
    
    # Step 2: Convert days to fortnights (1 fortnight = 14 days)
    fortnights = days_difference // 14
    
    # Step 3: Return the result as an integer
    return fortnights

# Entry point: calculate_fortnights_between_dates(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> int
```
