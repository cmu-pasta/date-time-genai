Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the pendulum library to work with timestamps.
2. **Define a function**: We will create a function that accepts two timestamps as pendulum.DateTime objects.
3. **Calculate the time difference**: Use pendulum's diff method to find the difference between the two timestamps.
4. **Extract seconds**: Get the total number of seconds from the difference using the in_seconds() method.
5. **Return the result**: Return the result as an integer representing the number of seconds.

```python
import pendulum

def calculate_seconds_difference(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> int:
    # Step 1: Calculate the difference between the two timestamps
    difference = dt2.diff(dt1)
    
    # Step 2: Get the total seconds from the difference
    seconds = difference.in_seconds()
    
    # Step 3: Return the result as an integer
    return int(seconds)

# Entry point: calculate_seconds_difference(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> int
```
