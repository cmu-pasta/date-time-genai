Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the pendulum library to work with dates.
2. **Define a function**: We will create a function that accepts year and month as integers.
3. **Create the first day of the month**: Use pendulum to create a date object for the first day of the given month and year.
4. **Find the weekday**: Get the weekday of the first day (Monday = 0, Tuesday = 1, ..., Sunday = 6).
5. **Calculate days to add**: If the first day is not Monday, calculate how many days to add to reach the first Monday.
6. **Return the result**: Add the calculated days to get the first Monday and return it as a pendulum.Date object.

```python
import pendulum

def find_first_monday(year: int, month: int) -> pendulum.Date:
    # Step 1: Create a date object for the first day of the given month and year
    first_day = pendulum.date(year, month, 1)
    
    # Step 2: Get the weekday of the first day (Monday = 0, Sunday = 6)
    weekday = first_day.weekday()
    
    # Step 3: Calculate how many days to add to reach the first Monday
    # If it's already Monday (0), add 0 days
    # Otherwise, calculate days needed to reach the next Monday
    days_to_add = (7 - weekday) % 7
    
    # Step 4: Add the calculated days to get the first Monday
    first_monday = first_day.add(days=days_to_add)
    
    return first_monday

# Entry point: find_first_monday(year: int, month: int) -> pendulum.Date
```
