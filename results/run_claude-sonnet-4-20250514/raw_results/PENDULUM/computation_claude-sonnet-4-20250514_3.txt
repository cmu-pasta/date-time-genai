Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the pendulum library to work with dates.
2. **Define a function**: We will create a function that accepts a date as input (pendulum.DateTime object).
3. **Identify leap year logic**: A year is a leap year if it's divisible by 4, except for years divisible by 100 (which are not leap years), unless they're also divisible by 400 (which are leap years).
4. **Find the next leap year**: Starting from the year after the given date, check each subsequent year until we find a leap year.
5. **Return the result**: Return the next leap year as an integer.

```python
import pendulum

def next_leap_year(dt: pendulum.DateTime) -> int:
    # Step 1: Get the year after the given date
    start_year = dt.year + 1
    
    # Step 2: Helper function to check if a year is a leap year
    def is_leap_year(year):
        return (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)
    
    # Step 3: Find the next leap year
    current_year = start_year
    while not is_leap_year(current_year):
        current_year += 1
    
    # Step 4: Return the next leap year
    return current_year

# Entry point: next_leap_year(dt: pendulum.DateTime) -> int
```
