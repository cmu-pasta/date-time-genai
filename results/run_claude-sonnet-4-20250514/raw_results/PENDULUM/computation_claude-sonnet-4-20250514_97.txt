Let's think step by step to solve this problem.

1. **Understanding the Thai Buddhist Calendar**: The Thai Buddhist calendar (B.E. - Buddhist Era) is essentially the same as the Gregorian calendar, but with the year offset by +543 years. So 2024 CE becomes 2567 BE.

2. **Import the necessary libraries**: We need the pendulum library to work with dates.

3. **Define a function**: Create a function that accepts a Gregorian date as a pendulum.Date object.

4. **Convert to Buddhist year**: Extract the year from the input date, add 543 to convert to Buddhist year, and create a new date with the same month and day but the Buddhist year.

5. **Return the result**: Return the Thai Buddhist calendar date as a pendulum.Date object.

```python
import pendulum

def gregorian_to_thai_buddhist(gregorian_date: pendulum.Date) -> pendulum.Date:
    # Step 1: Extract year, month, day from the input Gregorian date
    year = gregorian_date.year
    month = gregorian_date.month
    day = gregorian_date.day
    
    # Step 2: Convert to Thai Buddhist year by adding 543
    buddhist_year = year + 543
    
    # Step 3: Create a new pendulum.Date with the Buddhist year
    thai_buddhist_date = pendulum.Date(buddhist_year, month, day)
    
    # Step 4: Return the Thai Buddhist calendar date
    return thai_buddhist_date

# Entry point: gregorian_to_thai_buddhist(gregorian_date: pendulum.Date) -> pendulum.Date
```
