Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the pendulum library to work with dates and check day of the week.

2. **Define a function**: We will create a function that accepts a date as input (pendulum.Date type).

3. **Iterate through months**: Starting from the given date, we need to check each month's 13th day to see if it falls on a Friday.

4. **Check conditions**: For each 13th day, we need to verify:
   - It's after the given date (to ensure it's "next")
   - It falls on a Friday

5. **Return the result**: Return the first occurrence that meets our criteria as a pendulum.Date.

```python
import pendulum

def find_next_friday_13th(date: pendulum.Date) -> pendulum.Date:
    # Start checking from the current month
    year = date.year
    month = date.month
    
    while True:
        # Create the 13th of the current month
        thirteenth = pendulum.date(year, month, 13)
        
        # Check if this 13th is after our starting date and is a Friday
        if thirteenth > date and thirteenth.day_of_week == pendulum.FRIDAY:
            return thirteenth
        
        # Move to next month
        month += 1
        if month > 12:
            month = 1
            year += 1

# Entry point: find_next_friday_13th(date: pendulum.Date) -> pendulum.Date
```
