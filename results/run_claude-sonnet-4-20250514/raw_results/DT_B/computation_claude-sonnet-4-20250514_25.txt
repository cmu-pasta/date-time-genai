Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates and times.
2. **Define a function**: We will create a function that accepts four datetime parameters - start and end dates for each of the two date ranges.
3. **Implement overlap logic**: Two date ranges overlap if the start of the first range is before or equal to the end of the second range AND the start of the second range is before or equal to the end of the first range.
4. **Return the result**: Return a boolean value indicating whether the ranges overlap or not.

```python
from datetime import datetime

def check_date_ranges_overlap(start1: datetime, end1: datetime, start2: datetime, end2: datetime) -> bool:
    # Step 1: Check if the ranges overlap
    # Two ranges overlap if: start1 <= end2 AND start2 <= end1
    overlap_condition = start1 <= end2 and start2 <= end1
    
    # Step 2: Return the boolean result
    return overlap_condition

# Entry point: check_date_ranges_overlap(start1: datetime, end1: datetime, start2: datetime, end2: datetime) -> bool
```
