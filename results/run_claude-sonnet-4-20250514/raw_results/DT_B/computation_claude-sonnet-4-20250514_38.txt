Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts a datetime object as input representing the given date.
3. **Iterate through months**: Starting from the current month, we'll check each month to see if the 13th falls on a Friday and is after the given date.
4. **Check conditions**: For each month, create a datetime object for the 13th and check if it's both after the given date and falls on a Friday (weekday() == 4).
5. **Handle month/year transitions**: When moving to the next month, properly handle the transition from December to January of the next year.
6. **Return the result**: Return the first Friday the 13th found that occurs after the given date.

```python
from datetime import datetime

def find_next_friday_13th(given_date: datetime) -> datetime:
    # Start checking from the current month
    year = given_date.year
    month = given_date.month
    
    while True:
        # Create the 13th of the current month at 00:00:00
        thirteenth = datetime(year, month, 13)
        
        # Check if this 13th is after the given date AND is a Friday
        if thirteenth > given_date and thirteenth.weekday() == 4:  # 4 = Friday (Monday is 0)
            return thirteenth
        
        # Move to next month
        month += 1
        if month > 12:
            month = 1
            year += 1

# Entry point: find_next_friday_13th(given_date: datetime) -> datetime
```
