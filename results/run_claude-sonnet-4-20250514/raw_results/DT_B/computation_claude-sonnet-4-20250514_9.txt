Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with timestamps.
2. **Define a function**: We will create a function that accepts two datetime objects (timestamps) as input.
3. **Calculate the difference**: Use subtraction to find the difference between the two datetime objects, which will give us a timedelta object.
4. **Extract total seconds**: Use the `total_seconds()` method of the timedelta object to get the total number of seconds as a float.
5. **Return the result**: Return the absolute value to ensure we get the number of seconds between the timestamps (positive value).

```python
from datetime import datetime

def calculate_seconds_difference(dt1: datetime, dt2: datetime) -> float:
    # Step 1: Calculate the difference between the two timestamps
    difference = dt2 - dt1
    
    # Step 2: Get the total seconds from the timedelta object
    total_seconds = difference.total_seconds()
    
    # Step 3: Return the absolute value to get the number of seconds between timestamps
    return abs(total_seconds)

# Entry point: calculate_seconds_difference(dt1: datetime, dt2: datetime) -> float
```
