Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module and `timedelta` to work with dates and perform date arithmetic.
2. **Define a function**: Create a function that accepts a date as input and finds the previous Friday.
3. **Determine the current weekday**: Use the `weekday()` method to find what day of the week the given date is (Monday=0, Friday=4).
4. **Calculate days to go back**: Calculate how many days back we need to go to reach the previous Friday.
5. **Handle the special case**: If the given date is already a Friday, we want the previous Friday (7 days back), not the same day.
6. **Return the result**: Subtract the calculated number of days using `timedelta` and return the resulting date.

The logic for calculating days back:
- If given date is Saturday (5): go back 1 day
- If given date is Sunday (6): go back 2 days  
- If given date is Monday (0): go back 3 days
- If given date is Tuesday (1): go back 4 days
- If given date is Wednesday (2): go back 5 days
- If given date is Thursday (3): go back 6 days
- If given date is Friday (4): go back 7 days (previous Friday)

```python
from datetime import date, timedelta

def find_previous_friday(given_date: date) -> date:
    # Step 1: Get the weekday of the given date (Monday=0, Friday=4)
    weekday = given_date.weekday()
    
    # Step 2: Calculate how many days back to go to reach the previous Friday
    days_back = (weekday - 4) % 7
    
    # Step 3: Handle special case - if given date is Friday, go back 7 days
    if days_back == 0:
        days_back = 7
    
    # Step 4: Calculate the previous Friday by subtracting the required days
    previous_friday = given_date - timedelta(days=days_back)
    
    # Step 5: Return the result
    return previous_friday

# Entry point: find_previous_friday(given_date: date) -> date
```
