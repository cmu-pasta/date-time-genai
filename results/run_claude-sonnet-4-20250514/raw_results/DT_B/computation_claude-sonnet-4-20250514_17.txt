Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` and `timedelta` from Python's standard library to work with dates and iterate through days.

2. **Define the function parameters**: The function should accept a datetime object representing any date in the target month, an integer representing the weekday (0=Monday, 6=Sunday), and an integer representing which occurrence (1st, 2nd, 3rd, etc.).

3. **Initialize the search**: Start from the first day of the given month and initialize a counter to track occurrences of the target weekday.

4. **Iterate through the month**: Loop through each day of the month, checking if it matches the target weekday.

5. **Count occurrences**: When we find a matching weekday, increment the counter. When the counter reaches the desired nth occurrence, return that date.

6. **Handle month boundaries**: Use timedelta to safely increment days and check when we've moved beyond the target month.

```python
from datetime import datetime, timedelta

def find_nth_weekday_occurrence(month_date: datetime, weekday: int, n: int) -> datetime:
    # Get the year and month from the input date
    year = month_date.year
    month = month_date.month
    
    # Start from the first day of the month
    current_date = datetime(year, month, 1)
    
    count = 0
    
    # Iterate through the days of the month
    while current_date.month == month:
        # Check if this day is the target weekday (0=Monday, 6=Sunday)
        if current_date.weekday() == weekday:
            count += 1
            if count == n:
                return current_date
        
        # Move to the next day
        current_date += timedelta(days=1)
    
    # If nth occurrence doesn't exist, return the first day of the month
    # (This assumes valid input where nth occurrence exists)
    return datetime(year, month, 1)

# Entry point: find_nth_weekday_occurrence(month_date: datetime, weekday: int, n: int) -> datetime
```
