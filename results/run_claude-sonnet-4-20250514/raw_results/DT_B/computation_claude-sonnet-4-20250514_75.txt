Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with datetime objects.
2. **Define a function**: We will create a function that accepts a birth datetime as input.
3. **Get the current time**: Use `datetime.now()` to get the current datetime for comparison.
4. **Calculate the time difference**: Subtract the birth datetime from the current datetime to get a timedelta object.
5. **Convert to seconds**: Use the `total_seconds()` method of the timedelta object to get the total seconds.
6. **Return the result**: Convert the result to an integer and return it.

```python
from datetime import datetime

def calculate_age_in_seconds(birth_datetime: datetime) -> int:
    # Step 1: Get the current datetime
    current_datetime = datetime.now()
    
    # Step 2: Calculate the time difference between current time and birth time
    time_difference = current_datetime - birth_datetime
    
    # Step 3: Convert the time difference to total seconds and return as integer
    age_in_seconds = int(time_difference.total_seconds())
    
    return age_in_seconds

# Entry point: calculate_age_in_seconds(birth_datetime: datetime) -> int
```
