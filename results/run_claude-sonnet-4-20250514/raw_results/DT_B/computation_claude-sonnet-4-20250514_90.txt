Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module to work with dates and calculate differences.

2. **Define a reference new moon date**: We need a known new moon date as a reference point. January 6, 2000 was a new moon, so we'll use this as our reference.

3. **Define the lunar cycle length**: The average lunar cycle (synodic month) is approximately 29.530588853 days.

4. **Calculate days since reference**: Find the total number of days between the input date and our reference new moon date.

5. **Calculate lunar age**: Use modulo operation to find the remainder when dividing the total days by the lunar cycle length. This gives us the current position in the lunar cycle.

6. **Return the result**: Return the lunar age as a float representing days since the last new moon.

```python
from datetime import datetime

def calculate_lunar_age(input_date: datetime) -> float:
    # Reference new moon date: January 6, 2000
    reference_new_moon = datetime(2000, 1, 6)
    
    # Lunar cycle length in days (synodic month)
    lunar_cycle_days = 29.530588853
    
    # Calculate the difference in days between input date and reference
    days_difference = (input_date - reference_new_moon).total_seconds() / (24 * 3600)
    
    # Calculate lunar age using modulo operation
    lunar_age = days_difference % lunar_cycle_days
    
    # Ensure positive result
    if lunar_age < 0:
        lunar_age += lunar_cycle_days
    
    return lunar_age

# Entry point: calculate_lunar_age(input_date: datetime) -> float
```
