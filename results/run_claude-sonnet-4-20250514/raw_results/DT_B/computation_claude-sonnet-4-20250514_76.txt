Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with datetime objects.

2. **Define a function**: We will create a function that accepts two datetime objects as input - the target datetime and the reference datetime.

3. **Calculate the difference**: Use subtraction to find the difference between the target datetime and reference datetime, which will give us a timedelta object.

4. **Extract the days**: Get the days component from the timedelta object to determine how many days have passed since the reference date.

5. **Return the result**: Return the number of days as an integer.

```python
from datetime import datetime

def convert_datetime_to_days_since_reference(target_date: datetime, reference_date: datetime) -> int:
    # Calculate the difference between target date and reference date
    difference = target_date - reference_date
    
    # Return the number of days from the timedelta
    return difference.days

# Entry point: convert_datetime_to_days_since_reference(target_date: datetime, reference_date: datetime) -> int
```
