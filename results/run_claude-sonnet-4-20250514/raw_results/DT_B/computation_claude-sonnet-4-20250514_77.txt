Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime`, `date`, and `timedelta` classes from Python's standard library to work with dates.

2. **Define a function**: We will create a function that accepts a year as an integer input and returns the date of Columbus Day for that year.

3. **Find October 1st**: Create a date object for October 1st of the given year as our starting point.

4. **Determine the day of the week**: Use the `weekday()` method to find what day of the week October 1st falls on (0=Monday, 6=Sunday).

5. **Calculate days to first Monday**: If October 1st is not a Monday, calculate how many days to add to reach the first Monday of October using the formula `(7 - weekday) % 7`.

6. **Add 7 more days**: Since we need the second Monday, add 7 additional days to get from the first Monday to the second Monday.

7. **Calculate final date**: Use `timedelta` to add the calculated number of days to October 1st and return the resulting date.

```python
from datetime import date, timedelta

def find_columbus_day(year: int) -> date:
    # Step 1: Create October 1st of the given year
    oct_first = date(year, 10, 1)
    
    # Step 2: Find what day of the week October 1st is (0=Monday, 6=Sunday)
    weekday = oct_first.weekday()
    
    # Step 3: Calculate days to add to get to the first Monday
    days_to_first_monday = (7 - weekday) % 7
    
    # Step 4: Add 7 more days to get to the second Monday
    days_to_second_monday = days_to_first_monday + 7
    
    # Step 5: Calculate the date using timedelta
    columbus_day = oct_first + timedelta(days=days_to_second_monday)
    
    return columbus_day

# Entry point: find_columbus_day(year: int) -> date
```
