Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` and `time` modules from Python's standard library to work with times.
2. **Define a function**: We will create a function that accepts two time objects as input representing times on the same day.
3. **Convert times to datetime objects**: Since we can't directly subtract time objects, we need to convert them to datetime objects using a common date.
4. **Calculate the difference**: Use subtraction to find the difference between the two datetime objects, which gives us a timedelta.
5. **Convert to minutes**: Extract the total seconds from the timedelta and convert to minutes.
6. **Return the result**: Format the result as an integer and return it.

```python
from datetime import datetime, time

def calculate_minutes_difference(time1: time, time2: time) -> int:
    # Step 1: Convert times to datetime objects using a common date (today)
    today = datetime.today().date()
    dt1 = datetime.combine(today, time1)
    dt2 = datetime.combine(today, time2)
    
    # Step 2: Calculate the difference in seconds and convert to minutes
    difference_seconds = abs((dt2 - dt1).total_seconds())
    difference_minutes = difference_seconds / 60
    
    # Step 3: Return the result as an integer
    return int(difference_minutes)

# Entry point: calculate_minutes_difference(time1: time, time2: time) -> int
```
