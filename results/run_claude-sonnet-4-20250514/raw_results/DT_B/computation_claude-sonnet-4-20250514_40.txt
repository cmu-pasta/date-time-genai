Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `time` class from the `datetime` module to work with time objects.
2. **Define a function**: We will create a function that accepts a time object as input.
3. **Calculate seconds since midnight**: Extract the hour, minute, and second components from the time object and convert them to total seconds since 00:00:00.
4. **Return the result**: Return the total seconds as an integer.

The calculation involves:
- Hours × 3600 (seconds per hour)
- Minutes × 60 (seconds per minute) 
- Seconds (already in seconds)

```python
from datetime import time

def time_to_seconds_since_midnight(t: time) -> int:
    # Calculate total seconds since midnight (00:00:00)
    total_seconds = t.hour * 3600 + t.minute * 60 + t.second
    
    return total_seconds

# Entry point: time_to_seconds_since_midnight(t: time) -> int
```
