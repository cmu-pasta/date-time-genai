Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.

2. **Define a function**: We will create a function that accepts a date as input. The input should be a `date` object from the datetime library.

3. **Calculate the day of year**: We can use the `timetuple()` method of the date object, which returns a time.struct_time object. The `tm_yday` attribute of this object gives us the day of the year (1-366).

4. **Return the result**: Return the day of year as an integer.

```python
from datetime import date

def date_to_day_of_year(input_date: date) -> int:
    # Step 1: Get the day of year using timetuple().tm_yday
    day_of_year = input_date.timetuple().tm_yday
    
    # Step 2: Return the result as an integer
    return day_of_year

# Entry point: date_to_day_of_year(input_date: date) -> int
```
