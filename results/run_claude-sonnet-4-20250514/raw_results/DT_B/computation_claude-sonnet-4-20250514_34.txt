Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts a date object as input.
3. **Calculate the day of year**: Use the `strftime('%j')` method to get the day of the year as a zero-padded decimal number (001-366).
4. **Return the result**: Convert the string result to an integer and return it.

```python
from datetime import date

def convert_date_to_day_of_year(dt: date) -> int:
    # Step 1: Use strftime to get the day of year as a string
    day_of_year_str = dt.strftime('%j')
    
    # Step 2: Convert the string to integer and return
    day_of_year = int(day_of_year_str)
    
    return day_of_year

# Entry point: convert_date_to_day_of_year(dt: date) -> int
```
