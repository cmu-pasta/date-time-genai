Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with datetime objects.

2. **Define a function**: We will create a function that accepts two datetime objects as input parameters.

3. **Calculate the time difference**: Use subtraction between the two datetime objects to get a timedelta object representing the time period.

4. **Convert to minutes**: Convert the timedelta to total minutes by using the `total_seconds()` method and dividing by 60.

5. **Return the result**: Return the total minutes as an integer.

```python
from datetime import datetime

def calculate_total_minutes(dt1: datetime, dt2: datetime) -> int:
    # Step 1: Calculate the time difference between two datetime objects
    time_difference = abs((dt2 - dt1))  # Using abs to ensure a positive difference
    
    # Step 2: Convert the timedelta to total minutes
    total_minutes = int(time_difference.total_seconds() / 60)
    
    # Step 3: Return the result as an integer
    return total_minutes

# Entry point: calculate_total_minutes(dt1: datetime, dt2: datetime) -> int
```
