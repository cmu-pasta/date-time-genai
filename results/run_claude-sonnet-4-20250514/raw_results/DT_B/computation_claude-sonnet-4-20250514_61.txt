Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `date` class from Python's `datetime` module to work with dates.
2. **Define a function**: We will create a function that accepts a date as input and returns the day number within the week.
3. **Use the appropriate method**: Python's `date` object has an `isoweekday()` method that returns the day of the week as an integer where Monday is 1 and Sunday is 7, which matches our requirement of 1-7.
4. **Return the result**: Return the day number as an integer.

```python
from datetime import date

def get_day_number_in_week(input_date: date) -> int:
    # Use isoweekday() which returns 1-7 (Monday=1, Tuesday=2, ..., Sunday=7)
    day_number = input_date.isoweekday()
    
    return day_number

# Entry point: get_day_number_in_week(input_date: date) -> int
```
