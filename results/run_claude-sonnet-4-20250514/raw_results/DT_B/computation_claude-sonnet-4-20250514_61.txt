Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts a datetime object as input.
3. **Get the weekday number**: Use the `weekday()` method of datetime objects, which returns 0-6 (Monday=0, Sunday=6).
4. **Convert to 1-7 range**: Add 1 to the weekday result to convert from 0-6 range to 1-7 range.
5. **Return the result**: Return the day number as an integer.

```python
from datetime import datetime

def get_day_number_in_week(dt: datetime) -> int:
    # Get the weekday (0=Monday, 6=Sunday) and add 1 to make it 1-7 (Monday=1, Sunday=7)
    day_number = dt.weekday() + 1
    return day_number

# Entry point: get_day_number_in_week(dt: datetime) -> int
```
