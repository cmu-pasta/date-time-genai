Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Understand the Buddhist calendar**: The Buddhist calendar year is calculated by adding 543 years to the Gregorian year. This is based on the traditional calculation that places Buddha's death (or enlightenment) in 543 BCE.
3. **Define a function**: Create a function that accepts a datetime object as input.
4. **Extract the year**: Get the Gregorian year from the datetime object.
5. **Calculate Buddhist year**: Add 543 to the Gregorian year to get the Buddhist calendar year.
6. **Return the result**: Return the Buddhist year as an integer.

```python
from datetime import datetime

def get_buddhist_year(dt: datetime) -> int:
    # Step 1: Extract the Gregorian year from the datetime object
    gregorian_year = dt.year
    
    # Step 2: Calculate the Buddhist calendar year by adding 543
    buddhist_year = gregorian_year + 543
    
    # Step 3: Return the Buddhist year as an integer
    return buddhist_year

# Entry point: get_buddhist_year(dt: datetime) -> int
```
