Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `date` and `timedelta` classes from Python's datetime module to work with dates and perform date arithmetic.

2. **Define a function**: We will create a function that accepts a date as input and returns the last day of that month.

3. **Calculate the next month**: To find the last day of the current month, we can find the first day of the next month and then subtract one day. We need to handle the edge case where the current month is December (month 12).

4. **Create the first day of next month**: Use the calculated next month and year to create a date object for the first day of the next month.

5. **Subtract one day**: Use timedelta to subtract one day from the first day of the next month to get the last day of the current month.

6. **Return the result**: Return the calculated last day as a date object.

```python
from datetime import date, timedelta

def find_last_day_of_month(input_date: date) -> date:
    # Step 1: Get year and month from input date
    year = input_date.year
    month = input_date.month
    
    # Step 2: Calculate next month and year
    if month == 12:
        next_month = 1
        next_year = year + 1
    else:
        next_month = month + 1
        next_year = year
    
    # Step 3: Create first day of next month
    first_day_next_month = date(next_year, next_month, 1)
    
    # Step 4: Subtract one day to get last day of current month
    last_day_current_month = first_day_next_month - timedelta(days=1)
    
    # Step 5: Return the result
    return last_day_current_month

# Entry point: find_last_day_of_month(input_date: date) -> date
```
