Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts a datetime object as input.
3. **Extract year and month**: Get the year and month from the input datetime object.
4. **Calculate next month**: Determine the next month and handle the year rollover when the current month is December.
5. **Find first day of next month**: Create a datetime object for the first day of the next month.
6. **Subtract one day**: Subtract one day from the first day of next month to get the last day of the current month.
7. **Return the result**: Return the datetime object representing the last day of the month.

```python
from datetime import datetime, timedelta

def find_last_day_of_month(dt: datetime) -> datetime:
    # Step 1: Extract year and month from input datetime
    year = dt.year
    month = dt.month
    
    # Step 2: Calculate next month and handle year rollover
    if month == 12:
        next_month = 1
        next_year = year + 1
    else:
        next_month = month + 1
        next_year = year
    
    # Step 3: Create datetime for first day of next month
    first_day_next_month = datetime(next_year, next_month, 1, dt.hour, dt.minute, dt.second, dt.microsecond)
    
    # Step 4: Subtract one day to get last day of current month
    last_day_of_month = first_day_next_month - timedelta(days=1)
    
    # Step 5: Return the result
    return last_day_of_month

# Entry point: find_last_day_of_month(dt: datetime) -> datetime
```
