Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` and `timedelta` classes from Python's standard library to work with dates.

2. **Define a function**: We will create a function that accepts a year as an integer input and returns the date of Martin Luther King Jr. Day.

3. **Find the first day of January**: Create a date object for January 1st of the given year.

4. **Calculate the first Monday**: Determine what day of the week January 1st falls on, then calculate how many days to add to reach the first Monday of January.

5. **Find the third Monday**: Add 14 days (2 weeks) to the first Monday to get the third Monday.

6. **Return the result**: Return the date as a date object.

```python
from datetime import date, timedelta

def find_mlk_day(year: int) -> date:
    # Step 1: Create January 1st of the given year
    jan_1 = date(year, 1, 1)
    
    # Step 2: Find the day of the week (0=Monday, 1=Tuesday, ..., 6=Sunday)
    day_of_week = jan_1.weekday()
    
    # Step 3: Calculate days to add to get to the first Monday
    # If Jan 1 is Monday (0), we need 0 days
    # If Jan 1 is Tuesday (1), we need 6 days
    # If Jan 1 is Sunday (6), we need 1 day
    days_to_first_monday = (7 - day_of_week) % 7
    
    # Step 4: Get the first Monday of January
    first_monday = jan_1 + timedelta(days=days_to_first_monday)
    
    # Step 5: Add 14 days (2 weeks) to get the third Monday
    third_monday = first_monday + timedelta(days=14)
    
    return third_monday

# Entry point: find_mlk_day(year: int) -> date
```
