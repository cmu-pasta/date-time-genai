Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module to work with dates and the `timedelta` to perform date arithmetic.

2. **Define a function**: Create a function that accepts a year as an integer and returns the date of Martin Luther King Jr. Day as a datetime object.

3. **Find January 1st**: Create a datetime object for January 1st of the given year.

4. **Calculate the first Monday**: Determine what day of the week January 1st falls on, then calculate how many days to add to reach the first Monday of January.

5. **Calculate the third Monday**: Add 14 days (2 weeks) to the first Monday to get the third Monday, which is Martin Luther King Jr. Day.

6. **Return the result**: Return the calculated date as a datetime object.

```python
from datetime import datetime, timedelta

def find_mlk_day(year: int) -> datetime:
    # Step 1: Get January 1st of the given year
    jan_first = datetime(year, 1, 1)
    
    # Step 2: Calculate days to add to get to the first Monday
    # weekday() returns 0 for Monday, 1 for Tuesday, ..., 6 for Sunday
    days_to_first_monday = (7 - jan_first.weekday()) % 7
    
    # Step 3: Find the first Monday of January
    first_monday = jan_first + timedelta(days=days_to_first_monday)
    
    # Step 4: Add 14 days (2 weeks) to get the third Monday
    third_monday = first_monday + timedelta(days=14)
    
    return third_monday

# Entry point: find_mlk_day(year: int) -> datetime
```
