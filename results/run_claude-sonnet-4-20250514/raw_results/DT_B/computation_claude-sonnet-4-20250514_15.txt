Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` and `timedelta` modules from Python's standard library to work with dates and iterate through date ranges.

2. **Define a function**: We will create a function that accepts two datetime objects as input representing the start and end dates.

3. **Determine the date range**: We need to establish which date is earlier and which is later to properly iterate through the range.

4. **Count weekends**: We'll iterate through each date in the range and count complete weekends. A weekend is defined as a Saturday-Sunday pair. We can identify weekends by checking if a date is a Saturday (weekday() == 5) and the next day is Sunday.

5. **Return the result**: Return the count of complete weekends as an integer.

```python
from datetime import datetime, timedelta

def calculate_weekends_between_dates(start_date: datetime, end_date: datetime) -> int:
    # Ensure start_date is before end_date
    if start_date > end_date:
        start_date, end_date = end_date, start_date
    
    # Convert to date objects for easier comparison (ignore time component)
    current_date = start_date.date()
    end_date_only = end_date.date()
    
    weekend_count = 0
    
    # Iterate through each date in the range
    while current_date <= end_date_only:
        # Check if current date is Saturday (weekday() == 5)
        if current_date.weekday() == 5:
            # Check if the next day (Sunday) is still within our range
            next_day = current_date + timedelta(days=1)
            if next_day <= end_date_only:
                weekend_count += 1
        
        # Move to the next day
        current_date += timedelta(days=1)
    
    return weekend_count

# Entry point: calculate_weekends_between_dates(start_date: datetime, end_date: datetime) -> int
```
