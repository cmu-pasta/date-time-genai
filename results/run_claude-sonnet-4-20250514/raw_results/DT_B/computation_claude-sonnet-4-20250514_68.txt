Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.

2. **Define a function**: We will create a function that accepts a year as an integer input.

3. **Find September 1st**: Create a date object for September 1st of the given year.

4. **Determine the weekday**: Use the `weekday()` method to find what day of the week September 1st falls on (Monday = 0, Tuesday = 1, etc.).

5. **Calculate days to add**: Labor Day is the first Monday of September. If September 1st is already a Monday, that's Labor Day. Otherwise, we need to calculate how many days to add to reach the next Monday.

6. **Return the result**: Add the calculated number of days to September 1st and return the resulting date.

```python
from datetime import datetime, timedelta

def find_labor_day(year: int) -> datetime:
    # Step 1: Create September 1st of the given year
    sep_first = datetime(year, 9, 1)
    
    # Step 2: Find the weekday (Monday = 0, Sunday = 6)
    weekday = sep_first.weekday()
    
    # Step 3: Calculate days to add to reach the first Monday
    if weekday == 0:  # September 1st is already Monday
        days_to_add = 0
    else:  # Add days to reach the next Monday
        days_to_add = 7 - weekday
    
    # Step 4: Calculate Labor Day by adding the required days
    labor_day = sep_first + timedelta(days=days_to_add)
    
    # Step 5: Return the result as a datetime object
    return labor_day

# Entry point: find_labor_day(year: int) -> datetime
```
