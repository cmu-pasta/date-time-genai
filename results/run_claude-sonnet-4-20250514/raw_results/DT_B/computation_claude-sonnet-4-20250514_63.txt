Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts two dates as input as datetime objects.
3. **Calculate the difference**: Use subtraction to find the difference between the two `datetime` objects, which gives us a timedelta object.
4. **Convert to fortnights**: A fortnight is 14 days, so we need to divide the number of days by 14.
5. **Return the result**: Return the result as a float to handle partial fortnights accurately.

```python
from datetime import datetime

def calculate_fortnights_between_dates(dt1: datetime, dt2: datetime) -> float:
    # Step 1: Calculate the difference between the two dates
    difference = dt2 - dt1
    
    # Step 2: Get the number of days from the timedelta
    days = difference.days
    
    # Step 3: Convert days to fortnights (1 fortnight = 14 days)
    fortnights = days / 14.0
    
    # Step 4: Return the result as a float
    return fortnights

# Entry point: calculate_fortnights_between_dates(dt1: datetime, dt2: datetime) -> float
```
