Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts two dates as input as datetime objects.
3. **Calculate the difference**: Use subtraction to find the difference between the two `datetime` objects, which gives us a timedelta object.
4. **Convert to fortnights**: Since a fortnight is 14 days, we divide the total days by 14 to get the number of fortnights.
5. **Return the result**: Return the result as an integer representing the number of fortnights.

```python
from datetime import datetime

def calculate_fortnights_between_dates(dt1: datetime, dt2: datetime) -> int:
    # Step 1: Calculate the difference between the two dates
    difference = abs((dt2 - dt1).days)  # Using abs to ensure a positive difference
    
    # Step 2: Convert days to fortnights (1 fortnight = 14 days)
    fortnights = difference // 14  # Using integer division to get whole fortnights
    
    # Step 3: Return the result as an integer
    return fortnights

# Entry point: calculate_fortnights_between_dates(dt1: datetime, dt2: datetime) -> int
```
