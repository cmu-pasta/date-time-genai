Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with datetime objects.
2. **Define a function**: We will create a function that accepts two datetime objects as input.
3. **Calculate the midpoint**: To find the midpoint between two datetimes, we need to:
   - Calculate the time difference between the two datetimes (this gives us a timedelta)
   - Divide this difference by 2 to get half the duration
   - Add this half-duration to the earlier datetime to get the midpoint
4. **Return the result**: Return the calculated midpoint datetime.

```python
from datetime import datetime, timedelta

def find_midpoint_datetime(dt1: datetime, dt2: datetime) -> datetime:
    # Step 1: Calculate the difference between the two datetimes
    time_difference = dt2 - dt1
    
    # Step 2: Calculate half of the time difference
    half_difference = time_difference / 2
    
    # Step 3: Add half the difference to the first datetime to get the midpoint
    midpoint = dt1 + half_difference
    
    # Step 4: Return the midpoint datetime
    return midpoint

# Entry point: find_midpoint_datetime(dt1: datetime, dt2: datetime) -> datetime
```
