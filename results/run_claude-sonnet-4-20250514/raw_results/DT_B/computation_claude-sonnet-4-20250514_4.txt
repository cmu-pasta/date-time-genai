Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module and `zoneinfo` module from Python's standard library to work with dates, times, and timezones.

2. **Define a function**: We will create a function that accepts a datetime object and two timezone objects (source and target timezones).

3. **Handle timezone awareness**: If the input datetime is timezone-naive, we need to localize it to the source timezone first.

4. **Convert timezone**: Use the `astimezone()` method to convert the datetime from the source timezone to the target timezone.

5. **Return the result**: Return the converted datetime object in the target timezone.

```python
from datetime import datetime
from zoneinfo import ZoneInfo

def convert_timezone(dt: datetime, source_tz: ZoneInfo, target_tz: ZoneInfo) -> datetime:
    # Step 1: Check if the datetime is timezone-aware
    if dt.tzinfo is None:
        # If timezone-naive, localize it to the source timezone
        dt_aware = dt.replace(tzinfo=source_tz)
    else:
        # If already timezone-aware, ensure it's in the source timezone
        dt_aware = dt.astimezone(source_tz)
    
    # Step 2: Convert to the target timezone
    converted_dt = dt_aware.astimezone(target_tz)
    
    # Step 3: Return the converted datetime
    return converted_dt

# Entry point: convert_timezone(dt: datetime, source_tz: ZoneInfo, target_tz: ZoneInfo) -> datetime
```
