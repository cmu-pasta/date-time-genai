Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts two dates as input - the birth date and a reference date (both as datetime objects).
3. **Calculate the age difference**: Use subtraction to find the difference between the reference date and birth date, which gives us a timedelta object.
4. **Extract total days**: Get the total number of days from the timedelta object using the `.days` attribute.
5. **Return the result**: Return the age in days as an integer.

```python
from datetime import datetime

def calculate_age_in_days(birth_date: datetime, reference_date: datetime) -> int:
    # Step 1: Calculate the difference between reference date and birth date
    age_difference = reference_date - birth_date
    
    # Step 2: Extract the total number of days from the timedelta
    total_days = age_difference.days
    
    # Step 3: Return the age in total days as an integer
    return total_days

# Entry point: calculate_age_in_days(birth_date: datetime, reference_date: datetime) -> int
```
