Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` and `timedelta` classes from Python's datetime module to work with dates and time differences.

2. **Define a function**: We will create a function that accepts a datetime object as input representing the given date.

3. **Calculate the date 100 days before**: Use the `timedelta` class to represent 100 days and subtract it from the given date using basic arithmetic operations.

4. **Return the result**: Return the resulting datetime object that represents the date exactly 100 days before the input date.

```python
from datetime import datetime, timedelta

def find_date_100_days_before(dt: datetime) -> datetime:
    # Step 1: Create a timedelta object representing 100 days
    hundred_days = timedelta(days=100)
    
    # Step 2: Subtract 100 days from the given date
    result_date = dt - hundred_days
    
    # Step 3: Return the resulting date
    return result_date

# Entry point: find_date_100_days_before(dt: datetime) -> datetime
```
