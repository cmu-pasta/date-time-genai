Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` and `timedelta` classes from Python's standard datetime library to work with dates and time differences.

2. **Define a function**: We will create a function that accepts a date as input. We'll use a datetime object to represent the date.

3. **Calculate the date 100 days before**: Use the `timedelta` class to subtract exactly 100 days from the given date.

4. **Return the result**: Return the calculated date as a datetime object.

```python
from datetime import datetime, timedelta

def find_date_100_days_before(given_date: datetime) -> datetime:
    # Step 1: Create a timedelta object representing 100 days
    hundred_days = timedelta(days=100)
    
    # Step 2: Subtract 100 days from the given date
    result_date = given_date - hundred_days
    
    # Step 3: Return the calculated date
    return result_date

# Entry point: find_date_100_days_before(given_date: datetime) -> datetime
```
