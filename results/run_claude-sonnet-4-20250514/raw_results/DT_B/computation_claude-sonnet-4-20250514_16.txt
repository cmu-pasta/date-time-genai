Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with timestamps and datetime objects.
2. **Define a function**: We will create a function that accepts a Unix timestamp as input (as a float representing seconds since epoch).
3. **Convert timestamp to datetime**: Use `datetime.fromtimestamp()` to convert the Unix timestamp to a datetime object.
4. **Return the result**: Return the datetime object which represents the human-readable datetime.

```python
from datetime import datetime

def convert_unix_to_datetime(timestamp: float) -> datetime:
    # Step 1: Convert Unix timestamp to datetime object
    dt = datetime.fromtimestamp(timestamp)
    
    # Step 2: Return the datetime object
    return dt

# Entry point: convert_unix_to_datetime(timestamp: float) -> datetime
```
