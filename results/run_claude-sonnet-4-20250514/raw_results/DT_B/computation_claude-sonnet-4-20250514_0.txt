Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts two datetime objects as input representing the start and end dates.
3. **Determine the date range**: We need to iterate through all dates between the two input dates to check which ones are business days.
4. **Identify business days**: Business days are typically Monday through Friday (weekdays 0-4 in Python's weekday() method, where Monday=0 and Sunday=6).
5. **Count business days**: Iterate through each day in the range and count only those that fall on weekdays.
6. **Return the result**: Return the count as an integer.

```python
from datetime import datetime, timedelta

def calculate_business_days(start_date: datetime, end_date: datetime) -> int:
    # Ensure start_date is before end_date
    if start_date > end_date:
        start_date, end_date = end_date, start_date
    
    # Initialize business day counter
    business_days = 0
    
    # Start from the start_date
    current_date = start_date.date()
    end_date_only = end_date.date()
    
    # Iterate through each day between start and end dates
    while current_date <= end_date_only:
        # Check if current day is a weekday (Monday=0 to Friday=4)
        if current_date.weekday() < 5:
            business_days += 1
        
        # Move to next day
        current_date += timedelta(days=1)
    
    return business_days

# Entry point: calculate_business_days(start_date: datetime, end_date: datetime) -> int
```
