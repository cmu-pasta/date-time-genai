Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts a date as input. This can be a `date` or `datetime` object.
3. **Determine the day name**: Use the `strftime` method with the format code '%A' to get the full day name (e.g., "Monday", "Tuesday").
4. **Return the result**: Return the day name as a string.

```python
from datetime import date, datetime

def get_day_name(input_date: date) -> str:
    # Step 1: Use strftime to get the full day name
    # '%A' format code returns the full weekday name
    day_name = input_date.strftime('%A')
    
    # Step 2: Return the day name
    return day_name

# Entry point: get_day_name(input_date: date) -> str
```
