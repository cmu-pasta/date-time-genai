Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module to work with time objects.
2. **Define a function**: Create a function that accepts a time object (in 12-hour format) and a boolean indicating whether it's PM.
3. **Handle the conversion logic**: 
   - For AM times: if hour is 12, convert to 0 (midnight), otherwise keep the same
   - For PM times: if hour is 12, keep as 12 (noon), otherwise add 12 to convert to 24-hour format
4. **Return the result**: Return a new time object in 24-hour format.

```python
from datetime import time

def convert_12_to_24_hour(time_12h: time, is_pm: bool) -> time:
    # Extract components from the input time
    hour = time_12h.hour
    minute = time_12h.minute
    second = time_12h.second
    microsecond = time_12h.microsecond
    
    # Convert based on AM/PM
    if is_pm:  # PM case
        if hour == 12:
            # 12 PM stays as 12 (noon)
            new_hour = 12
        else:
            # Add 12 to convert PM hours to 24-hour format
            new_hour = hour + 12
    else:  # AM case
        if hour == 12:
            # 12 AM becomes 0 (midnight)
            new_hour = 0
        else:
            # AM hours remain the same (1-11 AM)
            new_hour = hour
    
    # Create and return the new time object in 24-hour format
    return time(new_hour, minute, second, microsecond)

# Entry point: convert_12_to_24_hour(time_12h: time, is_pm: bool) -> time
```
