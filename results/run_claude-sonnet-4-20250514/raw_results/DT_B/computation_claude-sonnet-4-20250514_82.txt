Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `date` class from Python's `datetime` module to work with dates.

2. **Define a function**: We will create a function that accepts a date as input and returns the corresponding week number of the year.

3. **Use the isocalendar() method**: The `isocalendar()` method returns a tuple containing (ISO year, ISO week number, ISO weekday). The ISO week number is what we need, and it ranges from 1 to 53.

4. **Extract the week number**: From the tuple returned by `isocalendar()`, we extract the second element (index 1) which represents the week number.

5. **Return the result**: Return the week number as an integer.

```python
from datetime import date

def date_to_week_of_year(input_date: date) -> int:
    # Use isocalendar() to get the ISO week number (1-53)
    # isocalendar() returns a tuple: (year, week, weekday)
    week_number = input_date.isocalendar()[1]
    
    return week_number

# Entry point: date_to_week_of_year(input_date: date) -> int
```
