Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the `datetime` module from Python's standard library to work with dates.
2. **Define a function**: We will create a function that accepts a date as input. This can be provided as a datetime object.
3. **Extract the week number**: Use the `isocalendar()` method which returns a tuple containing (year, week, weekday). We need the week component.
4. **Return the result**: Return the week number as an integer (1-53 range).

```python
from datetime import datetime

def get_week_of_year(dt: datetime) -> int:
    # Step 1: Get the ISO calendar representation (year, week, weekday)
    iso_calendar = dt.isocalendar()
    
    # Step 2: Extract the week number (second element in the tuple)
    week_number = iso_calendar[1]
    
    # Step 3: Return the week number as integer
    return week_number

# Entry point: get_week_of_year(dt: datetime) -> int
```
