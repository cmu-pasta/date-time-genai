Let's think step by step to solve this problem.
1. Import the necessary component from the datetime library to work with calendar dates.
2. Define a function that accepts a year as an integer input.
3. Attempt to construct February 29 of the given year using datetime.date.
4. If the construction succeeds, the year is a leap year; if it raises a ValueError, it is not a leap year.
5. Return the result as a boolean.

```python
from datetime import date

def is_leap_year(year: int) -> bool:
    """
    Determine if a given year is a leap year using the datetime library.
    
    Args:
        year (int): The year to check (1..9999).
    
    Returns:
        bool: True if the year is a leap year, False otherwise.
    """
    try:
        # If February 29 exists in the given year, it's a leap year.
        _ = date(year, 2, 29)
        return True
    except ValueError:
        return False

# Entry point: is_leap_year(year: int) -> bool
```
