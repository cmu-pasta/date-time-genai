Let's think step by step to solve this problem.
1. Import the required classes from the datetime library.
2. Define a function that accepts two time objects representing times on the same day.
3. Combine each time with a fixed common date to create comparable datetime objects.
4. Subtract the datetime objects to get a timedelta.
5. Convert the absolute timedelta to an integer count of minutes using floor division.
6. Return the integer minute difference.

```python
from datetime import datetime, date, time, timedelta

def minutes_between(t1: time, t2: time) -> int:
    # Step 1: Use a fixed common date to ensure both times are on the same day
    common_date = date(2000, 1, 1)
    dt1 = datetime.combine(common_date, t1)
    dt2 = datetime.combine(common_date, t2)
    
    # Step 2: Compute the difference and convert to absolute minutes
    delta = abs(dt2 - dt1)
    minutes = delta // timedelta(minutes=1)  # Floor division to get integer minutes
    
    # Step 3: Return the integer number of minutes
    return int(minutes)

# Entry point: minutes_between(t1: time, t2: time) -> int
```
