Let's think step by step to solve this problem.
1. Import the datetime class from the datetime module to validate leap years via date construction.
2. Define a function that accepts two integers representing years.
3. Ensure the range is correctly ordered by swapping if needed so the start year is less than or equal to the end year.
4. Iterate over each year in the inclusive range and attempt to construct February 29; if successful, it’s a leap year.
5. Count and return the number of leap years as an integer.

```python
from datetime import datetime

def count_leap_years_between(year1: int, year2: int) -> int:
    """
    Count the number of leap years between two years, inclusive.
    A year is considered leap if February 29 exists for that year.
    """
    # Ensure start_year <= end_year without using tuples
    if year1 <= year2:
        start_year = year1
        end_year = year2
    else:
        start_year = year2
        end_year = year1

    count = 0
    year = start_year
    while year <= end_year:
        try:
            # If this succeeds, the year is a leap year
            datetime(year, 2, 29)
            count += 1
        except ValueError:
            # Not a leap year
            pass
        year += 1

    return count

# Entry point: count_leap_years_between(year1: int, year2: int) -> int
```
