Let's think step by step to solve this problem.
1. Import the required classes from the datetime library.
2. Define a function that accepts a year as an integer.
3. Create date objects for the first and last day of the given year.
4. Iterate from the start date to the end date, counting days that fall on weekdays (Monday to Friday).
5. Return the total count as an integer.

```python
from datetime import date, timedelta

def calculate_trading_days_in_year(year: int) -> int:
    """
    Calculate the number of trading days (Monday through Friday) in a given year.
    
    Args:
        year (int): The year for which to calculate trading days.
    
    Returns:
        int: The count of trading days in the specified year.
    """
    start = date(year, 1, 1)
    end = date(year, 12, 31)
    
    count = 0
    current = start
    one_day = timedelta(days=1)
    
    while current <= end:
        # weekday(): Monday=0, Sunday=6
        wd = current.weekday()
        if 0 <= wd <= 4:
            count += 1
        current += one_day
    
    return count

# Entry point: calculate_trading_days_in_year(year: int) -> int
```
