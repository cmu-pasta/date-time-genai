Let's think step by step to solve this problem.
1. Import the required type from the datetime module.
2. Define a function that takes a date as input.
3. Compute the difference between the given date and the first day of its year.
4. Add 1 to convert from zero-based difference to the 1-366 day-of-year count.
5. Return the result as an integer.

```python
from datetime import date

def day_of_year(d: date) -> int:
    """
    Convert a date to its corresponding day of the year (1-366).
    """
    start_of_year = date(d.year, 1, 1)
    return (d - start_of_year).days + 1

# Entry point: day_of_year(d: date) -> int
```
