Let's think step by step to solve this problem.
1. Import the required classes from the datetime module.
2. Define a function that accepts a date input.
3. Use the built-in isocalendar method to obtain the ISO week number for the given date.
4. Return the week number as an integer.

```python
from datetime import date

def week_number_of_year(d: date) -> int:
    """
    Calculate the ISO week number of the year for a given date.
    
    Parameters:
    - d: date
    
    Returns:
    - int: ISO week number (1-53)
    """
    return d.isocalendar().week

# Entry point: week_number_of_year(d: date) -> int
```
