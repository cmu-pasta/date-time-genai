Let's think step by step to solve this problem.
1. Identify if the given Gregorian year is a leap year using only datetime by attempting to construct February 29.
2. Determine the Gregorian date on which the Saka year starts: March 21 if the Gregorian year is leap, otherwise March 22.
3. Decide whether the input date falls on or after the Saka New Year of its Gregorian year; if not, use the previous year's Saka New Year.
4. Compute the Saka year relative to Gregorian: if on/after Saka start, Saka year = Gregorian year - 78; otherwise Saka year = Gregorian year - 79.
5. Calculate the offset in days from the Saka New Year start date.
6. Determine month lengths in the Saka year: Chaitra has 31 days if the Saka year starts in a Gregorian leap year, otherwise 30; months 2–7 have 31 days; months 8–12 have 30 days.
7. Map the day offset to Saka month and day.
8. Return the Saka date as a datetime.date with year set to the Saka year and month/day set to the Saka calendar values.

```python
from datetime import date

def _is_gregorian_leap(year: int) -> bool:
    # Use datetime.date construction to test for Feb 29 existence
    try:
        date(year, 2, 29)
        return True
    except ValueError:
        return False

def gregorian_to_saka(gregorian_date: date) -> date:
    # Determine Saka New Year start for the relevant Gregorian year
    gy = gregorian_date.year
    gy_is_leap = _is_gregorian_leap(gy)
    saka_start_current = date(gy, 3, 21 if gy_is_leap else 22)

    if gregorian_date >= saka_start_current:
        saka_year = gy - 78
        saka_year_start = saka_start_current
        chaitra_len = 31 if gy_is_leap else 30
    else:
        prev_gy = gy - 1
        prev_is_leap = _is_gregorian_leap(prev_gy)
        saka_year = gy - 79
        saka_year_start = date(prev_gy, 3, 21 if prev_is_leap else 22)
        chaitra_len = 31 if prev_is_leap else 30

    # Compute days since start of Saka year
    days_since_start = (gregorian_date - saka_year_start).days  # 0-based

    # Month lengths in Saka year starting from Chaitra
    month_lengths = (
        chaitra_len, 31, 31, 31, 31, 31, 31, 30, 30, 30, 30, 30
    )

    # Map day offset to month and day
    month = 1
    remaining = days_since_start
    for ml in month_lengths:
        if remaining < ml:
            day = remaining + 1
            break
        remaining -= ml
        month += 1

    # Return as a datetime.date representing the Saka calendar components
    return date(saka_year, month, day)
```
