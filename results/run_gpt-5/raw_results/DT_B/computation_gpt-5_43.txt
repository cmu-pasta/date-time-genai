Let's think step by step to solve this problem.
1. Import the required type from the datetime library.
2. Define a function that accepts a date input.
3. Compute the weekday index using the date's weekday() method.
4. Determine if the index corresponds to Saturday or Sunday.
5. Return the result as a boolean.

```python
from datetime import date

def is_weekend(d: date) -> bool:
    """
    Determine if the given date falls on a weekend.
    Weekend days are Saturday (5) and Sunday (6) according to date.weekday().
    """
    weekday_index = d.weekday()  # Monday=0, Sunday=6
    return weekday_index >= 5

# Entry point: is_weekend(d: date) -> bool
```
