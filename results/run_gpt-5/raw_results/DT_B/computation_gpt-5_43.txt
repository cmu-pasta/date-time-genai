Let's think step by step to solve this problem.
1. Import the required type from the datetime library.
2. Define a function that accepts a date input.
3. Use the date.weekday() method where 0=Monday, ..., 5=Saturday, 6=Sunday.
4. Determine if the weekday index corresponds to Saturday or Sunday (>= 5).
5. Return the result as a boolean.

```python
from datetime import date

def is_weekend(d: date) -> bool:
    """
    Determine if the given date falls on a weekend.

    Args:
        d (date): The date to check.

    Returns:
        bool: True if the date is Saturday or Sunday, otherwise False.
    """
    # weekday(): Monday=0, Tuesday=1, ..., Saturday=5, Sunday=6
    return d.weekday() >= 5

# Entry point: is_weekend(d: date) -> bool
```
