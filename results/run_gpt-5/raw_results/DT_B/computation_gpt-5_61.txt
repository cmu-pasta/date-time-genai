Let's think step by step to solve this problem.
1. Import the required type from the datetime library.
2. Define a function that takes a date as input.
3. Use the date's isoweekday() method to get the day number (Monday=1, Sunday=7).
4. Return the integer result.

```python
from datetime import date

def day_number_in_week(d: date) -> int:
    # Returns ISO weekday number: Monday=1, ..., Sunday=7
    return d.isoweekday()

# Entry point: day_number_in_week(d: date) -> int
```
