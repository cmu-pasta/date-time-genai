Let's think step by step to solve this problem.
1. Import the required classes from the datetime library.
2. Define a function that accepts a date as input.
3. Subtract a timedelta of 100 days from the given date.
4. Return the resulting date.

```python
from datetime import date, timedelta

def date_100_days_before(d: date) -> date:
    # Subtract 100 days using timedelta and return the resulting date
    return d - timedelta(days=100)

# Entry point: date_100_days_before(d: date) -> date
```
