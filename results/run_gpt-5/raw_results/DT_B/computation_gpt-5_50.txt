Let's think step by step to solve this problem.
1. Import the necessary classes (date, timedelta) from the datetime module.
2. Define a function that accepts a date input.
3. Create a timedelta of 100 days.
4. Subtract the timedelta from the given date to get the target date.
5. Return the resulting date.

```python
from datetime import date, timedelta

def find_date_100_days_before(given_date: date) -> date:
    """
    Return the date that is exactly 100 days before the given date.

    Parameters:
        given_date (date): The reference date.

    Returns:
        date: The date exactly 100 days before the given date.
    """
    hundred_days = timedelta(days=100)
    result_date = given_date - hundred_days
    return result_date

# Entry point: find_date_100_days_before(given_date: date) -> date
```
