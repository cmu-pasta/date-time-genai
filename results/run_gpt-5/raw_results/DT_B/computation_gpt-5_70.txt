Let's think step by step to solve this problem.
1. Use a well-known algorithm to convert a Julian calendar date to a Julian Day Number (JDN).
2. Convert the JDN to the corresponding proleptic Gregorian calendar date.
3. Construct and return a datetime.date object representing the Gregorian date.

```python
from datetime import date

def julian_to_gregorian(year: int, month: int, day: int) -> date:
    """
    Convert a Julian calendar date to a Gregorian calendar date.
    Returns a proleptic Gregorian date as datetime.date.
    Valid for years in Python's datetime range (1..9999).
    """
    # Step 1: Julian calendar date to Julian Day Number (JDN)
    a = (14 - month) // 12
    y = year + 4800 - a
    m = month + 12 * a - 3
    jdn = day + (153 * m + 2) // 5 + 365 * y + y // 4 - 32083

    # Step 2: JDN to proleptic Gregorian date
    a2 = jdn + 32044
    b = (4 * a2 + 3) // 146097
    c = a2 - (146097 * b) // 4
    d = (4 * c + 3) // 1461
    e = c - (1461 * d) // 4
    m2 = (5 * e + 2) // 153

    day_g = e - (153 * m2 + 2) // 5 + 1
    month_g = m2 + 3 - 12 * (m2 // 10)
    year_g = 100 * b + d - 4800 + (m2 // 10)

    # Step 3: Return as datetime.date (Gregorian)
    return date(year_g, month_g, day_g)
```
