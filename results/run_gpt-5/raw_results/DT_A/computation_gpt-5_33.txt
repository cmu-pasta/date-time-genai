Let's think step by step to solve this problem.
1. Import the necessary classes (date, time, datetime) from the datetime module.
2. Define a function that accepts a date and two times as inputs.
3. Combine the date with each time to form two datetime objects on the same day.
4. Subtract the datetime objects to get a timedelta representing the difference.
5. Convert the timedelta to total minutes (as a non-negative integer).
6. Return the integer number of minutes.

```python
from datetime import date, time, datetime

def minutes_between_same_day(d: date, t1: time, t2: time) -> int:
    # Combine the given date with each time to create datetime objects on the same day
    dt1 = datetime.combine(d, t1)
    dt2 = datetime.combine(d, t2)
    
    # Compute the difference as a timedelta
    delta = dt2 - dt1
    
    # Convert the difference to a non-negative integer number of minutes
    minutes = int(abs(delta.total_seconds()) // 60)
    return minutes

# Entry point: minutes_between_same_day(d: date, t1: time, t2: time) -> int
```
