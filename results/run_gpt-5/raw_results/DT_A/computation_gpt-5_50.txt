Let's think step by step to solve this problem.
1. Import the required classes (date and timedelta) from the datetime module.
2. Define a function that accepts a date as input without default values.
3. Subtract a timedelta of 100 days from the given date.
4. Return the resulting date.

```python
from datetime import date, timedelta

def date_100_days_before(d: date) -> date:
    # Subtract exactly 100 days from the provided date
    return d - timedelta(days=100)

# Entry point: date_100_days_before(d: date) -> date
```
