Let's think step by step to solve this problem.
1. Accept a target year (integer) and a timezone (zoneinfo.ZoneInfo) as inputs.
2. Iterate over each calendar day of the given year and evaluate the timezone-aware datetime at local noon to determine whether DST is active on that day.
3. Detect the first day where DST is inactive while the previous day was in DST; that day is the DST end date for that year in the given timezone.
4. If no such transition is found (e.g., the timezone does not observe DST that year), return the minimal date value as a sentinel (0001-01-01).

```python
from datetime import date, datetime, timedelta
from zoneinfo import ZoneInfo

def find_dst_end_date(year: int, tz: ZoneInfo) -> date:
    """
    Find the calendar date when daylight saving time ends for a given year and timezone.
    
    The function samples each day at local noon to detect the transition from DST to standard time.
    If no DST end is detected for the specified year (e.g., no DST observed), returns date.min (0001-01-01).
    """
    if year < 1 or year > 9999:
        raise ValueError("year must be in the range 1..9999")

    start_day = date(year, 1, 1)
    end_day = date(year, 12, 31)

    # Determine DST status at local noon for each day
    prev_is_dst = None
    current_day = start_day
    while current_day <= end_day:
        # Local noon avoids ambiguity around transition times (typically near 02:00)
        local_dt = datetime(current_day.year, current_day.month, current_day.day, 12, tzinfo=tz)
        is_dst = (local_dt.dst() != timedelta(0))

        if prev_is_dst is True and is_dst is False:
            # DST ended at some point between previous day and this day -> return this date
            return current_day

        prev_is_dst = is_dst if prev_is_dst is not None else is_dst
        current_day += timedelta(days=1)

    # No DST end detected in this year for this timezone
    return date.min
```
