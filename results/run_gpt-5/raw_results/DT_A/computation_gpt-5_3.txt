Let's think step by step to solve this problem.
1. Import the necessary classes from the datetime module to work with dates.
2. Define a helper function to check if a year is a leap year using Gregorian calendar rules.
3. Define the main function that takes a date (or datetime) as input, starts from the following year, and iterates forward to find the next leap year.
4. Return the year of the next leap year as an integer.

```python
from datetime import date, datetime

def _is_leap_year(year: int) -> bool:
    """Return True if the given Gregorian year is a leap year."""
    return (year % 4 == 0) and (year % 100 != 0 or year % 400 == 0)

def next_leap_year_after(given_date: date) -> int:
    """
    Determine the next leap year strictly after the given date.
    Accepts a datetime.date (a datetime.datetime is also acceptable since it subclasses date).
    Returns the year as an integer.
    """
    year = given_date.year + 1
    while not _is_leap_year(year):
        year += 1
    return year
```
