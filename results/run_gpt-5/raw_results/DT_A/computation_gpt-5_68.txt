Let's think step by step to solve this problem.
1. Import the required classes from the datetime module: date and timedelta.
2. Accept the target year as an integer input.
3. Construct a date for September 1st of the given year.
4. Determine the weekday of September 1st (Monday=0, Sunday=6).
5. Compute the offset in days to the first Monday using modular arithmetic.
6. Add the offset to September 1st to obtain Labor Day and return it as a date.

```python
from datetime import date, timedelta

def find_labor_day(year: int) -> date:
    # Step 1: Start at September 1st of the given year
    sept_first = date(year, 9, 1)
    # Step 2: Calculate weekday (Monday=0, Sunday=6)
    weekday = sept_first.weekday()
    # Step 3: Compute days to the first Monday
    days_to_monday = (7 - weekday) % 7
    # Step 4: Determine Labor Day date
    labor_day = sept_first + timedelta(days=days_to_monday)
    return labor_day

# Entry point: find_labor_day(year: int) -> date
```
