Let's think step by step to solve this problem.
1. Import the required classes from the standard datetime library.
2. Define a function that accepts two time objects as inputs.
3. Combine each time with a fixed reference date to create comparable datetime objects.
4. If the end time is earlier than the start time, assume the period crosses midnight and add one day to the end datetime.
5. Compute the timedelta between the two datetimes.
6. Convert the timedelta to total minutes and return it as an integer.

```python
from datetime import datetime, date, time, timedelta

def total_minutes_between(start: time, end: time) -> int:
    """
    Calculate the total whole minutes in the time period between two times.
    If end is earlier than start, the period is assumed to cross midnight into the next day.

    Args:
        start (time): The starting time.
        end (time): The ending time.

    Returns:
        int: The total number of whole minutes between start and end.
    """
    reference_day = date(1900, 1, 1)
    start_dt = datetime.combine(reference_day, start)
    end_dt = datetime.combine(reference_day, end)

    if end_dt < start_dt:
        end_dt += timedelta(days=1)

    delta = end_dt - start_dt
    total_minutes = int(delta.total_seconds() // 60)
    return total_minutes
```
