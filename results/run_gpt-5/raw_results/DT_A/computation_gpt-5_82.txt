Let's think step by step to solve this problem.
1. Import the required type from the datetime library.
2. Define a function that accepts a date input.
3. Compute the ISO week number (1-53) using the date's isocalendar.
4. Return the week number as an integer.

```python
from datetime import date

def date_to_week_of_year(d: date) -> int:
    # Compute the ISO week number for the given date (range 1-53)
    return d.isocalendar().week

# Entry point: date_to_week_of_year(d: date) -> int
```
