Let's think step by step to solve this problem.
1. Define “work weeks” as complete sets of 5 weekdays (Monday–Friday).
2. Compute the number of days between the two dates, exclusive of the end date, ensuring the order is from earlier to later.
3. Calculate the number of weekdays in that range using arithmetic: weekdays in full weeks plus weekdays in the remaining days.
4. Divide the total weekdays by 5 (integer division) to get the number of complete work weeks.
5. Return the result as an integer.

```python
import pendulum

def calculate_work_weeks_between(start: pendulum.Date, end: pendulum.Date) -> int:
    """
    Calculate the number of complete work weeks (Mon–Fri) between two dates.
    The calculation considers days in the half-open interval [start, end),
    i.e., it includes 'start' and excludes 'end'.
    """
    # Ensure chronological order
    if end < start:
        start, end = end, start

    # Total days in the range [start, end)
    total_days = end.diff(start).in_days()

    # Full weeks contribution
    full_weeks = total_days // 7
    weekdays = full_weeks * 5

    # Remaining days contribution
    rem = total_days % 7
    start_wd = start.day_of_week  # Monday=0 ... Sunday=6

    # Count weekdays in the remaining span (at most 6 iterations)
    for i in range(rem):
        if (start_wd + i) % 7 < 5:
            weekdays += 1

    # Number of complete work weeks
    work_weeks = weekdays // 5
    return work_weeks
```
