Let's think step by step to solve this problem.
1. Import the pendulum library to work with timestamps.
2. Define a function that accepts two pendulum.DateTime timestamps.
3. Subtract the two timestamps to obtain a pendulum.Duration.
4. Convert the duration to milliseconds by using total_seconds() * 1000 and take the absolute value.
5. Return the result as an integer.

```python
import pendulum

def calculate_milliseconds_between(ts1: pendulum.DateTime, ts2: pendulum.DateTime) -> int:
    """
    Calculate the absolute duration in milliseconds between two pendulum.DateTime timestamps.
    """
    duration: pendulum.Duration = ts2 - ts1
    milliseconds: int = int(abs(round(duration.total_seconds() * 1000)))
    return milliseconds
```
