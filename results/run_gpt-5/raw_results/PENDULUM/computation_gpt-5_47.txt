Let's think step by step to solve this problem.
1. Receive the target year as an integer input.
2. Create a pendulum.Date representing May 31st of that year.
3. Determine the weekday of May 31st (0=Monday, ..., 6=Sunday).
4. Subtract that many days to get the last Monday in May.
5. Return the resulting pendulum.Date.

```python
import pendulum

def memorial_day(year: int) -> pendulum.Date:
    """
    Compute Memorial Day (last Monday of May) for the given year.
    Returns a pendulum.Date.
    """
    may_31 = pendulum.date(year, 5, 31)
    # weekday(): 0=Monday, ..., 6=Sunday
    offset = may_31.weekday()
    last_monday = may_31.subtract(days=offset)
    return last_monday

# Entry point: memorial_day(year: int) -> pendulum.Date
```
