2. Accept an integer year as input.
3. Use the Meeus/Jones/Butcher algorithm to compute the month and day of Easter Sunday for the given year in the Gregorian calendar.
4. Construct and return a pendulum.Date representing Easter Sunday.

```python
import pendulum

def easter_sunday_date(year: int) -> pendulum.Date:
    """
    Compute Easter Sunday for a given Gregorian year using the
    Meeus/Jones/Butcher algorithm and return it as a pendulum.Date.
    """
    # Algorithm variables
    a = year % 19
    b = year // 100
    c = year % 100
    d = b // 4
    e = b % 4
    f = (b + 8) // 25
    g = (b - f + 1) // 3
    h = (19 * a + b - d - g + 15) % 30
    i = c // 4
    k = c % 4
    l = (32 + 2 * e + 2 * i - h - k) % 7
    m = (a + 11 * h + 22 * l) // 451

    month = (h + l - 7 * m + 114) // 31  # 3 = March, 4 = April
    day = ((h + l - 7 * m + 114) % 31) + 1

    # Return as pendulum.Date
    return pendulum.date(year, month, day)
```
