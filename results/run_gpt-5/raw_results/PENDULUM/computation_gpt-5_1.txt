Let's think step by step to solve this problem.
1. Import the pendulum library to work with timezone-aware timestamps.
2. Define a function that accepts two pendulum.DateTime objects as inputs.
3. Use pendulum's diff method to compute the exact Duration between the two timestamps.
4. Return the resulting pendulum.Duration, which correctly accounts for daylight saving time transitions.

```python
import pendulum

def calculate_exact_time_difference(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> pendulum.Duration:
    """
    Calculate the exact time difference between two pendulum.DateTime timestamps,
    correctly accounting for timezone and daylight saving time transitions.

    The result is a signed pendulum.Duration representing dt2 - dt1.
    """
    # Compute the signed duration difference (dt2 - dt1).
    # Pendulum's timezone-aware arithmetic respects DST transitions.
    duration: pendulum.Duration = dt2.diff(dt1, absolute=False)
    return duration

# Entry point: calculate_exact_time_difference(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> pendulum.Duration
```
