Let's think step by step to solve this problem.
1. Import the pendulum library to work with dates.
2. Define a function that accepts a pendulum.Date as input.
3. Use the subtract method to go back exactly 100 days.
4. Return the resulting pendulum.Date.

```python
import pendulum

def date_100_days_before(given_date: pendulum.Date) -> pendulum.Date:
    """
    Return the date that is exactly 100 days before the given pendulum.Date.
    """
    return given_date.subtract(days=100)

# Entry point: date_100_days_before(given_date: pendulum.Date) -> pendulum.Date
```
