Let's think step by step to solve this problem.
1. Import the pendulum library to work with timezone-aware DateTime and Duration types.
2. Define a function that accepts two pendulum.DateTime instances (potentially in different time zones) and an optional boolean to control absolute/signed difference.
3. Convert both DateTime inputs to their Unix timestamps (int_timestamp), which are in UTC, ensuring time zones are properly accounted for.
4. Compute the difference in seconds between the two timestamps.
5. If requested, take the absolute value to get a non-negative duration.
6. Build and return a pendulum.Duration from the computed seconds.

```python
import pendulum

def timezone_aware_difference(dt1: pendulum.DateTime, dt2: pendulum.DateTime, absolute: bool = True) -> pendulum.Duration:
    """
    Calculate the time difference between two timezone-aware pendulum.DateTime objects.
    The computation accounts for their respective time zones by comparing their Unix timestamps.
    
    Parameters:
        dt1 (pendulum.DateTime): The first datetime.
        dt2 (pendulum.DateTime): The second datetime.
        absolute (bool): If True, returns the absolute difference; if False, returns a signed duration
                         (positive if dt2 occurs after dt1, negative otherwise).
    
    Returns:
        pendulum.Duration: The time difference as a Duration.
    """
    # Convert both datetimes to their UTC-based Unix timestamps to account for time zones
    seconds_diff = dt2.int_timestamp - dt1.int_timestamp

    # Apply absolute value if requested
    if absolute:
        seconds_diff = abs(seconds_diff)

    # Construct a Duration representing the difference
    return pendulum.duration(seconds=seconds_diff)
```
