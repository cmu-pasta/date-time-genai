Let's think step by step to solve this problem.
1. Identify the first day of November for the given year as a pendulum.Date.
2. Determine the weekday index of that date (Monday=0, ..., Sunday=6).
3. Compute the offset in days to the first Thursday (weekday index 3).
4. Add 3 weeks to the first Thursday to get the fourth Thursday.
5. Return the resulting pendulum.Date as the Thanksgiving date.

```python
import pendulum

def thanksgiving_date(year: int) -> pendulum.Date:
    """
    Compute the date of Thanksgiving (fourth Thursday of November) for the given year.
    Returns a pendulum.Date.
    """
    # Step 1: First day of November for the given year
    first_nov = pendulum.date(year, 11, 1)  # pendulum.Date

    # Step 2: Weekday of the first day (Monday=0 ... Sunday=6)
    first_weekday = first_nov.day_of_week

    # Step 3: Days to the first Thursday (Thursday=3)
    days_to_first_thu = (3 - first_weekday) % 7

    # Step 4: Fourth Thursday = first Thursday + 3 weeks
    thanksgiving = first_nov.add(days=days_to_first_thu + 3 * 7)

    # Step 5: Return the pendulum.Date
    return thanksgiving

# Entry point: thanksgiving_date(year: int) -> pendulum.Date
```
