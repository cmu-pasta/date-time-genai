1. Import the pendulum library to work with dates.
2. Define a function that takes a pendulum.DateTime as input.
3. Start from the year immediately after the date’s year.
4. For each year, construct a pendulum.DateTime and check if it is a leap year using pendulum’s is_leap_year.
5. Return the first year that satisfies the leap year condition as an integer.

```python
import pendulum

def next_leap_year_after(dt: pendulum.DateTime) -> int:
    """
    Determine the next leap year strictly after the given date.
    
    Args:
        dt: A pendulum.DateTime representing the reference date.
        
    Returns:
        An integer representing the next leap year after the given date.
    """
    year = dt.year + 1
    while True:
        # Use Pendulum to construct a date and check if that year is a leap year
        if pendulum.datetime(year, 1, 1).is_leap_year():
            return year
        year += 1
```
