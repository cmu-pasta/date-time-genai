Let's think step by step to solve this problem.
1. Import the pendulum library to work with dates.
2. Define a function that accepts two pendulum.Date inputs: start and end.
3. Ensure the date order by swapping if start is after end.
4. Find the first Saturday on or after the start date.
5. Find the last Saturday whose corresponding Sunday is not after the end date (i.e., last Saturday on or before end - 1 day).
6. If no such range exists, return 0. Otherwise, compute how many Saturdays (spaced by 7 days) are between these two Saturdays inclusive; that count equals the number of complete weekends.
7. Return the count as an integer.

```python
import pendulum

def count_weekends_between(start: pendulum.Date, end: pendulum.Date) -> int:
    # Ensure start <= end by swapping if necessary
    if start > end:
        start, end = end, start

    # Day-of-week mapping in Pendulum: Monday=0 ... Saturday=5, Sunday=6
    SATURDAY_DOW = 5

    # Compute the first Saturday on or after 'start'
    start_dow = start.day_of_week
    to_first_saturday = (SATURDAY_DOW - start_dow) % 7
    first_saturday = start.add(days=to_first_saturday)

    # The last valid Saturday must have its Sunday within the end date.
    # Therefore, consider the latest allowed Saturday as (end - 1 day).
    latest_allowed_saturday = end.add(days=-1)
    if latest_allowed_saturday < start:
        return 0

    # Compute the last Saturday on or before 'latest_allowed_saturday'
    las_dow = latest_allowed_saturday.day_of_week
    back_to_saturday = (las_dow - SATURDAY_DOW) % 7
    last_saturday = latest_allowed_saturday.add(days=-back_to_saturday)

    # If the range doesn't include any full weekend (Sat+Sun), return 0
    if first_saturday > last_saturday:
        return 0

    # Count Saturdays spaced 7 days apart, inclusive
    total_days = (last_saturday - first_saturday).in_days()
    weekends = (total_days // 7) + 1

    return int(weekends)
```
