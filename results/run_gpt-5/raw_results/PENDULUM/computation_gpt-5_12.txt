Let's think step by step to solve this problem.
1. Import the pendulum library to work with date types.
2. Define a function that accepts a pendulum.Date input representing the given date.
3. Use the week_of_year property to get the ISO week number (1–53).
4. Return the computed week number as an integer.

```python
import pendulum

def calculate_week_number(date_value: pendulum.Date) -> int:
    """
    Calculate the ISO week number (1-53) for the given pendulum.Date.
    """
    # Step 1: Access the ISO week number using Pendulum's built-in property
    week_num = date_value.week_of_year

    # Step 2: Return the result as an integer
    return int(week_num)

# Entry point: calculate_week_number(date_value: pendulum.Date) -> int
```
