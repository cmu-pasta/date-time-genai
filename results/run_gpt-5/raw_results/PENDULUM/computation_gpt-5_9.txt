Let's think step by step to solve this problem.
1. Import the pendulum library to work with timestamps.
2. Define a function that accepts two pendulum.DateTime timestamps as inputs.
3. Compute the difference between the two timestamps using Pendulum's diff method.
4. Convert the resulting duration to seconds and ensure the result is non-negative.
5. Return the number of seconds as an integer.

```python
import pendulum

def calculate_seconds_difference(ts1: pendulum.DateTime, ts2: pendulum.DateTime) -> int:
    # Compute the absolute difference in seconds between two pendulum.DateTime timestamps
    seconds = abs(ts2.diff(ts1).in_seconds())
    return seconds

# Entry point: calculate_seconds_difference(ts1: pendulum.DateTime, ts2: pendulum.DateTime) -> int
```
