1. Import the pendulum library to work with dates.
2. Define a function that accepts a pendulum.Date input.
3. Use the built-in day_of_year property to obtain the ordinal day (1-366).
4. Return the result as an integer.

```python
import pendulum

def convert_to_day_of_year(d: pendulum.Date) -> int:
    """
    Convert a pendulum.Date to its corresponding day of the year (1-366).
    """
    return d.day_of_year
```
