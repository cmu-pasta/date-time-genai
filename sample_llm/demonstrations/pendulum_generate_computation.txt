Problem:
# Here is an interesting idea for a datetime computation:
1. Calculate the number of days between two dates and return the result as an integer representation of the difference.

**Stick to using the Pendulum library in your solution. The inputs and outputs must be of this library type.**

Solution:
Let's think step by step to solve this problem.

1. **Import the necessary libraries**: We need the pendulum library to work with dates.
2. **Define a function**: We will create a function that accepts two dates as input. These dates can be provided as pendulum.DateTime objects.
3. **Calculate the difference**: Use subtraction to find the difference between the two `pendulum.DateTime` objects.
4. **Return the result**: Format the result as an integer in the specified format and return it.

Here is the implementation of the above steps in code:

```python
import pendulum

def calculate_days_difference(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> int:
    # Step 1: Calculate the difference in days
    difference = abs(dt2.diff(dt1).in_days())  # Using abs to ensure a positive difference
    
    # Step 2: Return the result as an integer
    return difference

# Entry point: calculate_days_difference(dt1: pendulum.DateTime, dt2: pendulum.DateTime) -> int
```
